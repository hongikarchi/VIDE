## 수행한 검사

- TypeScript UI/서버 검사 통과.
- 단위·계약·서버 테스트 **147/147** 통과. 네트워크 오류의 Node 검증에서 브라우저 전역 참조 문제를 발견하고 수정한 뒤 전체 재검증.
- tests/integration/browser-react-panels.mjs: 기존 입력 편집·프로젝트 격리·Inspector·수량표·실패 복원·검토본·의견 복구·모바일 초안 회귀 통과.
- tests/integration/browser-workspace-controls.mjs: 위 표의 버튼 조건, 초안 교체 취소/수락, slider, 카메라, 탭, 패널 폭, 파일 오류, 연계 묶음, 문맥 펼침, 인증 상실 통과.
- 실제 Aside: 같은 포트 63702로 재시작/공식 실행 링크 인증, 기존 프로젝트/호스트 선택 복원, 이력/문서 탭, 위→원근 상태, effort 기본값→max→기본값을 확인. 사용자 모델·도면 변경이나 AI 요청 제출은 하지 않음.
- 기존 네이티브 브라우저 테스트의 effort select 선택자를 slider로 갱신. low를 지정하는 Claude 시험은 별칭 대신 명시적 Opus 4.6을 선택하도록 변경했으며 이번에는 이 실호스트/구독 실행을 다시 수행하지 않음.

## 모델 자료와 한계

Codex는 설치된 models_cache.json의 표시 여부와 supported_reasoning_levels를 사용한다. VIDE의 기존 실행 계약이 받는 low/medium/high/xhigh/max와 교집합만 노출한다. ultra의 자동 위임 모드는 이번 UI 수정에서 추가하지 않는다.
Claude CLI의 --help에서 effort 인자를 확인하고 [공식 모델별 지원표](https://code.claude.com/docs/en/model-config#adjust-effort-level)로 명시적 모델별 목록을 제한했다. Fable 5·Opus 4.6·Sonnet 4.6을 명시적 선택지로 제공한다. 계정/조직별 제한과 실제 추론 성공은 자료만으로 확정할 수 없으므로 모델 선택 툴팁에 구분해 표시한다. 모든 모델/effort 조합을 구독으로 실행해 검증한 것은 아니다.
이번 완료는 선택 UI 범위이며 모바일 펜 실기기 검수, 전체 제품 MVP 완료, 미선택 디자인 항목까지 뜻하지 않는다.
