## 실제 CLI 확인

`node tools/spikes/2026-09-19-ai-execution-path/adapter-probe.mjs`를 네트워크 접근 가능한 환경에서 실행해 starting→running→정상 응답 `VIDE_OK`를 확인했다. 실제 제품 코드 `src/ai/claude-cli.mjs`를 사용했다. 구독 잔량은 미확인으로 반환한다.

같은 명령에 `--cancel`을 추가해 running 뒤 취소를 요청했다. stopping→실제 프로세스 종료 관측→stopped→CANCELLED로 끝났고 명령 exit code 0이었다. 이는 CLI 프로세스 취소 검증이며 CAD 내부 연산 취소를 의미하지 않는다. 인증·계정 식별 정보와 원시 로그는 증거 파일에 보존하지 않았다.

## 남은 검증

T-001의 코어 계약은 위 시험으로 확인했다. 호스트 명령 본문 검증·기하 지문·대상 재확인·네이티브 영수증은 T-003·005에서 구현한다. T-004는 구독 응답과 프로세스 취소를 확인했으나 구조화 작업 제안 검증·연속 실행·재개·한도 초과·배포 조건이 남았다. 전체 PRD AC를 통과한 것으로 집계하지 않는다.
