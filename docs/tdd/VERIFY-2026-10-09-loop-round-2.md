# 검증–수정 루프 라운드 2

[PLAN-51](../plans/PLAN-51-verify-loop.md) §5 수정 웨이브(커밋 `d62d813a` → v0.2.32)를 설치본에서 다시 잰 기록이다. 라운드 1 기록은 [VERIFY 라운드 1](VERIFY-2026-10-08-loop-round-1.md)이다. 판정 등급은 PLAN-51 §1·§2를 따른다. 페르소나의 직관·쉬움 판정과 `goalReached`는 모두 **대행 판정**이다(`goalReached`는 검수자가 스크린샷을 읽고 손으로 적었다). 스코어카드 판정(`tools/ab/scorecard.mjs`)과 검토 판정이 다르면 둘 다 적는다.

**요약:** 스코어카드는 P0 5 · PASS 1(R1-NOTE)로 통과율 1/6이다(`.vide/ab/r2-scorecard-installed/`). route-only는 7/7 PASS로, R1-A가 `document`에서 Sync jig로 바뀌었다. 페르소나 런 다섯 개 중 `goalReached: true`는 R1-A 하나다. 그것도 Sync jig가 열렸다는 데까지만이고, 비교 결과는 Rhino 0개였다. **이번 L1 판정은 오염돼 있다.** CAD를 페르소나 런 전에 연결해서 AI 요청 5건이 모두 `host: zwcad`로 갔고, S-06·법규 체크·사이트 모델링도 ZWCAD 문서를 기준으로 삼았다. 그래서 R1-HIDE·D·C·B는 Rhino만 연결한 상태에서 다시 돌려야 판정이 유효하다. 라운드 1 P0 티켓 다섯 개 중 해소는 T-272 하나다. 나머지 넷은 부분이다. 새로 등록한 티켓은 P0 후보 3건, P1 1건, 도구 1건이다(T-282~T-286). 졸업한 시나리오는 0/10이다.
