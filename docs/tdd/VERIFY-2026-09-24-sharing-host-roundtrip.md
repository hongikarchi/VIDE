# 공유 의견의 실제 호스트 수정·재게시 왕복

기준은 SPEC-04.7과 PLAN-02 §6.1 4a다. 로컬 Cloudflare workerd/D1/R2, 실제 Chromium, 설치된 ZWCAD 2023의 소유 합성 실행본으로 검사했다. 원격 업로드·메일·유료 추론은 실행하지 않았다.

## 수행과 결과

`node tests/sharing/membership.mjs --browser --host`가 통과했다. 증거는 `.vide/sharing-membership/c5c5f7a6-dfc5-4408-9335-64f7662e0f57/result.json`과 `host-feedback-republished.png`다.

1. 자체 SDK가 24×10 m, 240 m² 합성 도면을 만들고 실제 저장/재조회했다. 브라우저에서 명시 선택한 객체만 공유 자료로 내보내 게시했다.
2. 다른 계정의 댓글 권한 사용자가 객체·월드 핀·스케치를 붙여 폭 26 m 변경 의견을 보냈다. 소유자가 의견 파일을 내려받고 로컬 UI에서 중복 수신·초안 채택·재시작 유지를 확인했다. 채택까지는 실행 호출 0회다.
3. 채택된 문장·객체 기준·스케치·출처 파일을 요청으로 제출했다. 결정적 에이전트 대역이 제품 MCP 도구를 호출하고 실제 제어기/자체 SDK가 같은 Handle의 도면을 수정했다. 면적 260 m²와 원본 파일 해시 불변을 확인했다.
4. 실제 결과를 새 게시본으로 전송하고 최신 게시본 전환·이전 게시본 보존을 확인했다. 브라우저에서 새 도면의 로딩·객체 선택·정투영 위 보기를 검수했다. 최초 캡처가 로딩 중이어서 시험을 보강한 뒤 다시 실행했고 위 증거는 보강 후 결과다.
5. 같은 실행에서 교차 프로젝트·권한 회수·게시/댓글 중복·중단 게시·오래된 게시 기준·핀/스케치·작은 화면 회귀도 통과했다.

## 판정과 한계

파일 방식의 로컬 의견 수신→명시 실행→실제 후보 수정→재게시 연결은 검증했다. 자연어 추론 품질은 이 결정적 대역 시험의 판정 대상이 아니며 양쪽 실제 구독 시험은 [SDK 제품 검증](VERIFY-2026-09-24-zwcad-sdk-product.md)을 참조한다. 열린 원본에 자동 적용하지 않으며 후보의 명시 적용은 별도 호스트 검수다. 온라인 자동 동기화, 원격 게시/PC 종료 후 지속성, 논현동 수준의 실무 수용을 완료로 표시하지 않는다.

## 로컬 복구 회귀

`membership.mjs --backup`도 통과했다. `.vide/sharing-membership/660ee563-94ec-4194-b401-dd3e5c8e4059`에서 10 MiB 전송/재시작 복구 1,084 ms, 중지한 로컬 에뮬레이터 스냅샷의 복원/검증 937 ms였다. 게시·의견·권한의 복원 일치를 검사했다. 이는 loopback 실측이며 원격 D1 반출·실서비스 재해복구·인터넷 지연의 증거가 아니다.

## 원격 무료 조건 재확인

2026-09-24 Wrangler 4.136.1의 읽기 전용 `r2 bucket list/info`로 계정 저장 통계를 재확인했다. VIDE staging은 0개·0 B이지만 기존 다른 버킷 하나가 약 11.2 GB이며 추가 버킷에도 데이터가 있다. 객체 내용은 읽지 않았고 자료를 삭제하지 않았다. [공식 R2 가격표](https://developers.cloudflare.com/r2/pricing/)의 Standard 무료 저장은 월 10 GB-month이며 일별 최고 저장량의 월 평균으로 계산된다. 현재 용량만으로 실제 월 청구액을 확정할 수 없지만 무료 시험을 보장할 근거도 없어 `UPLOADS_ENABLED=false`를 유지했다. 무료 여유 또는 명시된 유료 시험 예산이 확인된 뒤 원격 모델 게시·PC 종료 후 열람을 재개한다. 현재 원격 미검수와 로컬 왕복 완료를 구분한다.
