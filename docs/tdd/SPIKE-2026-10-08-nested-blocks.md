# 중첩 블록이 Sync에서 상자로 오는 문제 재현

사용자 보고(2026-10-08): "라이노에서 블록 안에 다른 블록이 들어 있는 중첩 구조가 되면 sync할 때 박스로 넘어오는 것 같다." 기준은 [ARCH-01](../architecture/ARCH-01-system.md) 「Rhino 표시 페이지 취득」(한 객체가 페이지 예산 12 MiB를 넘으면 경계 상자)과 [Rhino 지원표](../specs/hosts/rhino.md) H-RHINO-09다. 해당 FR·AC가 따로 없어 이 두 기준 문단을 인용한다. 실험은 제품 지원으로 세지 않는다(AI.md §2). 제품 코드는 바꾸지 않았다.

## 질문

중첩 블록 인스턴스가 표시 Sync에서 상자(`oversized`)로 바뀌는 조건은 무엇인가. 중첩 자체(깊이·변환·정의 구성·정의 수정)가 원인인가, 크기인가.

## 방법

- 코드: `tools/spikes/2026-10-08-nested-blocks/repro.mjs`. `node tools/spikes/2026-10-08-nested-blocks/repro.mjs` (`HEAVY=<n>`로 무거운 사례의 가지 수를 바꾼다).
- 합성 문서만 쓴다(`.vide/nested-blocks/<uuid>/`). 작업용 Rhino에서 문서를 만들고, 사본을 이 스크립트가 띄운 숨은 Rhino 8에서 열어 `AttachedConnection`으로 연결한다. 앱과 같은 경로인 `SdkExecution.syncEditor`(`displayPage`, VGT1)로 전체 Sync, `displayChanges`로 Live 변경을 읽는다.
- 환경: Rhino 8, 메인 체크아웃의 개발 빌드 플러그인(`.vide/build/rhino-worker/.../VIDE.Worker.rhp`, 2026-10-08 빌드).

중첩 깊이·변환·정의 구성·정의 수정만으로는 상자가 되지 않는다. 같은 형상량이 중첩 없이 놓이면 정상이고, 중첩되면 상자가 된다.

## 원인

- `DisplayParts.AddDefinition`은 중첩 참조를 바깥 정의 안에 펼쳐(flatten) 복사한다. 안쪽 정의가 공유되지 않으므로 바깥 정의 하나의 크기는 안쪽 형상 × 사본 수로 곱해진다. 사례 6은 정점 63만·삼각형 127만, VGT1로 약 23 MB다.
- `DisplayScene.Fit`은 인스턴스 크기에 처음 쓰이는 정의 크기를 더하고, 합이 페이지 예산(12 MiB)을 넘으면 `Box()`로 바꾼다. 상자는 `Definition`을 지우므로 그 정의는 `included`에 들어가지 않고, 같은 정의의 다음 인스턴스도 다시 정의 크기를 더해 상자가 된다(코드 판독, 이번 실행은 인스턴스 1개).
- 대략 펼친 정점 수 + 삼각형 수가 약 100만(VGT1 기준 12 MiB)을 넘으면 상자가 된다. 열린 파일 경로(`WorkerScene.Export`)도 같은 펼치기를 쓰고 JSON 16 MB 초과 시 `boxOnly`로 다시 읽으므로 같은 현상이 나올 것이다(코드 판독, 이번에 실행하지 않음).
- 화면: 상자 행은 `block` 없이 정점 8·삼각형 12의 메시라 `sceneRepresentation`이 메시로, 뷰포트가 상자로 그린다(코드 판독, 브라우저 렌더 확인은 하지 않음).

## 한계

- 사용자 실제 모델의 정의 크기는 보지 않았다. 실제 모델이 다른 이유(정의에 SubD·Surface·점만 있는 경우 등)로 비어 보이는 경우는 상자가 아니라 표시 없음이며 이번 실험 범위 밖이다.
- 브라우저 렌더(헤드리스 Chrome)는 하지 않았다.

## 다음 행동

수정 방향(결정 필요): 정의를 펼치지 않고 중첩 참조를 정의별로 한 번씩 보내 공유하거나, 큰 정의만 하위 정의 단위로 나누는 방안. 표시 계약 변경이므로 ARCH-01과 해당 PLAN에서 먼저 정한다.

2026-10-08 반영: 첫 방안(정의마다 한 번, 중첩은 `children` 참조, 엔진이 펼침)으로 고쳤다. 계약은 ARCH-01 「Rhino 네이티브 취득의 블록 보존」, 실호스트 검증은 `tests/integration/rhino-nested-blocks.mjs`와 [Rhino 지원표](../specs/hosts/rhino.md) H-RHINO-13이다.
