01 / SCREENS

화면 8장, 한 프로젝트의 하루.

‹ › 또는 ← → 로 넘긴다. 글자가 작으면 [새 창 ↗].

레일 왼쪽 아래: 피드백 · 밝게/어둡게 · 설정 · 계정(현행 제품 순서).

01

시작 — 선택 창

사용자 폴더를 연다.

화면 Kiro처럼 묻는다: 바로 시작 / 설계 세우기.

02

기록 DB

사용자 회의록·메일·주간/월간 업무·협의 리스트를 넣는다.

화면 번호·날짜·부위·글리프·문장 한 줄. 왼쪽에서 종류·출처·기간을 거른다.

03

조건 · 결정 · 작업

사용자 결정 D-04의 근거를 묻는다.

화면 표 하나, 탭 셋. 근거는 기록 번호.

04

바로 적용 → 변경 비교

사용자 기둥을 고르고 "600 동쪽으로".

화면 결과 한 줄 + 되돌리기. 가운데에 전/후.

05

검토 후 반영 — 구조 검토안

사용자 "기둥 배치 구조 검토".

화면 평면과 경간 표. [모델에 반영]을 눌러야 들어간다.

06

부위별 기록 × 모델

사용자 날짜를 끌거나 부위를 누른다.

화면 위 모델, 아래 타임라인. 커서 하나가 둘을 움직인다.

07

기록 그래프

사용자 레일의 「기록」을 연다.

화면 부위에 대고 본 기록과 관계, 스레드 4. 아티팩트 그대로.

08

검토본 비교 · 보고

사용자 "검토본 3이랑 비교해서 보고".

화면 두 장과 바뀐 점, 외부 의견. 폴더에 쓸지는 대화에서 한 번 묻는다.

02 / CHANGES

2026-10-20 피드백 8개를 이렇게 반영했다.

1 입력창 단순하게「계획부터」와 「자동|확인」을 지우고 스위치 하나 「적용 전 확인」.
2 단추 자리상단바 삭제. 피드백·테마·설정·계정은 현행 제품처럼 레일 왼쪽 아래.
3 기록 아티팩트 컨셉토큰·조각을 그대로 옮김(흰 바탕·가는 선·탠·글리프·스위치). 07은 그 코드 포팅, 06은 모델+타임라인 구성.
4 탐색기 정리유지. 자료에 주간·월간 업무·협의 리스트 추가.
5 시작 선택 창01에 Kiro식 선택 창(바로 시작 / 설계 세우기, 다음부터 묻지 않기).
6 worktrees59개 모두 main에 들어간 것 확인 뒤 삭제.
7 데이터 DB02 기록 DB: 올려 주는 업무 보고·협의 리스트가 번호·날짜·부위·글리프·문장으로 쌓인다.
8 글자 줄이기장마다 제목 + 한 문장 + 표나 그림 하나. 숫자 줄·안내 상자·배지 삭제.
