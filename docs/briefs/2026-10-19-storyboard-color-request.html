기둥 하나를 골라 빨갛게.
보내고, 바뀌고, 되돌린다.

프로젝트를 열고 Rhino 파일을 연결해 기둥 하나를 빨갛게 바꾸고 되돌리기까지, 지금 만들어진 실제 화면 8장.

단계 8 · 실제 캡처
답은 바닥의 [피드백 복사]
01 / STORY

단계마다 화면 하나.

사진 위 AI 응답 주입 = AI를 부르지 않고 결과 상태를 넣어 찍음 · 대체 = 가까운 화면 · 코랄 줄 = 캡처 중 본 문제.

01

프로젝트를 연다

사용자 프로젝트를 골라 홈을 연다.

화면 일정과 할 일, 연결 파일 수가 보인다. 아직 연결 파일 0.

근거 SPEC-01.14
02

작업 화면 첫 상태

사용자 3D 화면으로 들어간다.

화면 연결 파일이 없어 Link 하는 법 3단계와 빈 화면이 보인다.

근거 SPEC-01.11
03

Rhino 파일 연결과 Sync

사용자 Rhino에서 Link를 누른다(클릭 없이 자동 Sync).

화면 연결 파일·레이어 2개, 3D 모델, 오른쪽에 Sync 작업 카드.

근거 SPEC-01.9
04

기둥을 골라 문장에 넣는다

사용자 기둥을 클릭하고 입력창의 '선택 1개 첨부'를 눌러 문장에 넣는다.

화면 고른 기둥이 강조되고 문장 안에 [고정1 · 1개] 표시가 생긴다.

근거 SPEC-01.10
05

요청이 진행된다

사용자 보내고 기다린다. 필요하면 [추가 지시].

화면 대상·핀·모드, 진행 단계(요청 이해 → 실행)와 AI 한 줄 설명.

근거 SPEC-02.11
06

결과: 기둥이 빨갛게

사용자 3D에서 바뀐 기둥을 확인한다.

화면 결과 한 줄, '추가 0 · 변경 1 · 삭제 0 · 적용됨'과 [되돌리기].

변경 객체 목록이 이름 대신 긴 ID로 보인다. 근거 SPEC-02.13
07

되돌리기

사용자 [되돌리기]를 누른다.

화면 작업 줄이 취소선과 '되돌림'으로 바뀌고 기둥이 원래 색으로 돌아온다.

근거 SPEC-02.13
08

작업 이력에 남는다

사용자 왼쪽 [작업 이력]에서 지난 요청을 연다.

화면 요청과 Sync가 시간순으로 쌓인다. 되돌린 요청도 '응답 완료'로 남는다.

Sync 줄이 요청 사이에 섞여 요청을 찾기 어렵다. 근거 SPEC-03.2
