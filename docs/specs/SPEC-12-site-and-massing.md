# 규모검토 jig

근거: 2026-10-07 사용자 메모([RESEARCH-16](../research/RESEARCH-16-domain-services-roadmap.md) §2·§3)와 같은 날의 결정 "규모 검토의 경우, site modeling / 법규 검토 사항을 바탕으로 모델링(건축 가능 영역) + 매스 검토 / 건축 개요 작성(문서작업) 이런 식으로 기능을 쪼개서 개발하는게 좋아보이는데"와 "모두 상세". 과거 수행 내역과 함정은 [RESEARCH-04](../research/RESEARCH-04-jig-past-experience.md) J-01·J-03·J-04다.

이 명세는 규모검토를 **따로 개발하고 따로 쓸 수 있는 jig 세 개**로 나누어 동작을 정한다.

| jig | 하는 일 | 정본 절 |
|---|---|---|
| **사이트 모델링** | 주소·PNU로 대지와 주변(지적·도로·건물·지형·용도지역)을 모아 Rhino에 형상과 메타데이터로 만든다 | SPEC-12.3~12.6 |
| **건축 가능 영역·매스** | 대지와 규제 조건으로 2D 가능 영역 → 3D 가능 외피 → 층·대안·인센티브 → 용도 배분 → 주차·공지를 계산한다 | SPEC-12.7~12.12 |
| **건축개요** | 고른 대안으로 건축개요와 층별 면적표를 만든다 | SPEC-12.13 |

소유 경계는 다음과 같다. jig 공통 동작(작업본·입력 조립·설정값·단계·Rhino에 만들기·보고서)은 [SPEC-07](SPEC-07-jig-platform.md), 질문 카드와 말로 jig 열기는 [SPEC-02](SPEC-02-execution-candidates.md).17·02.19, 프로젝트 자료의 확정과 근거는 [SPEC-08](SPEC-08-project-facts.md)이 소유한다. **법규의 판단**(어느 조항이 적용되는지, 값이 얼마인지, 완화가 되는지)은 법규 질의응답·검토 명세 SPEC-13이 소유하고, 이 명세는 그 결과를 읽어 형상과 면적을 계산하는 쪽만 정한다. 공공 자료의 호출 방식·키 보관·메타데이터 키 이름·만들기 틀은 ARCH-01·[ARCH-03](../architecture/ARCH-03-jig-runtime.md), 구현 순서와 시험은 [PLAN-45](../plans/PLAN-45-site-massing-jigs.md)가 소유한다.

제품 범위: 2026-10-07 사용자가 규모검토 흐름(PRD C-05)을 채택했다. 제공 범위는 PRD §14.2의 '규모검토' 행이며, 그 밖의 사이트·법규·개요 전문 스킬(FR-21)은 후속 확장이다. 이 명세는 jig 플랫폼(FR-24) 위의 동작을 정한다. 구현은 과거 규모검토 자산(RESEARCH-04 S-02·S-03·S-04·S-19)을 재사용한다(PLAN-45 「재사용할 기존 코드·저장소」).

## 대지에서 개요까지 — SPEC-12.1

근거: FR-24·25·09, C-05, RESEARCH-16 §2·§3. **설계자는 주소 하나로 대지 모델을 Rhino에 만들고, 법규 결과를 받아 대지 안의 건축 가능 영역과 최대 외피를 보고, 대안 몇 개를 비교해 하나를 고른 뒤 건축개요와 층별 면적표를 낸다. 숫자와 형상은 코드가 계산하고, 법규의 판단은 법규 결과나 사람이 정하며, AI는 모호한 것을 묻고 초안을 낼 뿐이다.**

1. **대지 모델링:** "○○동 123-4 대지 모델링해 줘"라고 말하거나 JIG 목록에서 사이트 모델링을 연다(SPEC-07.18). 후보 필지가 나오면 사람이 대상 필지를 확정한다. VIDE가 지적·도로·주변 건물·지형·용도지역을 모아 미리보기로 보이고, 사람이 [Rhino에 만들기]를 누르면 대지 모델이 메타데이터와 함께 열린 문서에 생긴다.
2. **법규 결과 받기:** 같은 대지의 법규 검토(SPEC-13)가 낸 규제 조건(건폐율·용적률·높이·건축선·이격·일조·주차 기준 등)을 매스 jig가 읽는다. 법규 결과가 없거나 '판단 필요'인 항목은 사람이 값을 넣는다.
3. **가능 영역과 외피:** 건축 가능 영역·매스 jig가 제한선별 2D 영역과 3D 외피(돌출·일조 사선·최대 외피)를 계산해 보인다.
4. **대안:** 층을 나누고 기준 용적률안·인센티브 반영안 등 대안을 만들어 표로 비교한다. 용도를 층별로 나누고 주차 대수·공지 면적과 주차 방식 대안을 본다. 사람이 대안 하나를 '고른 대안'으로 정한다.
5. **건축개요:** 건축개요 jig가 고른 대안으로 개요와 층별 면적표를 만든다. 보고서(HTML)와 표(CSV)로 내보낸다.
6. **다시:** 앞 jig의 결과가 바뀌면 뒤 jig는 '다시 계산 필요'가 된다. 자동으로 이어서 다시 계산하지 않는다(SPEC-07 §19).

**완료 기준(1차):** 합성 대지 자료(실제 프로젝트 대지가 아닌 것)에서 주소 → 대상 필지 확정 → 수집·미리보기 → Rhino에 만들기 → 규제 조건 입력 → 2D 영역 → 3D 외피(닫힌 폴리서피스, 점검 통과) → 대안 세 개 이상 → 고른 대안 → 건축개요 HTML·CSV가 실제 Rhino 사본 문서에서 이어져야 한다. 공공 자료의 실제 호출은 키가 있는 PC에서 비프로젝트 공개 필지로 한 번 이상 확인한다. 화면만 있거나, 고정된 예제 대지에서만 되거나, 출처 구분 없이 숫자만 나오는 상태는 완료가 아니다. 결과 화면과 보고서에는 항상 "탐색용 규모검토 — 인허가 도서·면적 산정·법규 검토를 대체하지 않음"을 보인다.

## 1. 세 jig의 연결 — SPEC-12.2

근거: FR-24, SPEC-07.2·07.5.

| jig | 입력 | 출력 | Rhino에 만드는 것 |
|---|---|---|---|
| 사이트 모델링 | 주소·PNU, 넣은 SHP 파일(선택) | 대지 요약, 대상·주변 필지, 도로, 건물 매스, 지형, 용도지역 경계 | 위 형상과 메타데이터(SPEC-12.6) |
| 건축 가능 영역·매스 | 사이트 모델링 출력 또는 Rhino의 대지 경계 레이어, 규제 조건, 계획 조건 | 제한선, 2D 가능 영역, 3D 외피, 층별 윤곽, 대안 표, 용도·주차·공지 표, 고른 대안 | 제한선·영역 곡선, 외피·대안 매스(닫힌 폴리서피스) |
| 건축개요 | 고른 대안, 대지 요약, 규제 조건, 사람이 적는 개요 항목 | 건축개요 표, 층별 면적표, 보고서 | 없음 |

- **다른 jig의 출력은 입력으로만 받는다**(SPEC-07.2). 받을 때 앞 작업본·대안·계산 시각을 함께 기록하고, 앞 작업본의 결과가 바뀌면 '다시 계산 필요'를 보인다(SPEC-07.5의 6). 법규 서비스가 주는 규제 조건(SPEC-13.8)도 같다: 앞 작업본을 고를 것은 없고, 마지막 계산 뒤 그 내용(답의 값·적용 여부·조회 시각)이 바뀌면 매스 작업본의 법규 입력 카드에 '다시 계산 필요'를 보인다.
- **따로 쓸 수 있다.** 건축 가능 영역·매스 jig는 사이트 모델링 없이 Rhino의 대지 경계·도로 경계·인접 대지 경계 레이어를 입력 조립(SPEC-07.5)으로 받아 쓴다. 이때 정북 방향과 대지면적은 설정값으로 사람이 확인한다.
- **한 대지에 작업본 여럿:** 같은 jig의 작업본을 여러 개 둘 수 있다(SPEC-07.4). 매스 jig의 대안은 한 작업본 안의 대안 표로 다루고, 계획 조건 자체를 크게 바꾼 비교는 작업본을 나눈다.
- 세 jig는 공식 jig다. 공공 자료의 네트워크 접근은 공식 수집 라이브러리만 한다(SPEC-07.9).

## 2. 사이트 모델링: 대상 필지 찾기 — SPEC-12.3

근거: FR-24·25·16, SPEC-02.19의 6.

1. **입력:** 지번 주소, 도로명 주소, PNU(19자리) 중 하나. 필지를 더해 합필 대지를 만들 수 있다.
2. **후보:** 주소마다 후보 필지(주소·지번·지목·공부 면적·PNU)를 찾는다. 후보가 하나면 그것을 제안한다. 후보가 여럿이거나(동명 지번, 산 지번, 여러 필지에 걸친 도로명 주소) 하나도 없으면 질문 카드로 묻는다. 카드에는 후보 목록과 작은 위치 그림을 보이고, [PNU 직접 입력]을 둔다. AI가 후보 가운데 하나를 고르지 않는다. 고른 필지가 없는 동안은 후보가 하나여도 카드로 확인을 받으며, 아직 찾지 않았으면(전송 확인 전 등) 묻지 않는다. 이 카드는 jig 단계의 질문이므로 jig 화면의 대상 필지 부품 안에 VIDE 질문 카드 모양으로 보인다(ADR-026).
3. **대상 필지 확정(사람 단계):** 확정 전에도 수집·미리보기는 돌지만 결과에 '대상 필지 미확정'이 붙고 Rhino에 만들기는 막힌다. 확정한 뒤 필지 목록이 바뀌면 다시 확인 필요로 돌아간다(SPEC-07.7). 확인하는 것은 필지 목록이며, 누가 제안했는지나 다시 가져온 사본은 확정을 다시 묻지 않는다.
4. **합필:** 여러 필지는 경계를 합쳐 대지 하나로 만든다. 서로 닿지 않는 필지가 있으면 '떨어진 필지'로 경고하고 사람이 확정해야 한다. 필지 사이 내부 경계는 Rhino에 따로 남긴다.
5. **SHP에서 찾기:** 공공 자료 호출을 끈 프로젝트나 키가 없는 PC에서는 넣은 연속지적도 SHP에서 지번·PNU로 찾는다.
6. **말로 열기:** 요청 글에 지번·도로명 주소나 PNU가 있으면(예: "○○동 123-4 대지 모델링해 줘") 그 주소로 찾는 데까지 이어서 하고, 첫 사람 단계(대상 필지 확정) 앞에서 멈춘다. 주소를 읽지 못하면 사람이 입력한다.

## 3. 사이트 모델링: 가져오는 자료 — SPEC-12.4

근거: FR-09·18·16, PRD §6.3, ADR-040, RESEARCH-04 §4.

| 자료 | 내용 | 기본 출처 | 대체 출처 | 없을 때 |
|---|---|---|---|---|
| 대상·주변 필지 | 경계, 지번, 지목, PNU | 공공 지적 자료(연속지적) | 넣은 연속지적도 SHP | 대상 필지 경계가 없으면 다음 단계를 막음 |
| 대지면적 | 공부상 면적 | 공공 토지·건축물 대장 자료 | 사람 입력 | 계산 면적만 보이고 '공부 면적 없음' |
| 용도지역·지구·구역 | 이름, 코드, 저촉 여부, 고시 번호 | 공공 토지이용계획 자료 | 사람 입력 | '용도지역 미확인'. 매스 jig의 규제 조건이 비게 됨 |
| 도로 | 지목이 도로인 필지, 도로 경계·중심선 | 공공 지적 자료 + 넣은 수치지형도 SHP | 사람이 그린 선 | 도로 폭·접도 길이를 계산하지 않음 |
| 주변 건물 | 윤곽, 층수, 높이, 주용도 | 공공 건물 자료와 건축물대장 표제부 | 수치지형도 SHP의 건물 | 건물 없이 대지만 만듦 |
| 지형 | 등고선, 표고점 | 넣은 수치지형도 SHP | — | 평지(높이 0)로 두고 '지형 없음' |

- **범위:** 주변 자료는 대상 대지 경계에서 설정값 '주변 반경'(기본 200 m, 50~600 m) 안을 가져온다.
- **좌표계를 가정하지 않는다.** 자료마다 좌표계를 판별해 하나로 옮긴다. 판별하지 못하거나 구 좌표계(Bessel 기준)로 판별되면 그 자료를 쓰지 않고 이유를 보인다. SHP의 문자 인코딩도 파일이 밝힌 것을 따르고 추측하지 않는다.
- **조회 사본을 고정한다.** 가져온 자료는 조회 시각·출처·원 식별자와 함께 작업본에 사본으로 둔다. [다시 가져오기]는 새 사본을 만들고 바뀐 항목(필지 경계·지목·용도지역·건물 수 등)을 목록으로 보인다. 사람이 받을 때만 새 사본으로 바꾸며 이전 사본을 덮어쓰지 않는다.
- **'에러 없는 빈 결과'를 성공으로 보지 않는다.** 응답의 개수가 0이거나 대상 필지가 범위 안에 없거나 면적이 공부 면적과 크게 다르면(기본 5% 초과) 그 자료를 '확인 필요'로 표시한다. 형식이 예상과 다른 응답은 쓰지 않는다.
- **개인정보:** 소유자 이름·주민번호 등 개인정보를 요청하거나 저장하지 않는다. 그런 항목을 돌려주는 자료원은 호출하지 않는다.
- **전송 고지(FR-18):** 공공 자료원에 보내는 것은 주소·PNU·좌표 범위다. 프로젝트에서 처음 가져올 때 보내는 항목과 받는 곳을 한 번 보이고 확인을 받는다. 프로젝트 설정에서 끌 수 있고, 끄면 넣은 SHP만 쓴다.
- **키:** 자료원 키는 이 PC의 VIDE 설정에만 둔다. 키가 없으면 해당 자료만 '키 없음'으로 보이고 다른 자료는 계속 가져온다. 보관 방식은 ARCH-01이 소유한다.
- **SHP 넣기:** 사용자가 파일(또는 압축 파일)을 고른다. 필요한 짝 파일(형상·속성·좌표계)이 없으면 넣지 않고 무엇이 없는지 보인다. 넣은 파일은 프로젝트 자료로 남지 않고 이 작업본의 사본으로만 쓴다.
  - 좌표계는 파일 이름이 아니라 좌표계 파일의 값(투영·타원체·중앙 자오선·축척·원점)으로 판별한다. 한국 평면 좌표계(Korea 2000의 UTM-K와 서부·중부·동부·동해 원점), UTM, 경위도를 받는다. 받을 수 있는 좌표계·거절 이유의 목록은 ARCH-03 §8.1이 소유한다.
  - 인코딩은 파일이 밝힌 것을 따른다. 밝히지 않았으면 UTF-8로 온전히 읽힐 때만 쓰고 '인코딩 선언 없음'을 보이며, 그렇지 않으면 그 파일을 넣지 않고 인코딩 파일(.cpg)을 함께 넣으라고 보인다.
  - 수치지형도에서는 건물·도로경계·등고선·표고점만, 연속지적도에서는 필지만 쓴다. 나머지 레이어는 '쓰지 않음' 목록에 이름만 보인다. 도로경계 면은 건물로 쓰지 않고, 무벽건물은 목록에 남기되 매스·면적에서 뺄 대상으로 표시한다(SPEC-12.5).
  - 좌표계 판별·인코딩·짝 파일 문제는 그 파일만 빼고 나머지는 계속 넣는다. 넣은 형상과 속성 수가 다르거나 형상이 하나도 없으면 '확인 필요'다.

## 4. 사이트 모델링: 계산과 대지 요약 — SPEC-12.5

근거: FR-24·10·09, SPEC-07.6·07.7.

| 단계 | 종류 | 하는 일 |
|---|---|---|
| 필지 후보 | 라이브러리 + 계산 | 주소 → 후보 필지(SPEC-12.3). 공공 자료 조회는 엔진이 공식 라이브러리로 하고, 단계는 그 사본과 넣은 SHP에서 후보를 만든다 |
| 대상 필지 확정 | 사람 | SPEC-12.3의 3 |
| 수집 | 라이브러리 + 계산 | SPEC-12.4의 자료를 가져와 사본으로 둠([가져오기]·[다시 가져오기]는 엔진의 공식 라이브러리). 단계는 사본과 넣은 SHP를 자료별 상태와 함께 한 묶음으로 만든다 |
| 좌표 통일 | 계산 | 모든 자료를 한 평면 좌표계로 옮기고 기준점(정수 m) 하나를 정함. 계산은 기준점에서의 로컬 좌표로 하고 진북·도북 차는 기준점에서 구함. 기준점은 레이어를 빼거나 순서를 바꿔도 움직이지 않음 |
| 도로와 접도 | 계산 | 대지에 접한 도로 구간, 방향, 계산 폭(최소·평균), 접도 길이 |
| 건물 매스 | 계산 | 윤곽을 높이만큼 올린 닫힌 매스. 높이는 공공 자료에 기록된 높이(공공 건물 정보, 없으면 건축물대장 표제부), 둘 다 없으면 층수 × '추정 층고'(기본 3.3 m) |
| 지형 | 계산 | 등고선·표고점으로 지형 면. 꺼져 있으면 평지 |
| 대지 요약 | 계산 | 아래 목록 |

- **설정값:** 주변 반경, 추정 층고, 지형 포함(기본 끔), 원점 방식(대지 기준점 / 측량 좌표 그대로, 기본 대지 기준점), 정북 기준(진북 / 도북, 기본 진북). 모두 SPEC-07.6의 근거·이력을 가진다.
- **대지 요약:** 주소와 PNU 목록, 대지면적(공부 · 계산 · 차이), 지목, 용도지역·지구·구역(여러 지역에 걸치면 각 면적과 비율), 접한 도로(방향·계산 폭·접도 길이), 진북과 도북의 차(각도), 대지 고저차(지형이 있을 때), 주변 건물 수와 최고 높이, 각 값의 출처 구분(SPEC-12.14)과 조회 시각.
- **도로 폭은 계산 값이다.** 법상 도로인지, 폭을 얼마로 인정하는지, 접도 요건을 만족하는지는 법규 판단이며 SPEC-13 결과나 사람이 정한다.
- **추정 높이는 '추정'으로 남는다.** 층수로 추정한 건물은 표와 Rhino 속성에 높이 출처 '추정'을 단다. 지붕만 있는 시설 등 벽이 없는 건물은 매스로 만들지 않고 목록에 남긴다.
- **AI가 읽는 자리:** 대지 요약과 Rhino 메타데이터(SPEC-12.6)는 대화 AI와 법규 질의응답(SPEC-13)이 조회 도구로 읽는다. AI는 이 값을 고치지 않는다.

## 5. 사이트 모델링: Rhino에 만들기와 메타데이터 — SPEC-12.6

근거: FR-24·12·09, SPEC-07.12, ADR-030, ARCH-01 §「외부 도메인 서비스」.

- **레이어:** 작업본의 출력 레이어 아래에 대상 필지, 주변 필지, 도로, 건물, 지형, 등고선, 용도지역 경계, 대지 정보를 한 단계씩 둔다(SPEC-07.12의 2).
- **형상:** 필지·도로·용도지역 경계와 등고선은 닫힌 곡선 또는 곡선, 건물은 닫힌 폴리서피스, 지형은 메쉬 또는 면이다. 만들지 못한 항목(닫히지 않는 매스, 퇴화한 윤곽)은 조용히 빼지 않고 결과 카드에 '만들지 못함 n'과 목록으로 보인다.
- **메타데이터(객체 속성):** 모든 객체는 SPEC-07.12의 jig 태그를 갖고, 종류별로 다음을 더한다.

  | 객체 | 속성 |
  |---|---|
  | 필지 | PNU, 지번, 지목, 공부 면적, 자료 출처, 조회 시각 |
  | 도로 | 계산 폭(최소·평균), 계산 출처 |
  | 건물 | 층수, 높이, 높이 출처(대장·추정), 주용도(있을 때), 자료 출처 |
  | 용도지역 경계 | 이름, 코드, 고시 번호 |
  | 대지 정보(점 하나) | 대지 요약 전체, 좌표계, 기준점의 측량 좌표, 진북 각 |

  용도지역 경계는 공공 자료가 필지 안의 한 점으로만 답하므로 1차에는 형상을 만들지 않고, 이름·코드·고시 번호를 대지 정보의 요약에 둔다. 합필 대지는 대상 필지 곡선과 함께 합친 대지 경계를 따로 만든다.

  속성 이름·글자 규칙은 ARCH-03 §9가 소유한다. 문서 수준 값(문서 사용자 문자열)은 쓰지 않는다. jig는 자기 객체만 만들 수 있기 때문이다(SPEC-07.2). 연결 ID(ADR-030)는 문서와 VIDE 연결을 잇는 기존 값이며 이 jig가 쓰지 않는다.
- **원점:** 기본은 대상 대지 근처의 정수 m 기준점을 문서 원점에 둔다. 측량 좌표 그대로를 고르면 큰 좌표를 그대로 쓴다. 어느 쪽이든 기준점과 좌표계를 대지 정보에 남겨 다른 자료와 다시 맞출 수 있게 한다.
- **다시 만들기:** 다시 가져온 사본으로 다시 만들면 SPEC-07.12의 교체 규칙을 따른다. 사람이 고친 필지·건물은 보존한다.

## 6. 건축 가능 영역·매스: 입력 — SPEC-12.7

근거: FR-24·09·16, SPEC-07.5·07.6, SPEC-08.6, RESEARCH-04 J-04.

1. **대지:** 사이트 모델링의 출력(대지 경계, 도로, 인접 필지, 정북) 또는 Rhino 레이어의 입력 조립(역할: 대지 경계·도로 경계·인접 대지 경계·건축한계선·기타 이격 기준선). 정북은 정북 기준이 '사이트 모델링 따름'(기본)이고 이 프로젝트에 계산된 사이트 모델링 결과가 있으면 그 대지 요약의 정북 기준(진북·도북)과 격자 수렴각을 쓴다. 사람이 진북이나 도북을 고르면 그 선택과 도북 방향·격자 수렴각 설정값이 앞선다. 사이트 모델링 결과가 없으면 설정값(진북)으로 계산한다. 어디서 왔는지 결과에 적는다.
2. **규제 조건:** 아래 닫힌 목록의 항목이다. 값은 SPEC-13 법규 결과에서 받거나 사람이 넣는다. 항목마다 값, 단위, 적용 여부(적용 · 미적용 · 판단 필요), 근거 조항(원문 링크), 출처 구분, 확정 상태를 가진다.

   | 묶음 | 항목 |
   |---|---|
   | 밀도 | 용도지역(여럿이면 각 면적), 건폐율 상한, 용적률(기준·허용·상한) |
   | 높이 | 최고 높이, 가로구역 최고 높이, 고도지구 높이 |
   | 건축선 | 도로별 후퇴 거리, 가각 전제 길이, 건축한계선·지정선(그린 선) |
   | 이격 | 대지 안의 공지(건축선·인접 대지 경계선별 거리), 민법상 이격 거리, 기타 이격(그린 선 + 거리) |
   | 일조 | 정북 일조 적용 여부, 기준 높이, 기준 높이 이하 거리, 초과 부분의 높이 대비 비율, 기준선 위치(인접 대지 경계 · 도로 건너편 경계), 거리의 정의(기준선까지의 최단 거리 · 정북 방향으로 잰 거리) |
   | 인센티브 | 항목 이름, 완화량(용적률·높이), 조건, 근거, 공개공지 설치에 따른 완화량 |
   | 용도 | 허용 용도 목록, 층별 용도 제한 |
   | 주차·공지 | 용도별 주차 산정 기준('면적 n ㎡당 1대'의 n), 산정에 쓰는 면적, 끝수 처리와 그 단위, 주차 출입 제외 거리(모퉁이), 조경 면적 비율, 공개공지 대상 여부와 면적 비율 |

   설정값으로 담을 수 없는 항목(목록 값: 허용 용도·층별 용도 제한, 대상별 값: 용도별 주차 산정 기준·이름 붙은 인센티브)은 규제 조건 표에서 사람이 넣는다(수정 사항, 적용 여부와 근거 포함). 표의 값이 같은 항목의 설정값보다 앞서고, AI가 제안한 값은 사람이 받기 전에는 쓰지 않는다.

3. **계획 조건(설정값):** 주용도, 층고(1층·기준층·지하), 지하 층수, 지하 이격, 목표 용적률, 정북 기준(사이트 모델링 따름·진북·도북).
4. **비어 있으면 묻는다.** 주용도처럼 결과가 크게 갈리는 필수 값이 없으면 질문 카드로 묻는다(SPEC-02.19의 6). 기본값이 있는 값(층고 등)은 기본값으로 진행하고 '가정'으로 적는다.
5. **판단하지 않는다.** jig는 항목이 적용되는지, 값이 맞는지를 결론 내리지 않는다. 값이 들어오기 전의 항목은 모두 '사람 입력 필요'이고, 규칙에는 법정 값(일조 기준 높이·거리·비율, 민법 이격 거리 등)이 들어 있지 않다. '사람 입력 필요' 항목은 그 제한 없이 계산하고 '미반영 조건'으로 남긴다. '판단 필요' 항목은 미적용으로 계산하지 않고, 적용·미적용 두 경우를 모두 보이거나(일조·높이) 사람이 정할 때까지 그 제한 없이 계산하고 '미반영 조건'으로 목록에 남긴다. 일조 거리의 정의가 정해지지 않았으면 기준선까지의 최단 거리(정북 방향 거리보다 늘 작아 더 많이 깎는 쪽)로 계산하고 미확정 조건으로 센다. 법규 결과의 값은 사람이 넣은 값을 바꾸지 않고, 사람이 비워 둔 항목만 채우며 다른 값은 차이로 알린다.
6. **산식을 만들지 않는다.** 계산은 SPEC-12.8~12.12에 적은 규칙만 쓴다. 각 규칙은 위 항목의 값을 매개변수로 받는다. 목록에 없는 제한은 사람이 그린 선·영역과 거리로만 반영한다. AI가 새 계산식을 제안해도 jig에 들어가지 않는다.
7. **확정 상태와 만들기:** 계산은 언제나 돌고 미리보기를 보인다. 단계가 읽는 규제 조건에 '판단 필요'나 근거 없는 '가정'이 남아 있으면 그 단계 결과에 '미확정 조건 n개'를 붙이고, Rhino에 만들 때 객체 속성에도 같은 표시를 남긴다. 만들기 자체는 막지 않는다(탐색용 외피이기 때문). 고시 값처럼 기계로 읽을 수 없는 항목은 SPEC-12.16의 사람 투입 칸으로 받는다.

## 7. 2D 건축 가능 영역 — SPEC-12.8

근거: FR-24·10, RESEARCH-16 §2 1단계.

1. **제한선:** 다음 규칙마다 제한선을 따로 계산한다.
   - 건축선: 도로 경계에서 도로별 후퇴 거리만큼 대지 안쪽. 가각 전제 길이가 있으면 모퉁이 삼각형을 뺀다.
   - 건축한계선: 그린 선의 바깥쪽을 뺀다.
   - 대지 안의 공지: 건축선과 인접 대지 경계선에서 항목별 거리.
   - 민법상 이격: 인접 대지 경계선에서 거리.
   - 정북 일조(지면): 일조 기준선에서 '기준 높이 이하 거리'. 높이에 따른 사선은 3D에서 다룬다(SPEC-12.9).
   - 기타 이격: 그린 선에서 거리.
2. **인접 대지 경계는 실제 인접 필지로 나눈다.** 사이트 모델링 출력이나 입력 조립의 도로·인접 대지 경계가 있으면 대지 경계를 인접 필지·도로와 맞닿는 구간으로 나누어 어느 규칙이 어느 구간에 걸리는지 정한다. 같은 필지가 도로와 인접 대지 양쪽에 있으면(사이트 모델링의 주변 필지에는 도로 필지도 들어 있다) 도로로 본다. 구간 판정이 모호하면(틈·겹침이 허용 오차를 넘음) 그 구간을 표에 '확인 필요'로 남기고, 사람이 정할 때까지 도로·인접 대지 규칙을 걸지 않으며 '미반영 조건'에 둔다. 거리는 경계 **선분**에서 잰다(무한 직선 띠가 아님). 가각은 두 도로 구간이 만나는 볼록한 모퉁이에만 둔다.
   - **일조 기준선:** 사람이 그린 기준선이 있으면 그것을 쓴다. 없으면 바깥 법선이 정북 쪽을 향하는 구간을 고른다. 인접 대지 구간은 그 경계가 기준선이고, 도로 구간은 '기준선 위치' 항목대로(도로 건너편 경계면 도로 영역에서 잰 도로 너비만큼 바깥으로 옮김) 정하며, 그 항목이 비었거나 도로 너비를 찾지 못하면 그 구간의 일조는 '미반영 조건'이다. 정북은 SPEC-12.7의 1대로 정한다. 기준선을 고르는 규칙(바깥 법선이 정북 쪽으로 조금이라도 기울면 기준선)은 아직 법 해석이 정해지지 않았다: 바깥 법선이 정북과 80°보다 크게 벌어진(정북과 거의 수직인) 구간도 지금은 기준선으로 계산하되, 그 구간을 '판단 필요'로 미반영·판단 필요 조건 목록에 적고 미확정 조건으로 센다. 어느 방향 범위의 경계를 정북 쪽으로 볼지는 SPEC-13 결과나 사람이 정한다.
3. **가능 영역** = 대지 ∩ 모든 제한선의 안쪽. 같은 규칙·같은 거리의 이어진 구간이 거의 한 직선이면(끝점이 한 현에서 1 mm 안) 그 현에서 그 편차만큼 더 넓게 잰다(안전 쪽, 많아야 1 mm). 면적을 계산하고 건폐율 상한 면적과 비교한다. 가능 영역이 상한보다 크면 영역은 그대로 두고 '건축면적은 상한 n ㎡까지'를 보인다.
4. **결과 표:** 제한선별로 줄어든 면적, 걸린 경계 구간, 근거 조항, 출처를 보인다. 3D 겹침에서 제한선마다 색을 다르게 보인다.
5. **실패:** 대지 경계가 닫히지 않거나 스스로 교차하면 위치를 보이고 멈춘다. 가능 영역이 비면 "가능 영역 없음"과 가장 많이 줄인 제한선을 보인다.

## 8. 3D 가능 외피 — SPEC-12.9

근거: FR-24·10, RESEARCH-16 §2 2단계, RESEARCH-04 J-04.

1. **돌출 외피:** 2D 가능 영역(SPEC-12.8 3) 그대로를 높이 상한(최고 높이·가로구역·고도지구 가운데 가장 낮은 값, 없으면 '지상 층수 상한 × 층고'(1층 층고 + 기준층 층고 × (층수 − 1)))까지 돌출한다. 그것도 없으면 계획 조건의 '검토 높이'(법정 값이 아닌 계산 상한)까지 계산하고 '높이 상한 사람 입력 필요'를 '미반영 조건'에 남긴다.
2. **일조 사선 외피:** 일조 기준선으로부터의 수평 거리 d와 허용 높이 h의 관계(기준 높이 이하에서는 '기준 높이 이하 거리', 초과 부분은 '높이 대비 비율')로 만든 닫힌 폴리서피스. 기준선이 여러 구간이면 구간마다 만들고 합친다. 정북 기준을 바꾸면 다시 계산한다. d는 규제 조건 '거리의 정의'대로 잰다: 기준선 선분까지의 최단 거리이거나 그 점에서 정북 방향으로 기준선까지 잰 거리다. 어느 쪽이 법의 뜻인지는 법 해석이라 SPEC-13 결과나 사람이 정하며, 정해지기 전의 계산은 SPEC-12.7의 5를 따른다. 일조가 걸리는 구역(용도지역 걸침)이 주어지면 그 구역 안에서만 깎는다.
3. **최대 외피** = 돌출 외피 ∩ 일조 사선 외피 ∩ 높이 제한. 닫힌 폴리서피스.
4. **점검:** 모든 외피는 닫혀 있고 면 방향이 바깥이며 부피가 양수여야 한다. 실패하면 그 외피를 만들지 않고 단계를 '점검 실패'로 멈춘다. 닫힘 검사만 통과하고 뒤집힌 솔리드는 실패로 본다. Rhino에 만들 때도 같은 점검(한 조각, 닫힘, 바깥 방향, 엔진이 계산한 부피와의 일치)을 다시 하고, 통과하지 못한 외피는 만들지 않고 결과 카드의 '만들지 못함'에 보인다. 뒤집어서 고치지 않는다.
5. **결과:** 외피별 부피, 높이별 단면 면적, 일조 사선이 줄인 면적을 보인다. 외피는 '법정 최대치 추정'이며 계획 매스가 아니라고 표시한다.
6. **Rhino에 만들기:** 외피 종류별 레이어에 닫힌 폴리서피스로 만들고, 속성에 사용한 규칙·값·근거·출처와 미확정 조건 수를 남긴다.

## 9. 층·대안·인센티브 — SPEC-12.10

근거: FR-24·22·10, RESEARCH-16 §2 3단계.

1. **층 나누기:** 최대 외피를 층고로 잘라 층별 가능 바닥 윤곽과 면적을 만든다. 층은 1층 층고, 그 위는 기준층 층고로 쌓고 윗면이 외피 높이를 넘는 층은 만들지 않는다. 층 윤곽은 그 층 윗면 높이의 외피 단면이다(외피의 모든 규칙은 높이가 오를수록 더 깎기만 하므로, 그 윤곽을 층 높이만큼 돌출해도 외피 안에 든다). 외피가 '판단 필요' 항목으로 두 변형이면 적용 변형으로 나누고 그 사실을 적는다. 지하층은 대지 경계에서 '지하 이격'(설정값, 기본 0 m) 안쪽으로 계획 조건의 지하 층수만큼, '지하 층고'(설정값)로 만든다.
2. **대안 만들기(닫힌 목록):**
   - **최대:** 층별 가능 윤곽을 그대로 쓴다(참고용).
   - **기준 용적률:** 기준 용적률을 넘지 않도록 위층부터 덜어 낸다. 덜어 내는 방식을 설정값으로 고른다. '위층 축소'는 맨 위층부터 그 층의 산정 면적이 남은 초과분 이하이면 통째로 빼고, 남은 초과분은 다음 층을 정북 쪽에서 정북에 수직인 선으로 잘라 맞춘다. '층수 줄이기'는 위층부터 층을 통째로 뺀다. 외피가 먼저 막으면 그대로 두고 목표 대비 여유를 적는다.
   - **인센티브 반영:** 적용(또는 판단 필요)인 인센티브 항목의 용적률 완화량을 기준 용적률에 더한 목표로 같은 방식을 쓴다. 상한 용적률이 들어와 있으면 목표는 그 값까지다. 조건이 '판단 필요'인 항목은 반영하되 대안 이름과 표에 '조건 미확정'을 단다. 높이 완화량은 외피에 넣지 않고, 높이 상한에 더해 외피를 다시 계산하라고 적는다.
   - **공개공지 반영:** 공개공지 대상이고 후보가 있으면(5) 그 후보 위의 매스를 모든 지상층에서 뺀 윤곽에, 기준 용적률 + '공개공지 설치에 따른 완화량'(규제 조건 값)을 목표로 같은 방식을 쓴다. 완화량이 없으면 기준 용적률만 쓰고 그 사실을 적는다.
   - **사람 수정:** 층별 윤곽을 수정 사항(SPEC-07.8, 대안 `사람 수정 k`와 층마다 윤곽·구멍 지정 또는 층 빼기)으로 고치거나 Rhino에서 고친 매스를 받는다(SPEC-07.13). 출발 대안은 설정값이다. 외피 밖으로 나간 윤곽은 표에 '외피 밖'으로 보이고 막지 않는다.
   한 작업본의 대안은 8개까지다. 넘는 대안과 값이 없어 만들지 못한 대안(예: '기준 용적률 사람 입력 필요')은 이유와 함께 목록으로 보인다.
3. **대안 표:** 대안마다 건축면적(지상층 윤곽 합집합의 면적)·건폐율, 연면적(지상·지하), 용적률 산정 면적·용적률, 층수, 높이, 상한 대비 여유를 보인다. 건폐율은 건폐율 상한 면적과, 용적률은 들어온 용적률 값 가운데 가장 느슨한 것(상한 → 허용 → 기준)과 비교한다. 상한을 넘으면 '초과'로 판정하고 흐름은 막지 않는다(SPEC-07.2의 판정). 들어온 값이 없으면 '상한 없음'이다.
4. **면적 산정 제외:** 발코니·필로티·주차 등 용적률 산정 제외 면적은 1차에 층별 '제외 면적' 값으로 사람이 넣고 근거를 적는다(수정 사항, 근거가 비면 '근거 없음'). jig가 제외 여부를 판단하지 않는다. AI가 낸 제외 면적은 사람이 받기 전에는 쓰지 않는다.
5. **공개공지:** 공개공지 대상이면 필요 면적(공개공지 면적 비율 × 대지면적)을 계산하고, 사람이 그린 영역 또는 대지 모서리 후보 영역을 2D로 보이며, 설치안별 면적과 관련 인센티브의 완화량을 표로 보인다. 모서리 후보는 도로 구간에 닿는 볼록 모퉁이에서 두 변을 따라 같은 길이 s(s² × sin θ = 필요 면적)로 잡은 평행사변형을 대지로 자른 것이다. 표는 면적과 필요 면적만 비교하고, 위치 요건(도로 접면, 후퇴 부분 산입 등)은 판단하지 않는다. 대안에 쓸 후보는 설정값(표의 번호, 0이면 그린 영역 → 필요 면적을 채우는 첫 모서리 후보)이다. 대상 여부·비율이 비면 '사람 입력 필요'로 두고 공개공지 반영 대안을 만들지 않는다.
6. **인센티브 설명:** 항목의 뜻과 조건은 SPEC-13 결과의 문장과 근거 링크를 그대로 보인다. jig가 설명 문장을 새로 쓰지 않는다.
7. **고른 대안:** 사람이 설정값 '고른 대안'으로 대안 하나를 정하고 사람 단계 [고른 대안 확정]으로 확정한다. 건축개요 jig는 이것만 읽는다. 확정은 대안 표와 그 설정값에 대한 것이라, 고른 뒤 대안(덜어 내는 방식·규제 조건·수정 사항 등)이 바뀌면 다시 확인 필요다. 확정 전에는 고른 대안이 없다.
8. **Rhino에 만들기:** 대안마다 층별 매스(층 단위 닫힌 돌출, 구멍 포함, 지하층 포함)를 대안 레이어에 만든다. 속성에 대안 이름·층·면적·용도·미확정 조건 수를 둔다.

## 10. 용도 배분 — SPEC-12.11

근거: FR-24·22, RESEARCH-16 §2 4단계.

- 층(또는 층 면적의 비율)마다 용도를 정하는 표가 설정값이다(수정 사항: 모든 대안의 그 층, 또는 한 대안의 그 층에 용도 하나나 비율 합 1인 용도 목록). 기본은 모든 층(지하층 포함)이 주용도다. 주용도가 미정이면 '주용도 미정'으로 두고 판정은 '미검토'다.
- AI는 용도 배분 초안을 낼 수 있다(AI 단계, SPEC-07.7, 꺼진 상태로 시작). 초안은 사람이 받아야 표에 들어간다: 초안을 보이는 사람 단계 [AI 초안 받기]를 확정하면 초안의 층별 용도가 사람의 수정 사항(출처 'AI 초안을 사람이 받음', 같은 층은 바꿔 씀)으로 기록된다. 대안에 없는 층이나 용도가 빈 행은 받지 않고 목록으로 보인다. AI 표시가 남은 수정 사항은 표에 넣지 않는다. 초안은 용도만 담고 면적·대수를 담지 않는다.
- 규제 조건의 허용 용도 목록·층별 용도 제한과 대조해 맞지 않는 층을 '초과', 조건이 '판단 필요'면 '미검토'로 판정한다. 아무도 넣지 않은 목록도 '미검토'다(기본으로 '적합'이 되지 않음). 용도 법규의 설명은 SPEC-13 결과를 링크로 보인다.
- 결과: 대안별 용도 면적표(지상·지하·합계·용적률 산정 면적), 3D 겹침의 용도별 색. Rhino에 만들 때 층별 매스의 속성에 용도를 남긴다.

## 11. 주차와 대지 안의 공지 — SPEC-12.12

근거: FR-24·22, RESEARCH-16 §2 5단계.

1. **법정 주차 대수:** 대안마다 용도별 면적과 규제 조건의 산정 기준·끝수 처리로 계산한다. 산정 기준은 '면적 n ㎡당 1대' 꼴만 받는다(용도별 값 n, 모든 용도에 하나를 넣을 수도 있음). 다른 꼴(세대당 등)은 계획 대수로 넣는다. 산정에 쓰는 면적(용도별 바닥면적 합계 · 용적률 산정 면적), 끝수 처리(0.5 이상 올림 · 올림 · 버림)와 그 단위(용도별 값을 합한 뒤 한 번 · 용도마다)도 규제 조건 항목이고, 하나라도 비면 끝수 처리 전 값만 보이고 대수는 '사람 입력 필요'로 비운다. 계획 대수는 설정값이다. 기준이 '판단 필요'인 용도는 대수를 비우고 '미검토'로 두며 합계도 비운다. 기준이 '미적용'인 용도는 0대다.
2. **조경·공지 면적:** 법정 면적은 기준 비율 × 대지면적이다. 계획 면적은 사람이 그린 영역의 면적(대지 안, 겹친 부분은 한 번)이다. 비율이 비면 법정 면적은 '사람 입력 필요'다. 공개공지는 필요 면적(SPEC-12.10 5)과 그 대안이 비운 후보의 면적을 나란히 보인다.
3. **주차 진입 가능 구역(2D):** 접도 구간에서 사람이 그린 제외 구간과 규제 조건의 제외 거리(교차로 모퉁이 등)를 뺀 선분을 보인다. 제외 거리는 두 도로 구간이 만나는 볼록 모퉁이에서 양쪽 구간을 따라 잰다. 그린 제외 선은 도로 구간 위(구간 허용 오차 안)에 놓인 선이 덮는 부분을 뺀다. 제외 거리가 비면 모퉁이를 빼지 않고 '미반영 조건'으로 남긴다.
4. **공지 확인(3D):** 공지·조경 영역을 지면에 표시하고 매스를 투명하게 겹쳐 VIDE 뷰포트에서 본다. Rhino에는 영역 곡선(진입 가능 구간, 지상 여유, 조경, 공개공지)만 만든다.
5. **주차 방식 대안(닫힌 목록: 지상 자주식 · 지하 자주식 · 기계식):** 설정값으로 고른 대안 하나에 대해, 방식마다 '대당 필요 면적'(설정값, 계획 값이며 0이면 '사람 입력 필요') × 대수(계획 대수가 있으면 그것, 없으면 법정 대수)로 필요 면적을 구한다. 지상 자주식·기계식은 지상 여유 면적(대지 − 건축면적 − 그 대안의 공개공지 − 그린 조경 영역)과 비교하고, 지하 자주식은 지하 한 층 면적(대지 − 지하 이격)으로 나눠 올림한 층수를 계획 지하 층수와 비교한다. 지상 여유는 2D 영역으로, 추정 지하층은 Rhino에 닫힌 돌출로 보인다. 주차 구획·차로의 상세 배치는 하지 않는다.

## 12. 건축개요 — SPEC-12.13

근거: FR-24·14·22, AC-20·34, SPEC-07.11, RESEARCH-16 §2 6단계, RESEARCH-04 S-03(사무소 건축개요 표의 항목 구성)·S-04.

1. **입력:** 매스 jig의 고른 대안(사람이 [고른 대안 확정]을 한 뒤의 결과, 작업본·대안·계산 시각과 함께), 대지 요약(사이트 모델링, 없어도 됨), 그 대안의 규제 조건, 사람이 적는 항목(건물명·공사종별·구조·주차 방식·비고). 앞 작업본은 이 프로젝트에서 가장 최근에 계산된 것을 기본으로 읽고, 사람이 다른 작업본을 고를 수 있다. 고른 대안이 없거나 앞 작업본이 '다시 계산 필요'이면 개요를 만들지 않고 이유를 보인다. 대지 요약이 없으면 대지 위치·지역·지구·공부 면적·도로 칸은 '사람 입력 필요'다. 이 jig가 개요를 계산한 뒤 앞 결과가 바뀌면 '다시 계산 필요'를 보인다(SPEC-07.5의 6).
2. **건축개요 항목(사무소 표의 순서):** 건물명, 대지 위치(주소·PNU), 지역·지구, 대지면적(공부·계산 — 하나로 합치지 않음), 공사종별, 주용도, 규모(지상·지하 층수), 도로 현황, 건축면적, 연면적(지상·지하·합계), 용적률 산정 연면적, 건폐율(계획·법정), 용적률(계획·법정 기준·허용·상한), 높이(계획·법정 최고 높이, 들어온 가로구역·고도지구·층수 상한), 대지 안의 조경(법정·계획), 공개공지(대상·필요 면적·계획), 주차(법정·계획·방식), 구조, 비고. 각 칸은 값, 면적이면 평(㎡ × 121/400, 참고), 출처(SPEC-12.14의 짧은 글자), 법정 값이면 확정 상태와 근거 조항·링크, 그리고 어느 앞 결과에서 왔는지를 보인다. 값이 없으면 '사람 입력 필요', 적용하지 않는 항목은 '미적용'이다. 건축면적·연면적·용적률 등 숫자는 앞 jig가 계산한 값을 옮기기만 하고 이 jig가 새로 계산하거나 법정 값을 정하지 않는다.
3. **층별 면적표:** 층(지하는 깊은 층부터, 이어 지상 1층부터), 용도, 바닥면적, 산정 제외 면적, 용적률 산정 포함 면적, 평, 비고(제외 근거·축소·외피 밖·용도 판정), 그리고 지상 합계·지하 합계·합계.
4. **일관성:** 개요의 숫자 칸은 모두 고른 대안·규제 조건·대지 요약에 있는 값이어야 하고(`numbers-in-source`, 칸의 숫자 자체로 대조), 칸의 글자와 평은 그 값에서 쓴 것이어야 한다. 층별 면적의 합은 지상·지하·합계 줄과 개요의 연면적과 같고, 층별 산정 포함 면적의 합은 용적률 산정 연면적과 같으며, 층 수는 규모와 같아야 한다. 하나라도 맞지 않으면 개요·층별 면적표를 내보내지 않고(CSV 표가 비고 보고서 저장·인쇄가 꺼짐) 다른 칸(칸 · 보인 값 · 맞아야 할 값 · 이유)을 보인다. 아직 점검하지 않았을 때도 내보내지 않는다.
5. **미확정 표시:** 고른 대안에 미확정 조건(판단 필요·가정 항목, 미반영 조건, 조건 미확정 인센티브)이 있으면 개요 머리에 "미확정 조건 n개"와 목록을 싣는다. '사람 입력 필요' 칸도 첫 쪽의 검토하지 않은 항목에 싣는다(SPEC-07.11의 첫 쪽 규칙).
6. **내보내기:** 자체 포함 HTML 보고서와 CSV 두 개(건축개요, 층별 면적표)다. 그 밖의 형식(XLSX·HWPX)은 OQ-08을 따르고 1차에는 만들지 않는다.
7. AI 다듬기는 SPEC-07.11의 규칙대로 선택이고 한 번뿐이다. 숫자를 바꾸지 않는다(1차 틀은 다듬기를 쓰지 않음).

## 13. 출처 구분 — SPEC-12.14

근거: FR-09, AC-14, PRD §6.3, ARCH-01 §「외부 도메인 서비스」.

| 구분 | 이 jig에서의 예 | 함께 남기는 것 |
|---|---|---|
| 원본에서 읽음 | 공공 자료의 필지 경계·지목·용도지역·건물 층수, 넣은 SHP | 자료원·레이어·원 식별자·조회 시각 |
| 도구로 계산함 | 계산 면적, 도로 폭, 추정 높이, 제한선, 외피, 대안 면적 | 규칙 이름·입력·설정값 |
| 사용자가 확정함 | 대상 필지, 규제 조건 값의 확정, 고른 대안, 제외 면적 | 누가·언제·근거 |
| AI가 추정함 | 용도 배분 초안, 입력 역할 제안 | 확정 전에는 사실로 쓰지 않음 |

- 법규 결과에서 받은 항목은 SPEC-13이 붙인 출처 구분과 근거를 그대로 옮긴다: 출처 구분은 '서비스 확정'(서비스에서 사람이 확인한 값, 확정 상태 '확정') 또는 '서비스 해석'(확인하지 않은 값, 확정 상태 '가정')이고, 근거 조항과 원문 링크, 어느 법규 답에서 왔는지를 함께 둔다(SPEC-13.8). 법규 결과의 '판단 필요'는 확정 상태도 '판단 필요'다. 일조 값을 준 답은 정북 일조 적용 여부 항목에도 그 답의 적용 여부를 준다. 법규 결과의 수치 가운데 규제 조건 항목에 대응하지 않거나 단위가 다른 것은 '연결 안 된 제한'으로 보이고 아무 항목도 채우지 않는다.
- 건축개요(SPEC-12.13)의 출처 열은 사무소 표에 맞춘 짧은 글자를 쓴다: 계산(도구로 계산함), 공부(원본에서 읽음 — 공공 자료·넣은 SHP), 사람 입력(사용자가 확정함 — 매스 jig나 이 jig에서 사람이 넣은 값), 법규 결과(SPEC-13 결과를 그대로 옮긴 값 — 서비스 확정·서비스 해석). 값이 없는 칸은 '사람 입력 필요'다.
- 공부 면적과 계산 면적처럼 출처가 다른 값은 하나로 합치지 않고 나란히 보인다.
- AI 추정은 사람이 받기 전에 확정으로 바뀌지 않는다(AC-14).
- 보고서의 출처 줄에 자료 조회 시각, 규제 조건 수(확정·가정·판단 필요), 설정값 근거 현황을 둔다(SPEC-07.11).

## 14. AI가 하는 일 — SPEC-12.15

근거: FR-25·24, SPEC-07.18, ADR-026.

- **한다:** 말로 jig 열기(SPEC-07.18), 대상 필지·주용도 등 모호하거나 빈 것을 질문 카드로 묻기, Rhino 레이어의 입력 역할 제안(SPEC-07.5), 용도 배분 초안, 보고서 한 번 다듬기, 대화에서 대지 요약·대안 표·외피 결과를 읽고 설명하기.
- **하지 않는다:** 좌표·형상 만들기, 규제 조건의 적용 여부·값 결론, 계산식 추가, 대상 필지 확정, 고른 대안 지정, 수집 결과 고치기, Rhino에 만들기. 이것들은 코드·법규 결과·사람의 몫이다.

## 15. 실패와 사람 투입 — SPEC-12.16

근거: FR-16·18, SPEC-07.17, RESEARCH-04 J-03·J-04.

- **자료원 실패**(키 없음·거절·한도·응답 형식 다름·네트워크 끊김): 그 자료만 '가져오지 못함'과 이유를 보이고 마지막 사본은 유지한다. SHP 넣기 또는 사람 입력을 안내한다. 대상 필지 경계가 없으면 뒤 단계를 막는다. 자동으로 다른 자료원에 보내지 않는다.
- **모호한 필지:** 질문 카드(SPEC-12.3의 2).
- **좌표계 판별 실패:** 그 자료를 빼고 이유를 보인다(SPEC-12.4).
- **기계로 읽을 수 없는 고시:** 지구단위계획의 결정도·결정조서, 가로구역별 최고 높이 지침도, 건축한계선·지정선처럼 그림이나 스캔본으로만 있는 값은 '사람 입력 필요' 칸으로 보인다. 사람은 값을 적거나 선을 그리고, 근거 문서를 프로젝트 자료(SPEC-08)의 진술로 잇는다. 입력 전에는 그 제한 없이 계산하고 '미반영 조건'으로 남긴다.
- **법규 결과 없음:** SPEC-13 결과가 없으면 규제 조건을 사람 입력으로 받고 '법규 결과 없음'을 보인다. 나중에 결과가 오면 값이 다른 항목만 알리고 자동으로 바꾸지 않는다(SPEC-07.6의 근거의 변화).
- **기하 실패**(자기 교차, 폐합 실패, 빈 영역): 그 단계에서 멈추고 위치와 이유를 보인다(SPEC-07.17).
- **만들기 실패:** SPEC-07.17을 따른다.
