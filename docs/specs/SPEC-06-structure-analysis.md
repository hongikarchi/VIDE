# 구조 분석 jig

## 설계 중인 강구조를 계획 단계에서 스스로 검토한다 — SPEC-06.8

근거: PRD FR-23·AC-40, [ADR-019](../decisions/ADR-019-structure-jig-rust-core.md). **설계자는 CAD 도면이나 Rhino 모델로 받은 강구조를 해석 모델로 바꾸고, 부재가 대략 적정한지와 어디가 부족한지를 근거와 함께 빠르게 확인한다. 배치가 바뀔 때마다 구조사무소와 왕복하기 전에 스스로 1차 판단을 내리는 것이 목적이다.**

사용자는 JIG 탭에서 구조 분석을 열고 입력(Sync한 CAD 도면, Rhino 부재 솔리드, Rhino 중심선 곡선 중 하나 이상)을 고른다. AI가 해석 모델 초안을 만들고 코드가 점검한다. 사용자는 3D 미리보기와 표에서 부재 역할·단면·지점·접합·하중을 확인하고 고친 뒤 확정한다. 확정한 모델을 해석하면 부재마다 검정비·지배 조합·근거 조항·판정이 표와 뷰포트 색으로 나온다. 부족한 부재를 누르면 모델에서 찾아가고, 부족 원인이 부재 크기인지 입력·하중 의심인지 구분해 본다. 입력을 고치면 이전 결과는 오래된 것으로 표시된다.

**완료 기준:** 실제 Rhino 또는 CAD 입력 하나 이상에서 초안 → 점검 → 확정 → 해석·검정 → 결과 표시·모델 찾아가기가 이어지고, 검증 시험 자료(ARCH-02 §6)가 통과해야 한다. 결과 화면에는 항상 "탐색용 예비값 — 구조계산서·구조기술사 최종 검토를 대체하지 않음"과 검토하지 않은 항목이 보여야 한다(AC-40). 합성 예제만 되거나 표만 나오는 상태는 완료가 아니다.

## 1. 입력과 해석 모델 초안 — SPEC-06.1

근거: FR-23·03·18. 입력 형태는 프로젝트마다 다르다. 지원 입력은 다음과 같다.

| 입력 | 코드가 먼저 하는 일 | AI가 맡는 일 |
|---|---|---|
| Rhino 중심선 곡선 | 꺾인 곡선을 선분으로 나누고 끝점을 병합, 기울기로 기둥·보·가새 후보 판정 | 레이어·이름·속성의 의미 해석, 역할이 애매한 부재, 단면 지정 |
| Rhino 부재 솔리드(Brep) | 솔리드에서 축과 단면 치수를 추출해 단면표와 대조 | 불규칙 형상, 접합부 덩어리 분리, 단면 판정 |
| CAD 도면(ZWCAD Sync) | 선·레이어·문자 읽기 | 그리드·부재 부호를 부재와 단면에 연결, 일람표 해석 |

결과는 입력 형태와 무관하게 하나의 **해석 모델 초안**(ARCH-02 계약)이다. 초안의 항목(절점·부재·단면·지점·접합·하중)마다 출처를 **자동 / AI / 사용자** 중 하나로 기록한다. AI가 근거 없이 정한 값은 "가정"으로 표시한다. 초안 작성은 저장된 Sync만 읽으며 호스트 원본을 바꾸지 않는다. 여러 입력을 함께 쓰면 좌표 관계(단위·원점·회전)를 먼저 맞추며, 관계가 불확실하면 사용자에게 묻는다.

## 2. 모델 점검 — SPEC-06.2

근거: FR-23·10. 확정 전에 코드가 모델을 점검하고 항목별로 보인다.

- 허용오차 안에 가까이 붙은 절점, 중복 부재, 길이 0 부재. 병합 허용오차는 사용자에게 보이며, 병합·제거한 목록을 남긴다.
- 지점 없음, 기구(불안정) 자유도. 불안정하면 해당 절점·자유도를 뷰포트에 표시한다.
- 단면·재료 미지정 부재, 단위 이상(예: 부재 길이가 모두 수천 m).
- 접합 규칙과 다른 단부(§4).

점검 오류가 남으면 확정할 수 없다. 경고는 확정할 수 있으나 결과에 함께 표시된다.

## 3. 확정과 유효성 — SPEC-06.3

근거: FR-23·16. **사용자가 확정하기 전에는 해석하지 않는다.** 확정은 모델 전체를 한 번에 확인하는 행동이며, 확정한 모델과 입력 Sync의 기준 버전을 함께 저장한다. 입력 Sync·모델·하중·조건이 바뀌면 이전 결과를 "오래된 결과"로 구분하고 다시 확정·해석하게 한다. 결과를 지우지는 않는다.

## 4. 접합(단부) 규칙 — SPEC-06.4

근거: FR-23, RESEARCH-08 §4.1. 부재 단부 조건은 부재 종류가 아니라 **무엇에 붙는가**로 정한다. 기본 규칙은 다음과 같고 프로젝트마다 바꿀 수 있다.

- 보·거더의 단부가 기둥에 붙으면 강접.
- 작은 보가 큰 보(거더)에 붙는 단부는 핀.
- 가새는 양단 핀(인장 전용 여부는 선택).
- 기둥 하단은 핀(주각 조건은 선택).

예외는 부재·단부 단위의 예외표로 관리하며 출처(사용자·구조사무소 표시 등)를 남긴다. 해석 뒤 강접인데 단부 모멘트가 거의 0이거나 핀인데 단부 모멘트가 있으면 경고한다.

## 5. 하중과 해석 조건 — SPEC-06.5

근거: FR-23. 하중은 면하중(실·영역별 고정·활하중), 선하중, 집중하중, 자중으로 입력한다. 값마다 출처(하중표 / 가정)를 표시한다. 하중 패턴의 성격(고정·활·적설·풍·지진)이 조합 생성의 입력이다.

**기본 해석 조건은 계획 단계 중력 검토**다: 조합 1.2D+1.6L, 선형 정적 해석. 사용자는 조합을 추가·수정할 수 있다. 수평 거동을 빼고 중력 결과만 보기 위한 수평 구속(예: 지붕 레벨 기둥 상단 X·Y 구속)은 선택이며, 켜면 구속 반력 합계를 "횡력 시스템이 받아야 할 힘"으로 보인다. 풍·지진·전체 조합·2차 해석(P-Δ)을 포함한 최종 점검 모드는 후속 범위이며, 이번 범위에서는 "검토하지 않음"으로 표시한다.

## 6. 부재 검정 — SPEC-06.6

근거: FR-23. 강재 부재는 KDS 14 31 10 체계로 검정한다: 압축, 휨(횡비틀림좌굴·Cb 포함), 전단, 휨·축력 조합, 세장비. 압축과 휨을 함께 받는 기둥은 확대 모멘트(B1)를 적용하고 장주·단주 구분을 보인다. 처짐은 사용자가 정한 한계(기본 L/240·L/360 등, 부재 역할별)로 판정한다.

비지지 길이·유효좌굴길이계수 K·Cb는 부재마다 **자동값과 사용자 덮어쓰기**를 함께 가지며, 자동값은 "가정"으로 표시한다. 재료 상수·강종 항복강도(두께별)·단면 성질의 출처를 기록한다.

부재 판정은 네 상태로 나눈다: **통과 / 실패 / 미완(입력 부족으로 검정 못 함) / 오류(계산 실패)**. 일부 검사만 통과했다고 전체를 통과로 보이지 않는다. 각 판정에는 검정비, 지배 조합, 근거 조항, 중간값(세장비, 한계 길이, 공칭 강도 등)을 붙인다.

## 7. 결과와 NG 원인 — SPEC-06.7

근거: FR-23·10·14. 결과는 다음을 포함한다.

- 부재 표: 부재·역할·단면·길이·검정비·지배 조합·조항·판정·처짐. 정렬·필터와 행 선택 시 뷰포트에서 찾아가기.
- 뷰포트 색: 미판정(회색) / 통과(< 0.7) / 주의(0.7~1.0) / 초과(≥ 1.0)와 판정 불가를 구분한 색.
- 요약: 강재 중량(t)·면적당 중량, 최대 검정비, 실패 부재 수, 점검 경고 수.
- **NG 원인 분류**: 실패 부재마다 "부재 부족"과 "입력·모델 의심"(하중 합계 불일치, 가정값이 지배, 점검 경고와 관련, 비정상 크기)을 구분해 보인다.
- 검토하지 않은 항목 목록(횡력·접합부·기초·EJ 등)과 "탐색용 예비값 — 구조계산서·구조기술사 최종 검토를 대체하지 않음".

결과 표는 파일(CSV)로 내보낼 수 있다. 결과를 호스트에 반영(예: 부재 색·속성 기록)하는 것은 사용자가 요청할 때만 기존 수정 경로의 권한·검증으로 한다.

## 8. 실패와 보호 — SPEC-06.9

근거: FR-16·18. 해석이 실패하면(불안정, 계산 오류) 원인과 관련 절점·부재를 보이고 입력·이전 결과를 보존한다. 계산 코어는 입력 모델 외의 파일·네트워크·호스트에 접근하지 않는다. AI에는 모델 초안 작성과 결과 설명을 위해 필요한 표·요약만 보내며, 결과 설명은 표에 있는 부재·수치만 인용한다(없는 부재를 인용하면 경고). 사용자 원본 문서는 반영 요청 없이 바뀌지 않는다.

## 9. 후속 범위(이번 범위 밖)

배치 → 구조 자동 생성 규칙, 수직 가새·지붕 수평가새 배치 규칙과 다이어프램 판정 시험, 최종 점검 모드(풍·지진·전체 조합·P-Δ·모드 해석), 부재 편집 재검토와 영향 전파(예: 기둥 제거 검토), 대안 간 강재량 비교·단면 최적화, 계산서·부재 일람표 문서, 프로젝트별 선택 내보내기(예: midas MGT), EJ·기초 검토. 필요한 근거는 RESEARCH-08 §3·§4.1에 있다.
