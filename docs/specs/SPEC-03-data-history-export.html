00 / 변경 근거를 확인하고 표·검토본으로 전달한다 — SPEC-03.8

근거: PRD §6·§8.7·§12.4·§12.6, FR-09·12·14·16·22. 설계자는 형상이 바뀐 이유와 수치 변화를 확인하고, 주요 상태를 남겨 비교·전달한다. AI와 별개로 직접 조회·표 갱신을 사용할 수 있다.

대상에서 근거로, 표에서 대상으로

객체를 선택하면 관련 입력·유지 조건·사용한 자료·AI가 가정한 내용·생성/수정 작업을 확인한다. 예를 들어 늘어난 경계에서 “왜 이 선까지 늘렸는가”를 열면 원래 스케치와 채택한 지시가 나온다. 반대로 그 의견을 열면 해당 경계와 후보를 찾을 수 있다. 대상의 법적 용도나 건축적 의미가 입력되지 않았으면 미확정으로 남긴다.

기본 표를 만들고 변경 뒤 갱신한다

설계자는 선택 객체 또는 지정 문서/레이어 범위를 집계 대상으로 고르고, 유형·레이어별 개수·길이·기하 면적을 표로 만든다. 표의 행을 선택하면 계산한 대상을 찾고, 값을 열면 단위·원본/계산/사용자/AI 출처와 계산 기준을 확인한다. “이 경계들의 면적을 비교해 줘”라는 요청도 같은 계산 기능을 사용하며 AI가 숫자를 추측하지 않는다.

필터 조건을 저장하면 다음 Sync 기준에서 다시 계산할 수 있다. 원본/후보는 별도 대상으로 선택해 수정 전후 차이를 확인한다. 새 객체가 필터에 들어오거나 기존 객체가 빠지면 대상 집합 변화도 재계산 사유가 된다. 객체 값이 그대로여도 이전 대상 목록만 재사용하지 않는다. 계산/미상/환산 규칙은 §5를 따른다.

주요 시점을 남기고 전달한다

설계자는 현재 모델·도면·표·결정을 ‘수정 전’, ‘검토 후보’, ‘반영 후’ 등의 검토본으로 남긴다. 두 검토본을 고르면 보존된 표현과 표를 열고 추가/삭제/변경/비교 불가를 확인한다. 한쪽 호스트만 적용된 시점도 그대로 기록된다. 과거본 열람은 현재 모델을 되돌리는 행동이 아니다.

전달할 때는 선택한 표를 재사용 가능한 데이터 파일로, 선택한 작업과 검토본을 사람이 읽는 검토 요약으로 내보낸다. 요약에는 무엇을 요청했고 무엇이 달라졌으며 무엇이 미검토인지가 담긴다. 같은 결과를 웹에 공개하려면 SPEC-04의 공개 범위를 따로 적용한다.

완료 기준: 실제 후보 수정으로 달라진 수량을 근거와 함께 확인하고, 이후 원본이 바뀌어도 이전 검토본을 열며, 선택한 기준과 같은 내용의 표/요약 파일을 외부 도구에서 사용할 수 있어야 한다(AC-12·14·20·34·36). 빈 표나 미리 입력한 예제 숫자로 완료하지 않는다. 세부 보존/내보내기 규칙은 §2·3·6을 따른다.

01 / 조회와 근거 — SPEC-03.1

근거: FR-09·22. 원본 속성, 계산값, 사용자 입력, AI 추정을 구분한다. 결과는 객체·문서·취득 기준·단위에 연결한다. 개수, 유형·레이어별 그룹, 지원되는 길이·기하 면적을 조회하고 조건을 저장해 새 동기화 기준으로 다시 계산한다. 알 수 없는 값은 0으로 합산하지 않고 제외 건수를 표시한다. 서로 다른 단위는 검증된 환산 이후에만 합산한다. 기하 면적을 법정 면적이라고 표시하지 않는다.

02 / 기록과 검토본 — SPEC-03.2

근거: FR-12·16. 입력·실행·후보·적용·저장의 이력을 관계로 보존한다. 검토본은 지정 시점에 확인한 자료와 문서별 기준을 고정하며 이후 동기화가 기존 검토본을 바꾸지 않는다. 비교는 동일성을 확인한 대상끼리 수행하고 추가·삭제·변경·비교 불가를 구분한다. 검토본은 네이티브 파일 전체 복원 기능이 아니다.

03 / 내보내기 — SPEC-03.3

근거: FR-14·18. 재사용 가능한 표 데이터와 사람이 읽는 검토 요약을 구분해 내보낸다. 포함 자료·기준·단위·불확실성을 표시한다. 비밀 설정·인증 정보·내부 절대 경로는 포함하지 않는다. 텍스트를 실행 가능한 스크립트나 스프레드시트 수식으로 해석하지 않게 처리한다. 파일 형식 선정과 실제 열람 호환성은 PLAN §4·7 및 OQ-08에서 다룬다.

04 / 관계와 의존성 — SPEC-03.4

근거: FR-09·12·22. 지원 관계는 입력→참조 대상, 실행→입력 버전, 후보→원본 기준, 지표→계산 대상/방법, 검토본→포함 결과, 게시 의견→게시본이다. 포함·레이어·그룹 등의 호스트 관계는 호스트 지원표에서 확인된 것만 사실로 읽는다. 공간적으로 가깝다는 이유만으로 경계·연결 관계를 확정하지 않는다.

값에는 출처(원본/계산/사용자 확정/AI 추정)와 역할(현재 사실/가정/필수조건/참고)을 별도로 둔다. 근거에서 관련 대상을, 대상에서 근거·조건·지표를 조회한다. 수정된 입력을 참조한 결과만 오래됨으로 표시하고, 의존성 확인 불가이면 유효하다고 가정하지 않는다. 이전 계산 결과는 근거와 함께 보존한다.

05 / 조회·집계·갱신 — SPEC-03.5

근거: FR-09·22. 첫 기본 질의는 프로젝트 내 문서/객체 유형/레이어/출처 필터, 유형·레이어별 그룹, 개수·지원 길이·기하 면적 합계다. 지원하지 않는 값은 미상이며 빈 결과(0개)와 읽기 실패를 구분한다. 집계 대상은 원본/후보를 명시적으로 선택하며 기본 원본 집계에 후보를 중복 포함하지 않는다. 필터·그룹 정의를 저장하고 기준을 바꿔 재계산한다. AI를 호출하지 않는다.

길이와 면적을 같은 열에서 합산하지 않는다. 단위 환산은 차원을 확인하고 면적에는 제곱 환산을 적용한다. 단위 미지정·열린 경계·비평면·지원 밖 형상의 면적은 미상 사유와 제외 건수를 표시한다. 계산은 표시 반올림 이전 값으로 수행한다. 표에는 사용한 기준과 유효/오래됨/확인 불가를 표시한다.

‘표 갱신’은 선택된 IDE 취득 기준으로 재계산한다. 호스트 최신 상태가 필요하면 먼저 수동 Sync를 제시한다. 계산 실패는 마지막 성공 표를 유지한다. 관련 변경이 있는 상태로 내보낼 때는 오래된 기준임을 명시한다.

06 / 검토본·비교·내보내기 상세 — SPEC-03.6

근거: FR-12·14·16·18. 검토본은 제목·작성 시각, 문서별 기준, 선택 입력과 결정, 표시 자산, 표와 계산 정의, 후보·적용·저장 상태를 고정한다. 자산이 누락되면 불완전함을 표시하고 없는 모델을 재현했다고 주장하지 않는다. 과거 검토본 열람은 현재 호스트를 변경하지 않는다.

비교는 두 기준을 고르고 동일성이 확인된 객체의 추가·삭제·형상/속성 변경을 표시한다. 참조 끊김·불완전 취득·지원 밖 관계는 비교 불가다. 전체 변경량 0으로 합치지 않는다. 두 기준의 단위·표 계산 정의가 다르면 환산/동일 기준 재계산 가능 여부를 먼저 확인한다.

내보내기 전 포함 자료·기준·개인 의견 포함 여부를 미리 확인한다. 표는 값뿐 아니라 단위·출처·미상 이유와 기준을 보존하고, 검토 요약은 목표·결정·결과·미검토·호스트별 적용/저장·참조 기준을 포함한다. 파일 생성 성공과 외부 프로그램 열람 검수는 별개다. 파일 형식은 OQ-08의 검토안(CSV·자체 포함 HTML)으로 남기며 외부 호환성 시험 후 지원을 선언한다.

08 / 객체 변경·계산 재사용·체크포인트 — SPEC-03.9

근거: FR-09·12·16·22. 객체 형상·속성·관계의 변경과 작업 근거를 구분해 기록한다. 체크포인트 사이에도 관측한 추가·수정·삭제를 편집 작업 단위 요약으로 확인할 수 있다. 모든 드래그 중간 상태의 전체 복원을 약속하지 않는다. 외부 편집·오프라인 구간의 정확한 편집자·순서를 알 수 없으면 관측 사실과 불확실성을 표시한다. 변경 감지는 화면 기준의 자동 Sync나 AI 전송을 뜻하지 않으며 SPEC-01의 수동 Sync 계약을 유지한다.

변경 기록·캐시 갱신·체크포인트 생성 자체를 위해 AI 호출을 요구하지 않는다.

수량은 계산에 사용한 형상·단위·조건과 함께 보존하고 유효한 결과를 재사용한다. 무관한 속성 변경으로 형상 계산을 반복하지 않는다. 변경됐거나 계산 기준이 달라진 입력의 결과는 오래된 것으로 구분하고 필요한 계산만 수행한다. 표시 메시 재사용도 실제 형상 기준에 연결한다.

체크포인트는 모델·속성·관계·표 정의·근거의 버전을 함께 가리킨다. 여러 문서 기준이 서로 다른 시각에 취득됐으면 동시 원자 스냅샷으로 표시하지 않는다. 과거 모델을 최신 속성/표와 혼합해 과거 상태로 보여 주지 않는다. 복원 가능한 네이티브 자료가 없으면 열람/비교만 가능한 범위를 표시한다.

보관한 네이티브 파일을 별도 사본으로 열어 과거 자료를 확인한다. 삭제된 객체는 그 객체가 포함된 보관 시점의 자료에서 열람한다. 과거 상태를 현재 원본으로 되돌리는 기능·삭제 객체 자동 복원·자동 병합·고급 분기는 PRD §14.2 및 FR-20의 후속 범위다. 현재 후보 적용(SPEC-02)과 과거 상태 복원을 혼동하지 않는다. 버전 기록은 백업을 대체하지 않는다.
