# ZWCAD 호스트 계약과 검증 범위

사용자 지정 시험 버전은 현재 설치본 ZWCAD 2023, 실행 파일 버전 23.20.3.11이다. ProgID `ZWCAD.Application.2023`을 레지스트리에서 확인하고 새 시험 인스턴스의 COM API로 검증했다. 이는 제품용 .NET 어댑터의 빌드·로드·UI 문맥 검증을 대체하지 않는다.

| ID | 계약·확인 범위 | 확인한 증거 | 한계 |
|---|---|---|---|
| H-ZWCAD-01 | 합성 닫힌 LWPolyline 생성·복사 후보·이동·후보 삭제 | 새 문서 ModelSpace에서 객체 수·길이·좌표 비교 | 블록·외부참조·프록시·일반 3D 객체 미시험 |
| H-ZWCAD-02 | 시험 객체 색상 보존 | 후보 폐기·원본 이동·DWG 재열기 후 Color 유지 | 레이어·확장 데이터·구속조건·그룹 관계 미시험 |
| H-ZWCAD-03 | mm 단위·이동 기하·Handle 저장 지속성 | INSUNITS=4, 저장 후 HandleToObject 조회 및 좌표 확인 | 다른 문서의 같은 Handle은 동일 객체가 아님; 단위 환산 미시험 |

근거는 [호스트 실험](../../tdd/SPIKE-2026-09-19-host-native.md)이다. 실사용 연결에서 활성 문서를 실행 대상으로 암묵 선택하지 않는다. 문서별 명령 직렬화와 트랜잭션·문서 잠금 검수는 T-003·006에서 수행한다. 현재 결과를 IDE 다중 연결·기본 편집 도구 재편집·설치 지원 통과로 집계하지 않는다.

## 첫 사용자 작업의 지원 검토안

근거: SPEC-01.9·10, SPEC-02.12~14, FR-02·03·04, OQ-03·10. 아래는 **구현 목표 제안**이며 위의 실험 확인 행과 다르다. 사용자가 공간 입력→후보 조정→원본 반영→호스트 재편집을 수행할 대상으로 제시한다. 폴리라인 실험 통과를 입체·연계·전체 지원 완료로 확대하지 않는다.

| ID | 제안 동작 | 읽기·보존 계약 | 후속 편집·저장 검수 | 실증 전 제한 |
|---|---|---|---|---|

| H-ZWCAD-04 | 직선 세그먼트의 평면 LWPolyline 읽기·생성·정점 변경·이동·반복 복사 | 문서 범위 Handle·정점·닫힘·Elevation/Normal·단위·Layer·Color; 선언 속성 유지 | 그립/기본 폴리라인 편집·이동, DWG 저장/재열기 | COM 실험 외 .NET 제품 어댑터와 기본 도구 재편집 미검증 |
| H-ZWCAD-05 | CAD 경계를 연계 입력으로 읽고 동일 작업의 경계 수정 후보 생성 | 원 경계/후보의 문서·객체·기준과 좌표·단위·대응 유지 | Rhino 입력에서 같은 경계 확인; CAD 반영 뒤 기본 도구 편집 | 호스트 간 실제 연계 미검증. bulge 호·블록·Xref·프록시를 직선 경계로 몰래 변환하지 않음 |

위 지원안의 기본 평면은 알려진 단위와 문서 기준 좌표를 사용한다. 문서 간 원점/축/단위 변환은 사용자가 확인한 값으로 적용한다. 잠김·참조·공유 정의·미확인 관계가 있는 객체는 범용 수정 대상으로 포함하지 않고 이유를 표시한다. 이는 전체 MVP의 지원 상한 확정이 아니며, 첫 완결 과업을 실증할 구체안이다.

후보는 생성 시 원본 대응과 소유 정보를 기록하고 결과를 재조회한다. 기존 객체 수정은 복사 후보에서 먼저 검사하며, 적용 시 원본의 선언 속성·관계 보존을 확인한다. 보존을 확인할 수 없는 경우 임의 삭제/재생성으로 성공을 위장하지 않는다. 실험 뒤 행별 확인 증거·미지원 조건을 채워 지원 선언과 구분한다.

## 실제 제품 연결의 현재 증거

[작업 공간 검증](../../tdd/VERIFY-2026-09-20-native-workspace.md)에 브라우저 → 구독 CLI → ZWCAD의 닫힌 LWPolyline 생성·저장·재열기 및 CAD 경계를 Rhino Extrusion의 입력으로 쓴 실증이 있다. 실제 면적 200m²·돌출 체적 1,200m³와 DWG 다운로드를 확인했다. 시험 문서는 기존 사용자 문서와 분리했다. 현재 평면 폴리라인 작업 사본에 한정하며 기존 DWG 원본 적용·일반 CAD 객체·전체 연계 완료로 확대하지 않는다.

## DWG 참고 입력 확인 — 2026-09-21
H-ZWCAD-04 중 직선 XY LWPolyline 읽기를 ZWCAD 2023에서 확인했다. 업로드한 바이트의 고유 복사본을 읽기 전용으로 열고 mm 단위 경계 20×10 m의 정점·닫힘·Elevation·Normal·Handle·레이어·색·길이/면적을 읽는다. 원 파일 해시는 유지됐다. 확인한 수치는 길이 60 m·면적 200 m²이며 참고 핀을 통해 Rhino 높이 3 m 후보(체적 600 m³)로 연결했다.
참고 DWG 자체를 후보 편집/원본 적용하는 기능은 아직 지원하지 않는다. 모델 공간에 지원 밖 객체나 호 세그먼트가 있으면 일부 객체만 성공으로 취득하지 않고 거절한다. 다른 단위·블록·참조/구속관계·실무 도면 전체는 후속 검수다. [실증 기록](../../tdd/VERIFY-2026-09-20-native-workspace.md)의 실행 환경과 불명확 시험 기록을 함께 따른다.

## DWG 작업 사본 경계 수정 — 2026-09-21

H-ZWCAD-04·05의 일부로, 새로 취득한 독립 직선 XY LWPolyline의 이동·정점 수정 후보를 실제 ZWCAD 2023에서 검증했다. mm 단위, 그룹·확장 사전·XData·잠긴 레이어·선폭·두께가 없는 확인된 객체에 한정한다. 이름·객체 집합·Handle·레이어·색상을 유지하고 새 DWG 사본에서 수정한다. 20×10 m를 24×10 m로 수정해 240 m²·68 m를 재열기 확인했고 후속 이동도 통과했다. 원본 파일 적용, 추가·삭제·복사, 다른 단위·관계·일반 CAD 객체는 미지원이다. 앞 절의 참고 전용 제한은 능력 확인이 없는 이전 취득과 지원 밖 도면에 계속 적용된다. [실제 검증](../../tdd/VERIFY-2026-09-20-native-workspace.md).

## 설치 SDK 실험 — 2026-09-22

[ZWCAD SDK 실험](../../tdd/SPIKE-2026-09-22-zwcad-sdk.md)에서 설치된 공식 .NET DLL의 빌드·소유 시험 실행본 로드, 별도 Database/Transaction의 합성 경계 생성·저장·재열기를 확인했다. 활성 사용자 문서를 사용하지 않고 면적 200 m²·길이 60 m·mm·Handle·색을 대조했다. 위 첫 COM 실험과 구분되는 SDK 증거이며, 제품 범용 SDK 실행·기본 도구 재편집·열린 원본 적용·다중 문서 완료를 뜻하지 않는다.

## 자체 SDK DWG 가져오기 — 2026-09-22

제품의 DWG 읽기는 소유한 별도 ZWCAD 2023 실행본의 자체 .NET 애드인으로 전환했다. 사용자가 업로드한 고유 사본을 별도 Database로 읽고, 활성 사용자 문서/COM 활성 인스턴스에 붙지 않는다. 기존 읽기 지원 범위와 편집 능력 판정은 유지한다. 브라우저에서 20×10 m DWG의 표시·객체 선택, 200 m²·60 m·Handle·원본 해시 보존을 확인했다.

단위 미상/곡선 bulge는 거절하고 잠긴 레이어 및 m 단위 직선 경계는 정확한 단위 환산으로 표시하되 기존 정점 편집 능력을 부여하지 않는다. 근거는 [SDK 제품 이식 검증](../../tdd/VERIFY-2026-09-22-typescript-foundation.md)이다. 생성·수정은 아직 기존 COM 제품 경로이며 범용 SDK AI 편집은 실험에 머문다.
