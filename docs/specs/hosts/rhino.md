# Rhino 호스트 계약과 검증 범위

사용자 지정 시험 버전은 현재 설치본 8.34.26223.11001이다. 아래 표는 네이티브 실험으로 확인한 출발 범위이며 IDE 연결·실행·기본 도구 재편집까지의 제품 지원 완료 선언이 아니다. 근거는 [호스트 실험](../../tdd/SPIKE-2026-09-19-host-native.md)이다.

| ID | 계약·확인 범위 | 확인한 증거 | 한계 |
|---|---|---|---|
| H-RHINO-01 | 합성 평면 폴리라인 생성·복사 후보·이동·후보 삭제 | RhinoCommon에서 네이티브 객체를 생성·변환·삭제하고 길이·위치 비교 | 일반 곡선·솔리드·참조 객체·이력 관계는 미시험 |
| H-RHINO-02 | 시험 객체의 Name·사용자 문자열 보존 | 후보 분리·이동·3DM 재열기 후 사용자 문자열 유지 | 기존 레이어·그룹·블록·렌더 속성까지 일반화하지 않음 |
| H-RHINO-03 | mm 단위·이동된 기하·객체 식별자의 저장 지속성 | 저장 후 새 headless 문서에서 GUID로 조회, 좌표·단위 확인 | 다른 단위 환산·문서 간 복사·분할/합침 동일성은 미시험 |

제품 어댑터는 프로세스 인스턴스와 문서 런타임 식별자를 연결에 고정해야 한다. 재열기·재연결 시 저장된 경로나 GUID 하나만으로 이전 명령을 재전송하지 않는다. headless 실험은 화면 선택·작업 평면·수동 Sync·사용자 편집 중 충돌을 대체하지 않는다. 그 범위는 T-003·005에서 실제 연결로 검수한다.

## 첫 사용자 작업의 지원 검토안

근거: SPEC-01.9·10, SPEC-02.12~14, FR-02·03·04, OQ-03·10. 아래는 **구현 목표 제안**이며 위의 실험 확인 행과 다르다. 사용자가 공간 입력→후보 조정→원본 반영→호스트 재편집을 수행할 대상으로 제시한다. 폴리라인 실험 통과를 입체·연계·전체 지원 완료로 확대하지 않는다.

| ID | 제안 동작 | 읽기·보존 계약 | 후속 편집·저장 검수 | 실증 전 제한 |
|---|---|---|---|---|

| H-RHINO-04 | 평면 PolylineCurve 읽기·생성·정점 변경·이동·반복 복사 | 객체 GUID·점열·닫힘·단위·Name·Layer·사용자 문자열; 기존 객체 수정 시 선언 속성 유지 | 호스트 기본 이동·제어점 편집, 3DM 저장/재열기 | 기초 실험의 생성/이동 외 정점 편집·레이어·실사용 연결은 추가 검증 |
| H-RHINO-05 | 닫힌 평면 경계로 수직 돌출 후보 생성·지원 후보의 높이/경계 변경 | 네이티브 Extrusion을 우선 검토; 불가하면 대체 유형을 별도 제안. 입력 경계·높이·축·닫힘·원본 대응 보존 | 실제 Extrusion 유형/닫힘 확인, 호스트 기본 도구 후속 편집과 저장/재열기 | 실제 CLI→XY 스케치→Extrusion 저장/재열기 실증 있음(아래 증거). 생성 기준 없는 임의 솔리드의 파라메트릭 높이 편집으로 일반화 금지 |

위 지원안의 기본 평면은 알려진 단위와 문서 기준 좌표를 사용한다. 문서 간 원점/축/단위 변환은 사용자가 확인한 값으로 적용한다. 잠김·참조·공유 정의·미확인 관계가 있는 객체는 범용 수정 대상으로 포함하지 않고 이유를 표시한다. 이는 전체 MVP의 지원 상한 확정이 아니며, 첫 완결 과업을 실증할 구체안이다.

후보는 생성 시 원본 대응과 소유 정보를 기록하고 결과를 재조회한다. 기존 객체 수정은 복사 후보에서 먼저 검사하며, 적용 시 원본의 선언 속성·관계 보존을 확인한다. 보존을 확인할 수 없는 경우 임의 삭제/재생성으로 성공을 위장하지 않는다. 실험 뒤 행별 확인 증거·미지원 조건을 채워 지원 선언과 구분한다.

## 실제 제품 연결의 현재 증거

[작업 공간 검증](../../tdd/VERIFY-2026-09-20-native-workspace.md)에 브라우저 채팅·핀·스케치에서 실제 구독 CLI와 Rhino까지 연결한 결과가 있다. 3dm 파일은 별도 작업 사본으로 가져오며 네이티브 형상·속성을 유지한 이동을 수행한다. 이 증거는 현재 유한 기하 명령과 시험 객체에 한정하며 전체 지원 계약의 완료나 원본 문서 적용으로 확대하지 않는다. 실행 경로·업로드/객체 상한·기술 구현은 PLAN이 소유한다.


### 생성 후보 적용의 추가 증거

생성된 박스 후보를 식별된 열린 Rhino 문서에 반영하고, 후속 후보로 높이를 수정하면서 네이티브 GUID와 무관한 객체를 보존했다. 원본/후보 변경 검사를 거치며 파일 저장은 별도다. 범위는 VIDE가 생성·소유한 박스/폴리라인/돌출 객체이며 가져온 임의 원본 객체 수정과 일반 속성/관계 보존 지원으로 확대하지 않는다. 실제 수치·검수 코드는 [작업 공간 검증](../../tdd/VERIFY-2026-09-20-native-workspace.md)의 생성 후보 적용 절을 따른다.


### 열린 문서 취득의 추가 증거

명시한 문서 인스턴스에서 원본 상태를 유지한 작업 사본 취득을 연결했다. 취득 시각·원본 단위·문서 대응을 기록하며 현재 상태는 미확인으로 표시한다. 합성 솔리드·점 2개를 취득하고 원본 형상/속성·이름·경로·저장 상태·선택 보존을 확인했다. Point의 3D 표시 미지원은 화면에 표시한다. 상세 증거는 [작업 공간 검증](../../tdd/VERIFY-2026-09-20-native-workspace.md)의 열린 문서 취득 절에 있다.


### 취득 원본의 이동 적용 증거

같은 문서 취득 기준에서 만든 이동 후보를 원본에 반영하고 GUID·공개 스칼라 속성·사용자 문자열·무관한 형상 보존을 확인했다. 적용 후 원본 지문이 달라지므로 취득 전 후보를 다시 적용하지 않는다. 지원은 그룹/이력/참조/잠김/블록 관계가 없는 검증 대상 형상의 이동에 한정하며, 일반 삭제·파라메트릭 편집·사용자 플러그인 관계 보존으로 확대하지 않는다. 자세한 성공·실패 증거는 [작업 공간 검증](../../tdd/VERIFY-2026-09-20-native-workspace.md)의 취득 원본 이동 적용 절을 따른다.
