# 패널링

근거: 2026-10-08 사용자 지시 "패널링부터 계획 세워서 진행해줘"로 PRD C-07을 채택했다. 사용자 메모([RESEARCH-16](../research/RESEARCH-16-domain-services-roadmap.md) §4): 패널링은 작업 흐름의 이해가 중요하지만 프로젝트·사람마다 다르다. 입력은 기준 면·패턴·패널 크기·줄눈 논리이고, 모자란 정보는 사람에게 되물어 가며 구성한다. 단계는 ① 패턴을 3D로 빠르게 보는 미리보기(mesh·surface) → ② 실제 부재 크기·두께·줄눈(mesh·polysurface) → ③ 부재 최적화·평면화·타입화와 결합부 타입화이며 단계마다 입력과 출력이 다르다.

이 명세는 공식 jig '패널링'(J-07)이 Rhino 곡면 위에 패널을 나누고, 부재로 만들고, 타입으로 묶어 Rhino에 만들고 표로 내는 동작만 정한다. jig 공통 동작(작업본·입력 조립·설정값·단계·만들기·보고서)은 [SPEC-07](SPEC-07-jig-platform.md), 물리 계약(면 읽기 형식·만들기 틀·저장)은 [ARCH-03](../architecture/ARCH-03-jig-runtime.md)과 `src/contracts/paneling.ts`, 화면은 [Design](../../Design.md) SCR-33, 구현 순서·시험은 [PLAN-49](../plans/PLAN-49-paneling.md)가 소유한다. 과거 경험(S-06 브릿지 패널링 GH 정의, Wireify 원장, S-12 `rhino-easy-panelling`)은 [RESEARCH-04](../research/RESEARCH-04-jig-past-experience.md) §J-07이 정리하며, 그 코드와 프로젝트 자료는 참고만 하고 복사하지 않는다.

제품 범위: PRD §14.2의 '패널링' 행(C-07, 2026-10-08 채택).

## 곡면을 나누고, 부재로 만들고, 타입으로 묶는다 — SPEC-16.1

근거: FR-24·10·22, C-07. **설계자는 Rhino의 기준 면을 골라 패턴·크기만 정하면 바로 3D 미리보기를 보고, 두께·줄눈을 더해 실제 부재를 만들고, 평면도·타입 수를 맞춰 일람표와 함께 Rhino에 만든다. 모양 계산은 코드가 하고, 정해지지 않은 입력은 되물으며, 실패한 패널은 빼지 않고 보고한다.**

1. **열기:** JIG 목록의 '패널링'을 열거나 대화에서 "이 면 패널로 나눠 줘"처럼 말한다(SPEC-07.18). 대화로 열면 모자란 입력을 질문 카드로 묻는다(SPEC-16.4).
2. **기준 면 고르기:** 사람 단계다. 연결 Rhino 문서에서 면을 고르고 [고른 면 쓰기]를 누르면(SPEC-01.11의 선택 반영) VIDE가 그 면을 읽어 작업본에 고정한다(SPEC-16.3).
3. **1단계 미리보기:** 패턴·크기·방향을 바꾸면 AI 없이 바로 다시 계산되어 VIDE 뷰포트에 패널 면과 수·크기 범위가 보인다.
4. **2단계 부재:** 두께·줄눈·두께 방향·가장자리 규칙·판재 한도를 정하면 패널마다 닫힌 부재와 줄눈 선, 부재 크기 표가 나온다.
5. **3단계 최적화·타입화:** 평면도 허용 오차·타입 허용 오차·최대 타입 수를 정하면 평면화, 패널 타입·결합부 타입, 일람표, 펼친 재단 윤곽이 나온다.
6. **Rhino에 만들기:** 단계마다 사람이 [Rhino에 만들기]를 누를 때만, 연결 문서에 되돌리기 기록 하나로 만든다(SPEC-16.9).
7. **내보내기:** 패널·타입·결합부 일람표(CSV)와 보고서(HTML)를 낸다(SPEC-16.11).

**완료 기준(1차):** `.vide/` 아래 합성 이중 곡면(약 5천 패널)에서 기준 면 고르기 → 1단계 사각·엇갈림·마름모·삼각 패턴 미리보기 → 2단계 두께·줄눈 부재 → 3단계 평면화·타입(최대 타입 수 지킴)·결합부 타입·일람표·평면 패널 재단 윤곽까지 이어지고, 각 단계의 [Rhino에 만들기]가 숨은 Rhino 8에서 되돌리기 한 번으로 지워지며, 실패 패널이 실패 레이어와 보고서에 나와야 한다. 고정 예제에서만 되거나, 실패를 조용히 빼거나, 추천값을 사람이 확인하지 않은 채 부재를 만드는 상태는 완료가 아니다.

## 1. 단계와 입력·출력 — SPEC-16.2

근거: RESEARCH-16 §4 표, RESEARCH-04 §J-07, SPEC-07.7.

단계는 고정된 세 단계이며 순서대로 이어진다(자유 노드 배선 없음, PRD §14.2 제외 항목). 앞 단계의 입력이 바뀌면 뒤 단계 결과는 '다시 계산 필요'가 되고 저절로 지워지지 않는다.

| 단계 | 입력(설정값) | 출력 | 형상 |
|---|---|---|---|
| 1. 미리보기 | 기준 면, 패턴, 패널 크기(가로 × 세로), 크기를 재는 법, 방향·시작 모서리, 경계 처리 | 패널 목록(번호·격자 위치·면 위 꼭짓점·경계 여부), 패널 수, 크기 범위(최소·최대 가로·세로·면적), 실패 패널 | 열린 면 또는 메쉬 |
| 2. 부재 | 1단계 결과, 패널 두께, 두께 방향(바깥·안), 줄눈 폭, 줄눈 위치(격자선 가운데·패널 안쪽으로), 판재 한도(선택) | 패널마다 닫힌 부재, 줄눈 선, 부재 크기 표(펼친 크기·두께·면적·무게 선택), 판재 한도 초과 목록 | 닫힌 폴리서피스 또는 닫힌 메쉬 |
| 3. 최적화·타입화 | 2단계 결과, 평면도 허용 오차(mm), 평면화 방법, 타입 허용 오차(mm), 최대 타입 수(선택), 곡률 등급 경계 | 패널별 평면도와 평면화 뒤 이격, 패널 타입(번호·수·대표 치수·최대 편차), 곡률 등급(평면·단곡·복곡), 결합부 타입(꼭짓점 노드·모서리 줄눈), 일람표, 평면 패널의 펼친 재단 윤곽과 번호 | 타입별 부재(블록), 결합부 표식, 재단 윤곽 |

- 패턴(1차): 사각 격자, 엇갈림(벽돌), 마름모(사각을 45° 돌린 격자), 삼각. 육각·보로노이·비주기 타일·사람이 그린 타일은 후속이다(SPEC-16 「범위 밖」).
- 크기를 재는 법: '면 위 길이'(기본, 등각 현 길이로 이소커브를 따라 나눔), '매개변수 같은 간격', '평면 또는 입면에 투영한 격자'. 이것은 프로젝트마다 다르므로 묻는다(SPEC-16.4).
- 경계 처리: '자르기'(기본, 기준 면의 경계·트림으로 잘린 부분 패널), '이웃에 합치기'(잘린 패널의 면적이 정한 비율 미만이면 옆 패널에 합침), '빼기'(빠진 패널은 수와 위치를 보고).
- 판재 한도를 넣으면 2단계가 한도를 넘는 패널을 나누지 않고 '판재 초과'로 표시한다. 자동으로 더 잘게 나누는 것은 1단계 크기를 사람이 바꿔서 한다.

## 2. 기준 면 — SPEC-16.3

근거: FR-03·24, SPEC-01.11, SPEC-07.5, ADR-030.

1. **받는 것:** 연결 Rhino 문서 하나(Link ID, ADR-030)의 서피스·폴리서피스 면이다. 한 폴리서피스의 여러 면을 고를 수 있고, 면마다 따로 나눈다(면 사이 패널을 잇지 않음, 후속). 메쉬·SubD 기준 면은 1차에서 받지 않고 '메쉬 기준 면은 아직 받지 않습니다 · Rhino에서 서피스로 바꾸세요'를 보인다.
2. **읽는 것:** 면마다 매개변수 영역, 정한 간격의 매개변수 격자에서 점·법선·주곡률 두 값과 방향, 트림 안 여부, 경계 곡선을 고른 간격으로 나눈 점, 문서 단위와 m 환산 비율, 그 면의 형상 지문이다. 정확한 형식은 `src/contracts/paneling.ts`의 `SurfaceSample`이고, 읽는 경로(연결 Rhino의 공식 읽기 틀 또는 숨은 Rhino 워커)는 PLAN-49 T-250 실험으로 정한다.
3. **언제 읽는가:** [고른 면 쓰기]를 누를 때와 [다시 읽기]를 누를 때뿐이다. 읽은 표본은 작업본의 입력 사본이 되고, 설정값을 바꿔도 Rhino를 다시 부르지 않는다. Live Sync로 그 면의 지문이 바뀌면 '기준 면이 바뀜 · 다시 읽기'를 보이고 결과는 '다시 계산 필요'다(저절로 다시 읽지 않음).
4. **미리보기와 만들기의 정밀도:** 미리보기·부재·타입 계산은 읽은 표본에서 한다(표본 사이는 보간). Rhino에 만들기는 면 ID와 패널의 매개변수 좌표를 넘겨 Rhino가 원래 면에서 다시 계산한다(SPEC-16.9). 표본 보간과 실제 면의 차이는 만들 때 패널마다 재어 보고에 넣는다.
5. **실패:** 면을 찾지 못함, 단위를 모름, 면이 너무 작음(패널 하나보다 작음), 읽기 시간·크기 한도 초과는 각각 이유와 함께 읽기 실패이며 앞의 표본을 지우지 않는다.

## 3. 되묻기와 값의 출처 — SPEC-16.4

근거: ADR-026 §4, SPEC-07.6, AC-14, RESEARCH-16 §4 '되물어 가며 구성'.

1. **묻는 입력:** 아래는 프로젝트·사람마다 달라서 작업본에 값이 없으면 묻는다.

   | 단계 | 묻는 입력 | 추천값(카드에 먼저 보이는 값) |
   |---|---|---|
   | 1 | 기준 면 | 없음 — 사람 단계 '기준 면 고르기' |
   | 1 | 패턴 | 사각 격자 |
   | 1 | 패널 크기 | 1,200 × 600 mm |
   | 1 | 크기를 재는 법 | 면 위 길이 |
   | 1 | 방향·시작 모서리 | 면의 U 방향, 매개변수 최소 모서리 |
   | 1 | 경계 처리 | 자르기 |
   | 2 | 두께, 두께 방향 | 50 mm, 바깥(면 법선 쪽) |
   | 2 | 줄눈 폭, 줄눈 위치 | 10 mm, 격자선 가운데 |
   | 3 | 평면도 허용 오차 | 3 mm |
   | 3 | 타입 허용 오차, 최대 타입 수 | 2 mm, 제한 없음 |

2. **묻는 방법:** 대화로 열었으면 대화 제공자의 질문 기능, 없으면 VIDE 질문 카드로 한 번에 그 단계의 빠진 값만 묻는다(ADR-026 §4). jig 화면에서는 값이 없는 칸에 '물어볼 것' 표지와 추천값을 회색으로 보인다.
3. **추천값은 '가정'이다.** 1단계는 미리보기를 빨리 보이려고 빈 값을 추천값으로 채워 계산하고 그 값마다 '가정' 표지를 붙인다. 2·3단계 계산도 같은 방식으로 볼 수 있지만, **부재(2단계)·타입(3단계)을 Rhino에 만들려면 그 단계와 앞 단계의 모든 입력이 사람 입력 또는 사람이 받은 값이어야 한다**(SPEC-07.12 8의 확정 조건에 대응하는 `paneling-confirmed`). 1단계 미리보기 만들기는 가정 값으로도 할 수 있고 객체에 `vide-assumed` 속성을 단다.
4. **값의 출처:** 모든 설정값은 출처를 가진다 — 사람 입력, 추천값(가정), 질문 카드에서 사람이 고름, 프로젝트 자료(SPEC-08 근거 연결), AI 제안을 사람이 받음. AI는 값을 제안할 수 있으나(SPEC-07.7의 초안 단계) 받기 전에는 계산에 들어가지 않는다.
5. 질문을 건너뛰거나 닫아도 작업은 멈추지 않고 그 값은 '가정'으로 남는다.

## 4. 1단계 미리보기 — SPEC-16.5

근거: RESEARCH-04 §J-07(UV 등분·패턴 매핑), ARCH-03 §13.

1. **배치:** 패턴 셀을 면의 2D 영역(크기를 재는 법에 따라 면 위 길이로 편 영역, 매개변수 영역, 또는 투영 평면)에 놓고 면으로 옮긴다. 줄눈은 2단계에서 2D 영역에서 먼저 줄인 뒤 옮긴다(3D에서 줄이지 않음).
2. **패널 번호:** `P-<행>-<열>`(면이 여럿이면 `F<면>-P-<행>-<열>`). 같은 입력이면 같은 번호다. 번호는 일람표·Rhino 속성·화면이 함께 쓴다.
3. **경계:** 트림 밖 셀은 버리고, 경계에 걸친 셀은 경계 처리 규칙대로 한다. 잘린 패널은 '경계 패널'로 표시한다. 합치기로 만든 패널은 합친 원래 번호를 함께 둔다.
4. **결과:** 패널 수(전체·경계), 크기 범위, 면적 합, 매개변수 왜곡이 큰 곳(목표 크기와 ±15% 넘게 다른 패널 수)을 머리에 보인다. 목표와 다른 패널은 뷰포트에서 색으로 구분한다.
5. **시간:** 설정값을 끄는 동안의 다시 계산은 패널 5천 개까지 ARCH-03 §13의 `live` 목표를 따른다. 넘으면 손을 뗄 때만 다시 계산하고 '패널이 많아 손을 뗄 때 계산합니다'를 보인다.

## 5. 2단계 부재 — SPEC-16.6

근거: RESEARCH-04 §J-07(두께 오프셋·안전 한계), SPEC-07.12 8.

1. **줄눈:** 줄눈 위치가 '격자선 가운데'면 패널 윤곽을 2D 영역에서 줄눈 폭의 반만큼 안으로 줄이고, '패널 안쪽으로'면 줄눈 폭만큼 줄인다. 줄인 뒤 면으로 옮긴다. 줄눈 선은 이웃 패널 사이 가운데 선이다.
2. **두께:** 패널 면을 두께 방향으로 두께만큼 띄워 닫힌 부재를 만든다. 곡률 반지름이 작아 두께를 띄우면 면이 꼬이는 곳(두께 ≥ 0.7 ÷ 최대 곡률)은 그 패널을 '두께 불가 · 곡률 반지름 r mm'로 실패 처리한다.
3. **부재 크기:** 패널마다 펼친 가로·세로(평면이면 실제 크기, 곡면이면 경계 길이 기준 근사이며 '근사'를 적음), 두께, 면적, 부피. 판재 한도를 넣었으면 한도 초과 패널 목록.
4. **닫힘:** 부재는 닫히고 바깥을 향해야 한다. 아니면 그 패널은 실패이고 뒤집거나 메워 고치지 않는다.

## 6. 3단계 최적화·타입화 — SPEC-16.7

근거: RESEARCH-04 §J-07(곡률 타입·군집), PLAN-49 T-250·T-256.

1. **평면도:** 네 꼭짓점 이상의 패널마다 꼭짓점과 최적 평면 사이 최대 거리(mm)다. 삼각 패널은 늘 0이다.
2. **평면화(1차 방법 '패널별 최적 평면'):** 평면도가 허용 오차 이상인 패널을 그 최적 평면으로 옮긴 평면 패널로 바꾸고, 이웃 패널과 벌어진 최대 틈(mm)을 함께 보고한다. 전체 그물을 함께 움직이는 평면 사각 최적화(PQ)는 후속이며(PLAN-49 T-259), 방법 목록에 보이되 '준비 중'이다.
3. **곡률 등급:** 패널 가운데의 가우스 곡률·평균 곡률로 평면·단곡·복곡을 정한다. 등급 경계는 설정값이고 기본은 곡률 반지름 100 m 이상을 평면으로 본다.
4. **패널 타입:** 같은 등급 안에서 자세와 무관한 모양 지문(정렬한 모서리 길이와 대각선, 곡면이면 곡률 반지름을 정한 간격으로 반올림)이 타입 허용 오차 안이면 같은 타입이다. 돌린 것은 같은 타입, 거울상은 다른 타입이다. 최대 타입 수를 넣었으면 그 수 이하가 되도록 묶고, 그 결과 대표와의 편차가 허용 오차를 넘는 패널은 '허용 오차 넘음'으로 표시한다(조용히 맞추지 않음). 타입 번호는 `T-01`부터 수가 많은 순이다.
5. **결합부 타입:** 꼭짓점마다 만나는 패널 수와 모서리 사이 각, 모서리마다 이웃 패널 사이 꺾인 각(°)과 줄눈 길이를 잰다. 노드는 만나는 수와 각을 정한 간격(기본 1°)으로 묶어 `N-01`…, 모서리 줄눈은 꺾인 각 구간과 길이로 묶어 `J-01`…로 타입을 정한다. 위상은 패널 모서리의 연결에서 구하며 거리 근사로 구하지 않는다.
6. **재단 윤곽:** 평면(또는 평면화한) 패널은 자기 평면을 XY로 옮겨 펼친 윤곽과 번호를 낸다. 단곡·복곡 패널의 펼침은 후속이며 일람표에 '펼침 없음 · 곡면'으로 둔다.
7. **일람표:** 패널 표(번호·타입·등급·펼친 가로·세로·면적·평면도·평면화 틈·실패), 타입 표(타입·수·대표 치수·최대 편차·등급), 결합부 표(노드 타입·수·만나는 수·각, 줄눈 타입·수·각 구간·길이 합).

## 7. 3D 보기 — SPEC-16.8

근거: SPEC-07.10, Design SCR-33.

- 1단계 패널은 VIDE 뷰포트에 면(채운 삼각형)과 윤곽선으로 그린다. 기울어진 면을 그리려면 jig 겹침의 '메쉬' 종류가 필요하며 SPEC-15와 함께 쓴다(PLAN-49 T-253).
- 색은 단계에 따라 목표 크기 대비 편차(1단계), 판재 초과·실패(2단계), 타입·곡률 등급·평면도(3단계)로 고를 수 있다. 일람표 행을 누르면 그 패널을 고르고 화면을 맞춘다.
- 겹침은 Rhino 문서에 쓰지 않는다. Rhino에 쓰는 것은 [Rhino에 만들기]뿐이다.

## 8. Rhino에 만들기 — SPEC-16.9

근거: SPEC-07.12·07.13, ADR-022, ADR-020, ARCH-03 §9.

1. **단계마다 하나:** [미리보기 만들기](1단계 패널 면), [부재 만들기](2단계 부재와 줄눈 선), [타입 만들기](3단계 타입별 블록 정의와 놓기, 결합부 표식, 재단 윤곽과 번호). 각각 사람이 누를 때만 연결 문서에 되돌리기 기록 하나로 만든다. 같은 문서에 대한 AI 편집·다른 만들기와 대기열을 공유한다(SPEC-07.12 9).
2. **공식 틀:** 데이터 한 덩어리만 넘기며 호스트 코드 문장을 만들지 않는다(SPEC-07.12 1). 패널 면은 기준 면 ID·면 번호·매개변수 좌표로 넘겨 Rhino가 원래 면에서 만든다. 틀 이름과 데이터 형식은 ARCH-03 §9와 PLAN-49 T-255가 정한다.
3. **레이어:** 출력 레이어 아래 `패널링::미리보기`·`패널링::부재`·`패널링::타입::T-01`…·`패널링::결합부`·`패널링::재단`·`패널링::실패`(SPEC-07.12 2의 규칙).
4. **속성:** 객체마다 `vide-panel-id`·`vide-panel-type`·`vide-panel-class`·`vide-panel-size`·`vide-thickness`·`vide-joint`·`vide-flatness-mm`·`vide-deviation-mm`(표본과 실제 면의 차이)·`vide-assumed`(가정 값을 쓴 만들기)·`vide-status`. 이름·값 규칙은 ARCH-03 §9.1.
5. **실패 패널:** 틀이 만들지 못한 패널(닫히지 않음·잘림 실패·두께 불가)은 `패널링::실패`에 패널 윤곽선과 번호로 남기고 결과 카드·보고서에 이유를 적는다. 빠진 패널을 다른 모양으로 메우지 않는다.
6. **교체:** 다시 만들 때는 SPEC-07.12 4의 표대로 이전 만들기가 기록한 객체만 교체하고, 사람이 고친 패널은 보존한다(SPEC-07.13). 타입이 바뀐 패널은 교체 대상이다.
7. **결과 카드:** 추가 · 교체 · 보존 · 실패 수, 실제 면과 표본의 최대 차이(mm), [되돌리기].
8. 연결된 Rhino 문서가 없으면 만들지 않고 연결을 안내한다(원본 파일을 열어 쓰지 않음).

## 9. 실패 규칙 — SPEC-16.10

근거: SPEC-07.17, AC-14.

- 실패한 패널·부재·타입은 수와 이유를 화면·보고서·만들기 결과에 늘 보인다. '조용히 빼기'나 '조용히 메우기'는 없다. 경계 처리 '빼기'로 뺀 패널도 '뺀 패널 n'으로 센다.
- 한 패널의 실패가 다른 패널의 계산을 멈추지 않는다. 단계 전체가 실패(기준 면 없음, 단위 모름, 패널 0개)하면 그 단계 결과를 비우지 않고 이전 결과를 '다시 계산 필요'로 흐리게 두며 이유를 보인다.
- 패널 수가 상한(1차 2만 개)을 넘으면 계산하지 않고 '패널이 너무 많습니다 · 크기를 키우거나 면을 나누세요'를 보인다.
- 방향이 이상해 보일 때 확인할 수 있게, 패널마다 면 법선 방향·두께 방향·패턴 축을 보기 층으로 켤 수 있다. 뒤집기는 패턴 축과 두께 방향을 함께 뒤집는 설정값이며 법선만 뒤집지 않는다.

## 10. 보고서와 내보내기 — SPEC-16.11

근거: FR-14·22, AC-20, SPEC-07.11.

- **CSV:** 패널 표·타입 표·결합부 표(SPEC-16.7 7) 각각. 단계가 아직 계산되지 않은 열은 빈칸이다.
- **보고서(HTML, 자체 포함):** 기준 면(문서·면·읽은 시각·단위), 단계별 입력과 출처(가정 표지 포함), 수·크기 범위·타입 수·결합부 타입 수, 실패 목록, 평면화 틈, 마지막 만들기 결과.
- '다시 계산 필요' 상태이거나 가정 값이 남은 단계의 내보내기는 할 수 있지만 머리에 '가정 값 n개 포함'·'다시 계산 필요'를 찍는다.

## 11. 작업본과 기록 — SPEC-16.12

근거: SPEC-07.4·07.3, FR-12·16.

- 작업본 하나가 기준 면 하나(여러 면 묶음)와 세 단계의 설정·결과를 가진다. 같은 면으로 다른 패턴을 비교하려면 작업본을 복제한다.
- 작업본은 기준 면의 Link·객체 ID·면 번호·읽은 지문, 단계별 설정값과 출처, 질문 카드 답, 마지막 계산 지문, 만들기 기록을 남긴다. 표본 자체는 다시 읽을 수 있는 입력 사본이다.
- 작업 이력에는 면 읽기, 단계별 계산(입력 지문), 만들기·되돌리기가 남는다.
