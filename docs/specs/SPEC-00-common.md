# SPEC-00 · 공통 상태·권한·개입·참조 규칙

이 문서는 초안이다. 아래 절은 PRD 0.4 층 정리(2026-09-17)에서 PRD 본문에 있던 SPEC 층의 문장을 옮겨 담은 것으로, 문장의 자리만 옮겼고 확정 전이다. 각 절은 근거가 되는 PRD 절과 FR·AC를 인용하며, 문구가 열린 결정에 걸린 절은 ‘미결’ 줄로 표시한다. 사용자 약속 자체는 PRD가 소유하고, 이 문서는 그 약속을 지키기 위한 시스템의 상태·규칙만 정한다. 구체적인 필드·전송 형식은 PLAN이 소유한다(AI.md §7).

## 1. 참조 규칙

객체의 분할·합침·삭제·재생성 뒤 동일성이나 부분 참조를 확인할 수 없다면, ‘연결 끊김’ 또는 ‘이전 버전 참조’로 표시한다.

근거: PRD §6.2, FR-05, AC-21
미결: 없음. 상태 이름 두 개와 ID 변동 사례별 처리는 첫 호스트 SPEC에서 확인한다.

## 2. 상태 축 정의

실행 상태, 지시 반영 상태, 후보 유효성, 원본 적용 결과, 파일 저장, 검증 증거는 서로 독립된 축이며 동시에 참일 수 있다(예: 지시 접수·원본 적용 확인·파일 미저장). 이 문서는 이 축들을 하나의 상태 열거형으로 합치지 않는다. 이 절은 축의 독립성만 정하며 여섯 개의 공개 enum이나 별도 카드·서비스 구현을 요구하지 않는다(필드·전송 형식은 PLAN).

근거: PRD §9.3, FR-11, FR-12, AC-08, AC-18
미결: 없음. 각 축의 값과 전이는 이 문서의 후속 판에서 정한다.

## 3. 늦은 결과·직접 수정 처리

진행 중 연산을 안전하게 멈출 수 없는 경우 그 연산의 종료까지 기다려야 함을 표시하고, 종료 결과가 새 조건을 위반하면 활성 후보나 원본에 자동 채택하지 않는다.

무관한 변경은 영향 확인 후 유지하고, 관련 변경은 재비교한다. 안전하게 재사용할 수 없는 결과는 과거 결과로 남기되 현재 유효한 결과와 구분한다.

근거: PRD §4.3(늦은 결과 보호 정본)·§9.3·§9.4, FR-11, AC-09, AC-10, AC-11
미결: 늦은 결과의 문구(항상 보류 / 새 조건 위반 시만 보류 / 무관하면 자동 적용, 또는 Codex 제안의 보존·관련성 확인·별도 적용 조건)는 PRD §4.3 스레드(R-51·R-63)에서 사용자가 정한다. 결정되면 위 문장을 그 결정에 맞춘다.

## 4. 불명확 적용 결과 처리

캡처나 보고서 생성 실패로 확인된 변경을 다시 실행하지 않는다. 적용 결과가 불명확하면 영향받는 대상의 후속 쓰기를 보류하고 상태를 확인하되 다른 비파괴 작업은 유지한다.

근거: PRD §11.3, FR-16, AC-17, AC-18
미결: 없음.

## 5. 확장 선언 항목

확장에는 목적, 사용 입력, 결과 유형, 필요한 호스트·도구·권한, 진행·개입의 지원 범위가 있어야 한다.

근거: PRD §12.3, FR-13, FR-18, AC-26
미결: 확장의 신뢰·배포 범위와 실행 형태는 OQ-07·ADR-008이 정한다. 확장 계약 SPEC이 생기면 이 절은 그 문서로 옮긴다.
