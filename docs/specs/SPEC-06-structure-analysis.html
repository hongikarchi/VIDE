구조 분석 jig와 프로젝트 구조 jig

00 / 설계 중인 강구조를 계획 단계에서 스스로 검토한다 — SPEC-06.8

근거: PRD FR-23·AC-40~43, ADR-019. 설계자는 CAD 도면이나 Rhino 모델로 받은 강구조를 해석 모델로 바꾸고, 부재가 대략 적정한지와 어디가 부족한지를 근거와 함께 빠르게 확인한다. 배치가 바뀔 때마다 구조사무소와 왕복하기 전에 스스로 1차 판단을 내리는 것이 목적이다.

사용자는 JIG 탭에서 구조 분석을 열고 입력(Sync한 CAD 도면, Rhino 부재 솔리드, Rhino 중심선 곡선 중 하나 이상)을 고른다. AI가 해석 모델 초안을 만들고 코드가 점검한다. 사용자는 3D 미리보기와 표에서 부재 역할·단면·지점·접합·하중을 확인하고 고친 뒤 확정한다. 확정한 모델을 해석하면 부재마다 검정비·지배 조합·근거 조항·판정이 표와 뷰포트 색으로 나온다. 부족한 부재를 누르면 모델에서 찾아가고, 부족 원인이 부재 크기인지 입력·하중 의심인지 구분해 본다. 입력을 고치면 이전 결과는 오래된 것으로 표시된다.

프로젝트 골조를 직접 배치하고 점검한다. 받은 구조를 검토하는 데 그치지 않고, 프로젝트마다 다른 조건(기존 기초, 기존 지하 구조물, 기둥 금지 구역, 신설 E.J. 등)을 반영해 골조를 배치하는 프로젝트 구조 jig를 같은 구조 해석 기능 위에 만든다. 사용자는 관련 CAD·Rhino 파일을 모두 연결하고, AI가 역할별 입력을 제안하면 확인한다(§9). 먼저 지금 그려진 배치를 읽기만 해서 간섭·경간을 진단하고(§13), 설정값을 조정하며 축선·기둥·거더·작은보를 만들고 간섭·경간·높이를 판정한다(§10). 해석·단면 선정·부호·일람표(§11)를 거쳐 상단선과 부재를 Rhino에 만든다(§12). 이 명세는 일반 동작만 정한다. 한 프로젝트의 고유 규칙과 값은 그 프로젝트의 jig 설정값에 두며, jig 형식·작업본·수정 사항·실행 권한·Rhino에 만들기의 공통 규칙은 SPEC-07을 따른다.

완료 기준: 실제 Rhino 또는 CAD 입력 하나 이상에서 초안 → 점검 → 확정 → 해석·검정 → 결과 표시·모델 찾아가기가 이어지고, 검증 시험 자료(ARCH-02 §6)가 통과해야 한다. 결과 화면에는 항상 "탐색용 예비값 — 구조계산서·구조기술사 최종 검토를 대체하지 않음"과 검토하지 않은 항목이 보여야 한다(AC-40). 프로젝트 구조 jig는 실제 프로젝트 사본에서 진단 → 입력 조립 확인 → 배치·판정 → 확정 해석 → 단면·일람표 → Rhino 후보·원본 반영이 이어져야 하며, 수치 수용 기준은 PLAN-23과 해당 VERIFY가 정한다. 합성 예제만 되거나 표만 나오는 상태는 완료가 아니다.

01 / 입력과 해석 모델 초안 — SPEC-06.1

근거: FR-23·03·18. 입력 형태는 프로젝트마다 다르다. 지원 입력은 다음과 같다.

입력 코드가 먼저 하는 일 AI가 맡는 일
Rhino 중심선 곡선 꺾인 곡선을 선분으로 나누고 끝점을 병합, 기울기로 기둥·보·가새 후보 판정 레이어·이름·속성의 의미 해석, 역할이 애매한 부재, 단면 지정
Rhino 부재 솔리드(Brep) 솔리드에서 축과 단면 치수를 추출해 단면표와 대조 불규칙 형상, 접합부 덩어리 분리, 단면 판정
CAD 도면(ZWCAD Sync) 선·레이어·문자 읽기 그리드·부재 부호를 부재와 단면에 연결, 일람표 해석

결과는 입력 형태와 무관하게 하나의 해석 모델 초안(ARCH-02 계약)이다. 초안의 항목(절점·부재·단면·지점·접합·하중)마다 출처를 자동 / AI / 사용자 중 하나로 기록한다. AI가 근거 없이 정한 값은 "가정"으로 표시한다. 초안 작성은 저장된 Sync만 읽으며 호스트 원본을 바꾸지 않는다. 여러 입력을 함께 쓰면 좌표 관계(단위·원점·회전)를 먼저 맞추며, 관계가 불확실하면 사용자에게 묻는다.

설계 부재와 해석 부재. 초안은 지지점(기둥, 받는 보와의 접합 등) 사이의 물리 부재를 설계 부재로 두고, 해석을 위해 나눈 조각(해석 부재)이 어느 설계 부재에 속하는지 기록한다. 곧은 부재(꺾인 선의 각 선분 포함)는 접합점에서만 나누고, 곡선 부재만 설정한 최대 조각 길이와 곡선–현 차이 안에서 나눈다. 나눈 조각의 역할은 조각의 기울기로 다시 추정하지 않고 설계 부재의 역할을 따른다. 설계 부재는 비지지 길이·유효좌굴길이·처짐의 기준이다(§6).

02 / 모델 점검 — SPEC-06.2

근거: FR-23·10. 확정 전에 코드가 모델을 점검하고 항목별로 보인다.

  • 허용오차 안에 가까이 붙은 절점, 중복 부재, 길이 0 부재. 병합 허용오차는 사용자에게 보이며, 병합·제거한 목록을 남긴다.
  • 지점 없음, 기구(불안정) 자유도. 불안정하면 해당 절점·자유도를 뷰포트에 표시한다.
  • 단면·재료 미지정 부재, 단위 이상(예: 부재 길이가 모두 수천 m).
  • 접합 규칙과 다른 단부(§4).

점검 오류가 남으면 확정할 수 없다. 경고는 확정할 수 있으나 결과에 함께 표시된다.

03 / 확정과 유효성 — SPEC-06.3

근거: FR-23·16, AC-40, 2026-09-29 사용자 결정(슬라이더 조정 중 확정 전 미리보기 해석 허용). 이 결정은 ADR-019 결정 3("확정한 모델만 해석")을 미리보기에 한해 좁힌다. 해석 결과는 확정 결과와 미확정 미리보기로 나뉜다. 저장되고 근거로 쓰이는 것은 사용자가 확정한 모델의 결과뿐이다.

확정 결과. 확정은 사용자가 모델 전체를 한 번에 확인하는 행동이며 AI가 대신하지 않는다. 확정한 모델과 입력 Sync·입력 조립(§9)의 기준 버전을 함께 저장한다. 확정 결과만 결과 이력·보고서·일람표·내보내기에 '확정'으로 쓰이고, Rhino에 부재를 만드는 근거가 된다(§12). 입력 Sync·입력 조립·모델·하중·조건이 바뀌면 이전 결과를 "오래된 결과"로 구분하고 다시 확정·해석하게 한다. 결과를 지우지는 않는다.

미확정 미리보기. 설정값(슬라이더)·배치·단면을 조정하는 동안에는 확정 전 모델도 해석해 판정색과 요약을 보일 수 있다. 조건은 다음과 같다.

  • 점검 오류(§2)가 없는 모델만 미리보기로 해석한다. 오류가 있으면 해석 대신 오류를 보인다.
  • 결과에는 늘 '미확정 미리보기'를 표시하고 확정 결과와 구분되는 표현으로 보인다(표현은 Design).
  • 저장하지 않는다. 결과 이력·작업 기록·내보내기에 남기지 않고, 새 미리보기가 오면 이전 미리보기는 버린다.
  • 보고서·일람표·AI 설명에서 '확정'으로 쓰지 않는다. AI가 미리보기 수치를 인용할 때도 미확정 미리보기라고 밝힌다.
  • 미리보기가 실패해도 입력과 이전 확정 결과를 바꾸지 않고 원인만 보인다.

04 / 접합(단부) 규칙 — SPEC-06.4

근거: FR-23, RESEARCH-08 §4.1, 사용자 결정(2026-09-29: 기둥은 H형강, 주축 방향 거더만 강접). 부재 단부 조건은 부재 종류가 아니라 무엇에 붙는가로 정한다. 기본 규칙은 다음과 같고 프로젝트마다 바꿀 수 있다.

  • 보·거더의 단부가 기둥에 붙으면 강접. 다만 기둥이 H형강이면 기둥 단면의 주축 방향(플랜지·웨브에 바로 붙는 방향)에서 허용각(기본 ±15°) 안으로 붙는 보·거더만 강접하고, 그 밖의 방향은 핀으로 둔다. 여러 방향의 거더를 H형강 기둥에 모두 강접하면 제작하기 어려운 약축·플랜지 끝 접합이 되고, 단부 모멘트를 과대 평가해 거더 중앙 휨을 과소 평가하기 때문이다. 이 규칙은 출처를 가정으로 표시하고 구조사무소 확인 항목으로 둔다.
  • 작은 보가 큰 보(거더)에 붙는 단부는 핀.
  • 가새는 양단 핀(인장 전용 여부는 선택).
  • 기둥 하단은 핀(주각 조건은 선택).

예외는 부재·단부 단위의 예외표로 관리하며 출처(사용자·구조사무소 표시 등)를 남긴다. 해석 뒤 강접인데 단부 모멘트가 거의 0이거나 핀인데 단부 모멘트가 있으면 경고한다.

05 / 하중과 해석 조건 — SPEC-06.5

근거: FR-23. 하중은 면하중(실·영역별 고정·활하중), 선하중, 집중하중, 자중으로 입력한다. 값마다 출처(하중표 / 가정)를 표시한다. 하중 패턴의 성격(고정·활·적설·풍·지진)이 조합 생성의 입력이다.

기본 해석 조건은 계획 단계 중력 검토다: 강도 조합 1.2D+1.6L, 선형 정적 해석. 처짐용 사용성 조합과 명목 수평하중(층 중력에 설정한 비율을 곱해 X·Y 방향으로 가함) 조합은 jig 설정으로 더한다. 사용자는 조합을 추가·수정할 수 있다. 쓰인 조합은 이름 있는 계수 표로 결과와 보고서 첫머리에 그대로 보인다.

수평 구속은 수평 거동을 빼고 중력 결과를 보기 위한 선택이며, 지정한 절점에만 둔다(예: 지붕 레벨 기둥 상단, 지정한 슬래브 레벨의 기둥 절점). 어떤 높이 위의 모든 절점을 한꺼번에 잡지 않는다. 그렇게 하면 곡선 거더의 추력 같은 힘을 가짜 지점이 받아 결과가 왜곡된다. 구속을 켜면 기둥별 구속 반력과 합계를 "횡력 시스템(또는 기존 구조물)이 받아야 할 힘"으로 보인다. 구속 절점 위의 기둥 구간은 흔들림이 있는 골조로 보고 유효좌굴길이를 정한다(§6). 풍·지진·전체 조합·2차 해석(P-Δ)을 포함한 최종 점검 모드는 후속 범위이며, 이번 범위에서는 "검토하지 않음"으로 표시한다.

06 / 부재 검정 — SPEC-06.6

근거: FR-23, ADR-019 결정 2. 강재 부재는 KDS 14 31 10 체계로 검정한다: 압축, 휨(횡비틀림좌굴·Cb 포함), 전단, 휨·축력 조합, 세장비. 압축과 휨을 함께 받는 기둥은 확대 모멘트(B1)를 적용하고 장주·단주 구분을 보인다.

설계 부재 기준. 비지지 길이·유효좌굴길이계수 K·Cb는 해석 조각이 아니라 설계 부재(§1)를 기준으로 정한다. 조각 길이를 쓰면 작은보 접합점에서 나뉜 거더의 횡비틀림좌굴과 기둥 좌굴이 비보수적으로 검토되기 때문이다. 정모멘트 구간의 비지지 길이는 횡지지(작은보 접합 등) 사이 길이이고, 강접 단부의 부모멘트 구간은 압축 하부 플랜지를 잡는 부재가 없으면 변곡점까지, 모르면 지지점 사이 전 길이로 본다. 수평 구속 위 흔들림 골조 기둥의 K는 설정값(가정)이다. 이 값들은 부재마다 자동값과 사용자 덮어쓰기를 함께 가지며, 자동값은 "가정"으로 표시한다. 설계 부재 기준 값을 정하지 못한 부재는 '미완'으로 둔다. 재료 상수·강종 항복강도(두께별)·단면 성질의 출처를 기록한다.

처짐과 참고 처짐. 처짐 한계는 부재 역할별로 사용자가 정한다(기본값은 가정으로 표시). 설계 부재의 처짐(양 끝 지지점을 잇는 기준선에서 잰 처짐, 캔틸레버는 끝 처짐)은 코어가 설계 부재 단위로 판정하기 전까지 **'참고 처짐'**으로 한계와 함께 따로 보이고 4상태 판정에 합치지 않는다. 참고 처짐이 한계를 넘으면 판정과 별도로 표시하며, 해석 조각 기준 처짐만으로 설계 부재의 처짐이 충분하다고 보이지 않는다.

부재 판정은 네 상태로 나눈다: 통과 / 실패 / 미완(입력 부족으로 검정 못 함) / 오류(계산 실패). 일부 검사만 통과했다고 전체를 통과로 보이지 않는다. 각 판정에는 검정비, 지배 조합, 근거 조항, 중간값(세장비, 한계 길이, 공칭 강도 등)을 붙인다.

07 / 결과와 NG 원인 — SPEC-06.7

근거: FR-23·10·14. 결과는 다음을 포함한다.

  • 부재 표: 부재·역할·단면·길이·검정비·지배 조합·조항·판정·처짐·참고 처짐. 정렬·필터와 행 선택 시 뷰포트에서 찾아가기.
  • 뷰포트 색: 미판정(회색) / 통과(< 0.7) / 주의(0.7~1.0) / 초과(≥ 1.0)와 판정 불가를 구분한 색. 미확정 미리보기(§3)는 확정 결과와 구분해 표시한다.
  • 요약: 강재 중량(t)·면적당 중량, 최대 검정비, 실패 부재 수, 점검 경고 수. 여유를 보일 때는 '중력 조합 부재 검정 여유'처럼 검토한 조합 범위를 이름에 붙이고, '미완' 부재를 '통과'로 세지 않는다.
  • NG 원인 분류: 실패 부재마다 "부재 부족"과 "입력·모델 의심"(하중 합계 불일치, 가정값이 지배, 점검 경고와 관련, 비정상 크기)을 구분해 보인다.
  • 검토하지 않은 항목 목록(횡하중(풍·지진) 설계, 흔들림 안정의 정밀 해석, 접합부, 기초 내력, E.J. 상세, 데크 슬래브, 진동, 내화, 기존 구조물의 보강 등)과 "탐색용 예비값 — 구조계산서·구조기술사 최종 검토를 대체하지 않음".

결과 표는 파일(CSV)로 내보낼 수 있다. 결과를 호스트에 반영(예: 부재 색·속성 기록)하는 것은 사용자가 요청할 때만 기존 수정 경로의 권한·검증으로 한다.

08 / 실패와 보호 — SPEC-06.9

근거: FR-16·18. 해석이 실패하면(불안정, 계산 오류) 원인과 관련 절점·부재를 보이고 입력·이전 결과를 보존한다. 계산 코어는 입력 모델 외의 파일·네트워크·호스트에 접근하지 않는다. AI에는 모델 초안 작성, 입력 조립 제안(§9)과 결과 설명을 위해 필요한 표·요약만 보내며, 결과 설명은 표에 있는 부재·수치만 인용한다(없는 부재를 인용하면 경고). 사용자 원본 문서는 반영 요청 없이 바뀌지 않는다.

09 / 입력 조립 — SPEC-06.10

근거: FR-23·03·18, AC-41, RESEARCH-10 §14.3, 사용자 결정(2026-09-29: 구조 해석에 필요한 자료는 연결한 CAD·Rhino 파일 전부에서 AI가 조합하고 사람이 확인한다). 프로젝트 구조 jig는 입력을 파일 하나·레이어 하나로 고르게 하지 않고, SPEC-07.5의 입력 조립(규칙 후보 → AI의 역할 제안 → 코드의 형상 추출 → 역할별 사람 확인, 확인 전 '입력 미확인', 좌표 정렬, 표시용 Sync와 분리된 읽기)으로 받는다. 구조 jig에서는 다음을 더한다.

  • 역할: 슬래브 경계(보이드·설치 불가 영역 포함), 거더 상단 기준면(슬래브 하면), 현재 배치(기둥·거더), 기존 기초, 기존 지하 구조물의 보, 수평 구속 레벨, 기존 그리드와 이름, 신설 E.J., 기존 E.J.(점검용), 구조사무소 요청 위치, 기둥 금지 구역, 형하 점검 구역과 바닥 레벨, 레벨, 곡선 구역. 역할 목록과 모양은 jig 설명서가 선언한다(ARCH-03).
  • 후보가 여럿일 때: 같은 배치가 두 모델에 다른 기준 높이로 있는 경우처럼 한 역할에 후보가 여럿이면 AI가 하나를 제안하고 이유를 한 줄로 적으며, 사람이 고른다. 조용히 합치지 않는다.
  • 자료끼리 맞지 않을 때: 자료 사이의 개수·위치가 다르면(예: 두 자료의 기존 기둥 수가 다름) 한쪽을 조용히 버리지 않는다. 기준으로 쓴 쪽을 밝히고, 다른 쪽에만 있는 위치를 '누락 가능' 경고로 보이며 확인 목록에 올린다.
  • 자료에 위치가 없는 역할(예: 곡선 구역)은 사용자가 Rhino에 평면 곡선을 그리거나 스케치로 지정한다.
  • 좌표: 같은 좌표계로 확인된 모델은 변환 없이 쓰고, 도면은 기존 그리드 직선을 기준 쌍으로 정렬한다.
  • 출처: 판정과 보고서 수치에서 그 값이 어느 역할·파일·레이어에서 왔는지 찾아갈 수 있어야 한다. 확인한 입력의 원천이 바뀌어 다시 계산이 필요해진 결과는 확정 결과라도 오래된 결과로 구분한다(§3).

10 / 배치 생성·간섭·판정 — SPEC-06.11

근거: FR-23·10, AC-42, RESEARCH-10 §14.4·§14.6, 사용자 결정(2026-09-29: 삼각망 거더와 작은보, 경간 상한은 대각 거더를 포함한 모든 거더에 적용, 테두리보는 내민 보로 지지, 기존 지하 구조물의 보는 가능한 한 피함, 기둥 높이 정수, E.J. 분절과 양쪽 기둥, 슬래브 레벨 수평 구속, 기둥 금지 구역). 프로젝트 구조 jig는 확인한 입력(§9)과 설정값으로 골조 배치를 만든다. 경간 상한·작은보 간격·캔틸레버 한도·파일캡과 오픈컷 크기·형하·기둥 길이 단위 같은 값은 이 프로젝트의 jig 설정값이며, 기본값·범위와 저장 형식은 ARCH-03·PLAN-23이 정한다. 설정값을 바꾸면 그 값에 기대는 단계만 AI 없이 다시 계산하고(SPEC-07.7), 사용자가 평면에서 기둥을 끌거나 표에서 고친 값은 수정 사항으로 남아 다시 계산해도 유지된다(SPEC-07.8).

  1. 축선·기둥. 기둥은 슬래브 경계 안(외곽에서 설정 거리 이상)에만 두고 기둥 금지 구역(예: 소방 동선) 안에는 두지 않는다. 배치 후보는 직교 격자와 엇갈림 격자를 함께 만들고, 설정한 우선순위로 앞 항목이 같을 때만 다음 항목을 보는 방식(사전식)으로 비교한다. 기본 순서는 ① 경간 상한 초과 수·초과량 ② 파일캡↔기존 기초 간섭 ③ 기둥·파일캡↔기존 지하 보 겹침 ④ 오픈컷↔기존 기초 겹침 ⑤ 기둥 수(동률 깨기용 가정, 끌 수 있음)다. 모두 만족할 수 없으면 뒤 항목부터 완화하고 경간은 마지막까지 지키며, 남은 위반은 모두 판정 표와 확인 목록에 올린다. 목적값이 다른 대안 2~3개를 비교해 보이고 사용자가 고른다. 같은 입력·설정이면 같은 배치가 나오고, 기둥·거더는 축선 이름에서 온 안정 키(SPEC-07.8)로 다시 계산해도 같은 대상을 가리킨다.

  2. 간섭 판정. 기둥마다 파일캡·오픈컷 발자국(회전 포함)을 기존 기초 발자국 하나하나와, 기둥·파일캡을 기존 지하 보 띠와 비교한다. 축선 기준 금지 띠로 대신하지 않고 실제 발자국끼리의 겹침·최소 거리로 판정한다.

    대상 판정
    파일캡↔기존 기초, 파일캡↔파일캡 불가
    오픈컷↔기존 기초 협의(토목 협의 목록, 겹침 깊이·면적 표시)
    기둥·파일캡↔기존 지하 보 배치에서 가능한 한 피하고, 남은 겹침은 경고와 목록
    신설 구간의 기둥이 기존 E.J. 양쪽에 걸침 경고(확인 목록)
    구조사무소 요청 위치에 기둥이 없음 '확인 필요'와 이유

    불가 기둥에는 축선을 따라 설정 한도 안에서 겹침이 없는 가장 가까운 위치를 제안하되, 경간 상한을 넘기지 않을 때만 제안하고 자동 적용하지 않는다.

  3. 거더망. 기둥 사이를 삼각형으로 잇는다. 직사각형 칸처럼 대각선이 하나로 정해지지 않는 칸은 규칙(짧은 대각선, 길이가 같으면 전역 한 방향, 이전 결과와 거의 같으면 이전 것 유지)으로 정해, 기둥이 허용오차 안에서 움직여도 거더 집합·키·부호가 바뀌지 않게 한다. 슬래브 경계·보이드를 벗어나거나 가로지르는 거더와 신설 E.J.를 넘는 거더는 두지 않는다. 경간 상한은 대각 거더를 포함한 모든 거더에 적용하고, 넘으면 '초과'로 판정한다.

  4. 가장자리. 슬래브 끝이 바깥 거더에서 설정한 데크 내민 한도보다 멀면 바깥 거더에서 내민 보를 두고 그 끝을 테두리보로 묶는다(기둥을 더하지 않음). 캔틸레버 길이는 마지막 지지(기둥 또는 기둥–기둥 거더)에서 슬래브 끝까지로 재고, 내민 보 위의 테두리보는 지지로 세지 않는다. 캔틸레버 한도를 넘으면 '초과'로 목록에 올린다. 지지 방식을 '기둥 추가'로 바꾸면 테두리보를 기둥–기둥 거더로 두고 가장자리 기둥을 더한다(캔틸레버 길이를 줄이는 것은 이 방식뿐이다). 오목부와 가장자리 띠도 닫힌 칸이 되게 하고, 보이드 둘레에는 둘레 보를 둔다.

  5. 곡선 구역. 지정한 곡선 구역 안에 양 끝이 있는 거더는 연직면 위의 단일 곡률 곡선으로 만들고, 곡률은 슬래브 하면에 맞춘다.

  6. 작은보. 닫힌 칸(삼각형, 테두리보로 닫힌 칸 포함)마다 가장 긴 변과 평행하게 설정 간격 이하로 두고 칸 경계에서 자른다. 설정 최소 길이보다 짧은 작은보는 두지 않고, 양 끝은 핀이다.

  7. E.J. 신설 E.J.로 골조를 나눈다. E.J.를 넘는 거더를 두지 않고, E.J.마다 양쪽에 기둥(쌍기둥, 기본은 공통 파일캡)을 둔다. 기존 E.J.는 분절에 쓰지 않고 점검(2의 경고)에만 쓴다.

  8. 높이. 거더 상단은 슬래브 하면을 따른다. 기둥 길이는 (거더 하단 − 기둥 하단)을 설정 단위의 정수배로 내림해 강재가 슬래브를 뚫지 않게 한다. 단면 선정 전에는 거더 하단을 춤 상한으로 잡는다. 기둥 상단과 거더 하단의 차이는 받침으로 채우고 '기둥–거더 레벨 차' 표로 보인다. 사용자가 Rhino에서 고친 높이는 수정 사항으로 받아 다음 계산부터 지킨다(§12, SPEC-07.13).

  9. 형하·높이 점검. 형하(최저 부재 하단 − 보 아래 마감 − 점검 구역 바닥 레벨)가 설정값 이상인지 판정한다. 금지 구역에 높이 한도가 있으면(예: 소방 동선 위 법정 높이) 모자랄 때 '불가'로 판정한다.

  10. 해석 모델 조립. 배치에서 해석 모델을 직접 만든다. 역할·지점·접합·하중·설계 부재를 명시하며 §1의 역할 추정을 거치지 않는다. 해석은 상단선 위에서 하고 '편심 무시(상단선 기준)'를 가정 목록에 적는다. 수평 구속은 지정한 슬래브 레벨의 기둥 절점에만 두고 그 위 기둥 구간은 흔들림 골조로 본다(§5·§6). 접합은 §4, 하중은 구역별 면하중을 작은보 부담폭에 따른 선하중으로 넣고 가장자리 선하중·보 아래 천장 하중과 강재 자중을 늘 포함한다. 조립한 모델도 §2 점검과 §3 확정을 거친다.

11 / 단면 선정·부호·일람표 — SPEC-06.12

근거: FR-23·14, AC-42, RESEARCH-10 §10.3·§10.4, RESEARCH-08 §3.6·§3.7, 사용자 결정(2026-09-29: 부호는 구조 도면 관례와 S-18 자산을 참고, 기둥은 H형강).

단면 선정. 부재를 역할 × 경간 띠 × 구역(곡선 구역은 따로)으로 묶고, 묶음마다 KS H형강 가운데 설정한 춤 상한 이하의 후보를 모두 비교해 목표 검정비를 만족하는 가장 가벼운 단면을 고른다. 해석 → 묶음 최대 검정비 → 후보 교체를 설정한 횟수까지 되풀이한다. 참고 처짐(§6)은 단면을 고르는 기준에만 쓰고 판정에는 합치지 않는다.

  • 후보 안에 만족하는 단면이 없으면 가장 무거운 단면을 조용히 고르지 않고 '후보 없음(춤 상한 초과 필요)'으로 두어 확인 목록에 올린다.
  • 수렴하지 않으면 마지막 두 결과 중 무거운 쪽을 택하고 '수렴 안 됨'을 경고한다.
  • 선정은 확정한 모델에서 출발하고, 선정 중의 해석은 미확정 미리보기다(§3). 선정 결과는 제안이며, 사용자가 적용한 단면으로 다시 확정해야 확정 결과·보고서·Rhino 부재 만들기에 쓰인다.
  • 선정 단면 적용. 사용자가 [선정 단면 적용]을 확인하면 '선정' 묶음의 단면을 부재별 작업본 수정 사항(단면 지정)으로 쓴다. 지금 단면과 같은 부재는 쓰지 않고, 같은 부재에 다시 적용하면 앞의 지정을 바꾼다. '후보 없음'·'미검토' 묶음은 지금 단면을 유지한다. 적용하면 모델이 바뀌므로 그 전의 확정 해석은 이 모델의 것이 아니게 되어 [해석 확정]이 다시 필요하고(§3), 적용 확인도 새 선정 결과에 대해 다시 기다린다. 적용한 모델을 다시 확정한 뒤에만 부재 만들기가 열린다. 일람표·만들기 계획은 적용 뒤의 선정 단면을 쓰고, 부호는 이전 계산의 원장을 이어 받아 같은 부재의 부호를 유지한다(아래 '안정 부호').
  • 기둥은 H형강 계열에서 고르고, 강축 방향은 배치가 정한 주 거더 방향을 따른다. 접합은 §4의 H형강 기둥 규칙을 따른다.

부호. 구조 도면 관례대로 역할별 접두(예: 기둥 SC, 거더 SG, 작은보 SB)와 1부터 시작하는 번호로 붙인다. 접두 표는 프로젝트마다 정하는 부호 규칙 설정값이며, 참고한 표준을 확인하기 전에는 '가정'으로 표시한다.

  • 같은 부호로 묶는 기준은 역할·단면·곡선 여부(곡선이면 반지름·솟음 범위)다. 번호는 위치 순서로 결정적으로 매긴다.
  • 안정 부호: 설정값을 바꿔 다시 계산해도 같은 부재(§10의 안정 키)는 같은 부호를 유지한다. 부재가 나뉘거나 합쳐지면 이전 부호와의 대응을 보인다.
  • 한 부호는 한 묶음만 가리킨다. 연결 도면·자료에서 같은 부호가 발견되면 번호를 바꾸지 않고 경고와 확인 목록으로 보인다.

일람표. 부호별로 역할·단면·개수·총길이·단위중량·중량·최대 검정비·지배 조항과, 곡선 부재면 반지름·솟음·현 길이, 해당 부재를 보인다. 행을 누르면 부재를 찾아간다. 단위중량은 단면 치수로 계산한 물량용 값이며 검정에 쓰지 않는다. '미완' 부재가 있는 부호는 통과로 세지 않고 그 수를 보인다. 일람표는 §7과 같은 방식으로 CSV로 내보낸다. 미확정 미리보기 수치로 만든 일람표에는 '확정'을 쓰지 않는다.

12 / Rhino에 만들기 — SPEC-06.13

근거: FR-23·24·04·10·16, AC-43, ADR-020 결정 4~6, 사용자 결정(2026-09-29: 구조사무소에는 상단선만 전달). 만드는 방식(AI 없이 VIDE 소유 고정 틀에 데이터만 넘김, 작업 사본 → 후보 → 사용자의 원본 반영, 출력 레이어 한정), 교체 대상 판정, 만들기 전 점검은 SPEC-07.12·07.14를 따른다. 프로젝트 구조 jig는 결과를 Rhino에 두 종류로 만든다.

만드는 것 내용 언제 만들 수 있나 사람이 Rhino에서 고쳤을 때(SPEC-07.13)
상단선 축선, 기둥선, 거더 상단선(곡선 포함), 작은보 상단선. 구조사무소에 전달하는 기준선이며 중심선은 만들지 않는다 해석 확정 전에도 [선만 먼저 만들기]로 만든다. 사용자가 Rhino에서 기둥 높이·위치를 맞출 수 있게 하기 위해서다 jig와 사람이 함께 쓰는 선이다. 위치나 끝점 높이만 바뀌었으면 수정 사항으로 받을지 제안하고, 받으면 다시 계산한다
부재 상단선 아래로 붙인 H형강 부재 솔리드(웨브 연직), 배치가 정한 강축 방향의 기둥, 선택하면 부호 문자 현재 모델(입력 조립·배치·단면·설정값)과 같은 기준으로 확정한 해석이 있을 때만(analysis-confirmed). 미확정 미리보기나, 선정 뒤 다시 확정하지 않은 단면으로는 만들지 않는다 jig가 소유한 결과다. 고친 부재는 교체하지 않고 유지 · jig 값으로 덮기 · 수정 사항으로 받기(단면만 읽음) 중에서 고르게 한다

둘 다 필요한 입력 역할이 모두 확인된 뒤에만 만든다(§9). 슬래브 경계 밖 부재는 만들기를 막는 점검이고, 경간·캔틸레버 초과와 형하 부족은 결과 표의 판정이어서 만들기를 막지 않는다.

13 / 진단 — SPEC-06.14

근거: FR-23·14, RESEARCH-10 §0.3·§14.4. 지금 그려진 배치를 읽기만 해서 점검한다. 배치를 새로 만들거나 해석하지 않으며 호스트를 바꾸지 않는다. 입력 조립(§9)의 역할 가운데 현재 배치(기둥·거더), 기존 기초, 기존 지하 구조물의 보만 있으면 된다. 배치 생성·해석이 없어도 쓸 수 있는 첫 결과이며, 구현 순서는 PLAN-23이 정한다.

  • 간섭 표: 기둥마다 파일캡↔기존 기초, 오픈컷↔기존 기초, 기둥↔기존 지하 보의 겹침·최소 거리와 판정(§10과 같은 판정 이름).
  • 경간 표: 거더 곡선을 허용오차 안의 기둥 상단점에서 끊은 구간을 경간으로, 끝의 내민 구간을 캔틸레버로 따로 보인다. 곡선 하나의 평면 길이는 경간이 아니므로 별도 열로만 보이고 '경간 초과'로 세지 않는다.
  • 표의 행을 누르면 3D에서 찾아가고, 결과는 3D 겹침 표시와 CSV로 볼 수 있다.
  • 필요한 역할이 없으면 그 판정만 '미완'으로 두고 이유를 보인다.

14 / 후속 범위(이번 범위 밖)
