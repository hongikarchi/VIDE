ADR-007 · 웹 검토 — 온라인 제출까지 MVP

초록 추가·교체 제안빨강 삭제·교체 대상CLAUDE: 파란 상자 · CODEX: 보라 상자

검토자 필터는 코멘트·부록만 바꿉니다. ‘인라인 제안 미리보기’는 코멘트의 대안까지 합친 최종본이 아닙니다. 보기 전환은 MD 수정·수락·승인을 하지 않습니다.

01 / 배경

FR-19·OQ-04는 웹 참여의 첫 제공 범위를 미정으로 두었다. 2차 검토(PRD R-53, Design R-42)는 미정 자체가 아키텍처 비용이라며 파일 교환(FR-14 HTML 패키지 안에서 코멘트·주석 작성 → 파일 반출 → IDE 반입)을 MVP 기본값으로 권했다. 온라인 제출은 1인 팀에 두 번째 프런트엔드(호스팅·인증·동기화)를 뜻한다.

02 / 선택지

안 내용 트레이드오프
A 파일 교환만 MVP 서버·인증 없음. 검토자가 파일을 돌려보내야 함
B 온라인 제출까지 MVP 검토자 경험이 완결됨. 게시 주체(작업 PC / 중계 서비스)·인증·기준 버전 동기화·재접속(AC-28)이 MVP에 들어옴
C 보류 SPEC-00 권한 모델이 외부 검토자를 포함할지 정하지 못함

03 / 결정

B. 온라인 제출까지 MVP에 포함한다. 권고(A)와 다른 선택이며 소유자가 비용을 알고 정했다.

  • 외부 검토자는 브라우저에서 기준 버전의 모델·자료를 보고 코멘트·화면 주석을 온라인으로 제출한다. IDE는 제출을 기준 버전과 함께 수신·비교·선택 채택한다(AC-19). 원본 반영 권한은 여전히 외부 검토자에게 없다(PRD §12.5).
  • 게시 주체는 작업 PC 직접 게시가 아니라 중계 서비스로 한다(PRD §12.5 방화벽 조건). 인증·호스팅·데이터 보관 방식은 PLAN과 스파이크에서 정한다.
  • 웹 뷰어는 ADR-004의 IDE 자체 뷰와 표시용 형상·좌표계·객체 식별자를 공유한다. 웹 스케치는 '명명된 뷰 위 화면 주석'으로 저장하고, 객체 핀은 패키지가 식별자를 포함할 때만 허용한다(Design R-42 계약).
  • 파일 교환(A)은 온라인이 불가한 환경의 대체 경로로 함께 제공한다.

codexR-01높음 추가 지적. 제출의 권한과 전달 보장. 온라인+파일이라는 사용자 선택은 유지한다. 다만 파일 대체 경로는 읽기 전용 HTML 출력만으로 얻어지는 기능이 아니며 내보내기·반입·자료 검증이 필요하다. 제안: 패키지/기준 버전과 의견의 고유 ID를 유지하고 온라인 재시도·파일 재반입에서 같은 의견을 중복 채택하지 않는다. 작성 저장→서버 접수 확인→IDE 수신→사용자 채택→원본 반영은 구분하며 작업 PC가 오프라인일 때도 접수 사실을 잃지 않는 경계를 정한다. 검토 링크의 접근 범위·만료/철회와 보관/삭제, 허용 첨부 형식·크기를 SPEC의 의미와 PLAN의 방법으로 나누고, 반입 자료를 실행 권한으로 해석하지 않는다. 실제 서버 기술이나 실시간 공동 편집을 여기서 추가할 필요는 없다.

04 / 결과 — 적용 시 바꿀 문장

  • PRD FR-19 범위 값 '제공 범위 미정' → 'MVP 지원 범위(온라인 제출 + 파일 교환)', OQ-04를 "지원 기기·브라우저 범위"로 좁히고 이 ADR 링크. §12.5·§14.1 외부 웹 행, AC-28.
  • Design §12 웹 행을 ① 웹 검토(온라인·파일 경로) ② IDE 반입·채택 화면 ③ 인증·재접속으로 분리(Design R-42).
  • 배포 형태(ADR-002)가 개인 도구 단계인 동안 중계 서비스는 소유자 계정의 단일 인스턴스로 충분하다.

05 / 축소 조건

  • Rhino alpha 판정 시점까지 중계 서비스·인증 스파이크가 끝나지 않으면 MVP 출시 조건에서 온라인 제출을 빼고 파일 교환(A)으로 출시한 뒤 온라인은 후속 확장으로 옮긴다.
  • ADR-004가 자체 뷰를 축소하면 웹 뷰어는 캡처·명명된 뷰 기반으로 재정의한다.

codexR-02중간 추가 지적. 스파이크 미완료와 출시 범위. Rhino alpha 시점에 중계 스파이크가 끝나지 않은 것은 온라인 기능이 불가능하다는 증거와 다르다. 온라인은 명시적으로 선택된 MVP 범위이므로, alpha에서 조사 미완료·실패·보완 가능을 나누고 다음 일정/노력 상한이나 범위 변경을 판단하는 것으로 적는 편이 명확하다. 사용자가 alpha 시점의 파일 전용 전환까지 조건부 수락했다면 그 의도를 문장에 분명히 남기고, 그렇지 않으면 에이전트가 자동으로 후속화하지 않는다. 파일 대체 경로도 기준 버전 대조·반입 검수가 완료되어야 출시 대안이 된다.

06 / 출처

PRD R-53·R-48, Codex R-44, Design R-42·R-40. 2026-09-17 brainstorming Q&A.

06 / 부록 · Codex 검토 요약 (2026-09-17)

온라인 제출까지 제공하는 선택을 존중한다. 외부 의견이 접수·수신·채택·적용되는 의미와 파일 대체 경로의 중복 처리, 미완료 실험을 근거로 한 자동 후속화 조건을 보완할 것을 권한다.

이번 검토는 사용자 수락이나 본문 반영을 뜻하지 않는다. 기존 스레드는 같은 ID로 갱신하고, 새 지적은 별도 ID를 부여한다. 철회 기록은 상대 참조가 정리될 때까지 남긴다.
