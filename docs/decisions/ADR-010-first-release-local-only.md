# ADR-010 · 첫 출시는 한 PC 안에서 (원격 제어·웹 검토는 후속)

## 1. 배경

제품 형태(PRD R-49·R-61)와 웹 검토의 제공 범위(PRD R-53·R-65, Design R-42·R-46)가 이견으로 남아 있었다. ADR-007은 온라인 제출까지 MVP에 넣는 안을 골랐고, 이는 1인 팀에 두 번째 프런트엔드(중계 서비스·인증·기준 버전 동기화·재접속)를 뜻한다. 별도로, 아이패드 등 다른 기기에서 코멘트로 호스트 PC의 AI를 움직이는 원격 제어가 PRD §1.3·§12.5의 개념 서술에 섞여 있어 첫 출시가 어디까지인지 분명하지 않았다.

## 2. 선택지

| 안 | 내용 | 트레이드오프 |
|---|---|---|
| A | 첫 출시를 한 PC 안으로 한정 — 원격 제어·웹 검토 모두 후속 확장 | 서버·인증·중계 없음. 외부 검토자는 HTML 패키지(FR-14) 열람까지, 코멘트를 돌려받는 경로는 없음 |
| B | 웹 검토를 파일 교환으로 첫 출시에 포함 | 서버 없이 코멘트를 돌려받음. 내보내기·반입·기준 버전 대조·중복 방지가 첫 출시에 들어옴 |
| C | 온라인 제출까지 첫 출시에 포함(ADR-007) | 검토자 경험이 완결됨. 중계 서비스·인증·동기화·재접속이 첫 출시에 들어옴 |
| D | 원격 제어까지 첫 출시에 포함 | 다른 기기에서 조작. 중계·세션·권한 모델이 커짐 |

## 3. 결정

**A. 첫 출시는 한 PC 안에서 끝난다.** Rhino·ZWCAD, 로컬 서비스, AI 실행, 화면이 같은 컴퓨터에 있다.

- 제품 형태는 **로컬 설치형**이다. UI·로컬 서비스·호스트 애드인이 한 PC에서 동작한다. 화면을 브라우저 탭으로 띄울지 데스크톱 창으로 감쌀지는 기술 선택이라 PLAN이 정한다(ADR-004 0.2와 같은 결정).
- **원격 제어**(다른 기기에서의 조작)는 첫 출시에서 뺀다 → 후속 확장. 원격 접속은 같은 로컬 서비스에 중계를 붙이는 확장 경로다.
- **웹 검토**(FR-19: 브라우저에서 보고 코멘트 제출)는 온라인 제출·파일 교환 모두 첫 출시에서 뺀다 → 후속 확장. HTML 검토 패키지 내보내기(FR-14)는 유지한다. 코멘트를 돌려받는 경로는 후속이다.
- FR-19가 후속 확장인 동안 AC-19·AC-28은 해당 없음이다. AC 행 자체는 유지한다.
- OQ-04는 후속 확장 착수 시 결정한다. 막는 산출물은 없다(첫 출시 범위 밖).
- PRD §12.5의 웹 참여 서술은 제품 전체 개념으로 그대로 둔다.
- ADR-007(웹 검토 — 온라인 제출까지 MVP)은 이 ADR이 대체한다.

## 4. 근거

첫 출시의 가치는 한 PC 안에서 AI가 호스트를 제어하는 흐름(PRD §2 가설 1·3·5)에서 나온다. 원격 제어와 웹 검토는 둘 다 로컬 서비스 바깥의 중계·인증·동기화를 요구하고, 1인 개발에서 첫 호스트 수직 슬라이스와 시간을 다툰다. 로컬 서비스를 기준으로 두면 두 확장이 같은 경로(중계)로 붙으므로 첫 출시의 구조를 나중에 바꾸지 않는다.

## 5. 결과 — 적용 시 바꿀 문장

- PRD §1.1: 제품 형태 근거 2~3문장. "독립 Windows IDE" → "로컬 설치형(한 PC에서 UI·서비스·애드인이 동작)". §0 요약표 '주 사용 환경' 행도 같은 표현, '외부 참여' 행 경계 칸은 "후속 확장(§14.2)".
- PRD §1.3: 개념은 유지하고 원격 접속은 "같은 로컬 서비스에 중계를 붙이는 확장 경로"라는 한 문장만 둔다.
- PRD §13 FR-19 범위 값 '제공 범위 미정' → '후속 확장'(한정어 '제품 요구.' 유지). §14 첫 문단에 "첫 출시는 한 PC 안에서 동작한다". §14.1 외부 웹 행: 요구 능력 "후속 확장(FR-19)", 미결 "OQ-04(후속 확장 착수 시)". §14.2: 미정에서 FR-19 제거, 제외에 "원격 제어(다른 기기에서의 조작)"와 "웹 검토(FR-19, 온라인 제출·파일 교환 모두)" 추가. §15 머리에 "FR-19가 후속 확장인 동안 AC-19·AC-28은 해당 없음". §18 OQ-04 행: 결정 시점 "후속 확장 착수 시 · 결정: ADR-010", 막는 산출물 "없음(첫 출시 범위 밖)".
- Design §12 SCR-06 웹 검토 행: 관련 FR 칸에 "후속 확장(ADR-010)". 행은 유지.
- ADR-007 status → superseded. ADR-004 0.2 근거에서 웹 뷰어 공유 근거 제거.

## 6. 재검토 조건

- 외부 검토자가 HTML 패키지를 보고 낸 코멘트를 손으로 옮기는 부담이 첫 출시 사용에서 반복해 확인되면 웹 검토의 착수(파일 교환부터)를 검토한다.
- 다른 기기에서의 조작 요구가 실제 여정에서 나오면 원격 제어를 같은 로컬 서비스의 중계로 검토한다.
- 어느 쪽도 첫 출시 조건을 되돌리지 않는다.
