ADR-012 · 목표 — 두 기준선 대비 개선

01 / 배경

PRD §14.3의 alpha 판정 관문과 축소 조건이 이견(PRD R-59·R-71)으로 남아 있었다. Claude 안은 축소 조건을 지금 고정하는 것(재사용률 미달 → 호스트 수 축소, 핀 오인 미감소 → 자체 뷰 제외 등), Codex 안은 측정 범위·판정 시점·허용 오차·실패 대안을 사전에 정하고 사용자 재결정 지점으로만 두는 것이었다. ADR-001 §6·ADR-004 §6·ADR-007 §5가 각자 축소 조건을 두어 판정이 세 곳에 흩어졌고, §16.2의 비교 대상은 "수작업 또는 익숙한 CLI 작업 흐름"으로 느슨했다.

02 / 선택지

안 내용 트레이드오프
A 판정 관문 — 수치 조건 미달 시 자동 축소 결정이 빠름. 시험 미완료와 실패를 구분하지 못하고 부분 지표 하나로 다른 가치를 부정할 수 있음
B 목표 — 두 기준선 대비 개선을 목표로 두고, 미달은 사용자 재결정 시점 자동 축소 없음. 판정 절차·시점은 PLAN이 따로 정해야 함
C 목표 없이 시험만 비교 대상이 없어 가설 검증 불가

03 / 결정

B. "판정 기준"이 아니라 "목표"다.

  • 같은 기준 과업(ADR-006 ①)을 (1) 손으로 했을 때, (2) Claude·Codex 같은 에이전트를 MCP로 Rhino에 붙여 그냥 썼을 때와 비교해, VIDE로 했을 때 총시간이 짧고 대상 오인·재작업(헛수고)이 적어야 한다.
  • 정본은 PRD §16.1이다. §2 가설 1·5의 비교 대상에 "에이전트+MCP" 기준선을 추가한다.
  • 미달은 자동 축소가 아니라 사용자의 재결정 시점이다. 판정 절차와 시점은 PLAN §6·§9가 정한다.
  • ADR-004의 축소 조건은 없애고(0.2 "없음 — 목표는 ADR-012"), ADR-006의 기준선은 두 개로 보완한다(0.2). ADR-007은 ADR-010이 대체하므로 그 축소 조건은 사라진다.

04 / 근거

가설 1·5는 비교 없이 검증할 수 없다. 수작업 기준선만으로는 "AI를 붙였다"는 효과와 VIDE 고유의 구조(핀·스케치·후보·개입) 효과가 섞이므로, 에이전트+MCP 기준선이 VIDE의 몫을 분리한다. 자동 축소는 시험 미완료와 실패를 구분하지 못하고 부분 지표 하나로 다른 가치(호스트 부재 열람·후보 비교)를 부정할 수 있어, 미달을 재결정 시점으로 둔다.

05 / 결과 — 적용 시 바꿀 문장

  • PRD §16.1에 이 목표를 두 기준선과 함께 적는다(정본). §2 가설 1·5의 비교 대상에 "에이전트+MCP" 추가.
  • PRD §14.3의 "alpha 판정 관문과 축소 조건은 미결이며(R-59·R-71, …)" 항목을 "첫 호스트 alpha의 목표는 §16.1이다. 미달은 자동 축소가 아니라 사용자의 재결정 시점이며, 판정 절차와 시점은 PLAN §6이 정한다."로 교체.
  • ADR-006 0.2: 두 기준선, "판정 기준이 아니라 목표(ADR-012)". ADR-004 0.2 §6: "없음 — 목표는 ADR-012".
  • PLAN §6.2의 관문 참조를 이 ADR로 바꾸고, PLAN §9에 alpha 판정 절차·시점을 결정 항목으로 둔다. 측정 항목(총시간·대상 오인·재작업)의 절차는 PLAN §7.2가 소유한다.
  • ADR-001 §6의 축소·재검토 조건과의 정합은 별도로 확인한다.

06 / 재검토 조건

  • 기준 과업 ①에서 두 기준선 중 하나를 같은 조건으로 재현할 수 없으면(예: 에이전트+MCP 경로가 해당 호스트에서 불가) 그 기준선의 대체 방법을 사용자가 정한다.
  • 기준선의 오인·재작업이 0인 과업에서는 목표 문장을 다시 쓴다.

07 / 출처
