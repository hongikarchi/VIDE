# ADR-002 · 작업자·배포·입력 환경

## 1. 프로젝트별 제어 환경

첫 출시는 프로젝트별 하나의 로컬 작업환경이 연결된 호스트 제어와 원본 반영을 담당한다. 그 환경은 Rhino와 ZWCAD의 복수 연결·연계·독립 작업 병렬 실행을 수행한다. 하나의 로컬 작업환경을 하나의 활성 호스트로 해석하지 않는다.

여러 사람이 각자 설치해 독립 프로젝트를 사용하는 것은 제한하지 않는다. 같은 프로젝트를 여러 PC에서 공동 제어하고 원본 변경을 조정하는 기능은 후속이다. 외부 참여자는 ADR-010의 웹 검토 역할로 참여한다.

## 2. 첫 배포 대상

개발 소유자와 선정된 소수의 검증 사용자에게 제한 배포한다. 선언한 Windows·호스트 환경에서 설치하여 사용할 수 있어야 하며, 개발 환경 밖에서도 설치·최초 연결·기본 작업·저장·재개·제거와 작업 자료 보존을 확인한다.

검증 인원·장비·설치 방법은 SPEC·PLAN에서 정한다. 소유자 PC 성공만으로 배포를 검증하지 않는다. 제한 배포를 이유로 웹 공유·의견이나 두 호스트 제어 등 확정 기능과 데이터 보호를 제외하지 않는다.

사내 전체 배포와 불특정 사용자 공개 배포의 운영 범위는 후속으로 둔다. 서명·설치 권한·업데이트·서비스 이용 조건 등 구체 방법은 실제 배포 환경에 맞춰 PLAN에서 정하며, 이 결정만으로 필요 없다고 단정하지 않는다. 호스트 SDK와 서비스의 허용 범위는 OQ-09에서 관련 배포 전에 확인한다.

## 3. 입력 환경

Windows 로컬 IDE는 키보드·마우스로 선택·핀·스케치·검토·제어를 제공한다. 로컬 펜 입력은 금지하지 않지만 첫 출시의 필수 구현·검수 범위로 선언하지 않는다.

외부 웹은 선언한 iPad 환경에서 터치 탐색과 펜 스케치를, Mac·Windows의 지원 브라우저에서는 키보드·마우스를 제공한다. 펜 없이도 기본 열람·의견 작성이 가능해야 한다. 모든 펜의 필압·기울기·버튼을 지원한다는 뜻이 아니다. 기기·브라우저·제스처·입력 동작은 OQ-04와 SPEC에서 선언하여 시험한다.

## 4. 선택 이유

실제 프로젝트와 검증 사용자에게 제공할 기능은 유지하면서 설치 환경과 공동 원본 제어의 범위를 제한한다. 여러 로컬 설계자의 공동 제어와 원격 AI 실행은 웹 의견 작성과 다른 능력이므로 함께 포함하지 않는다. 펜 지원은 실제 검토용 iPad 사용에 우선 배정한다.

## 5. 기준 문서와 후속 명세

제품의 정본은 PRD §14.4이다. SPEC은 지원 환경·설치/미지원 동작·역할·기기별 입력을 구체화한다. Design은 로컬 키보드·마우스와 웹의 기기별 표현을 구분한다. PLAN은 설치·배포·검수 방법을 정한다.
