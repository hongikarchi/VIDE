# ADR-008 · 확장 계약 후속화, 첫 스킬 = 일람표 작성

## 1. 배경

FR-13·§14.3·AC-26은 검증용 소확장(선택 객체 속성 요약)으로 확장 계약을 MVP 완료 조건에 넣지만, §2 어느 가설도 검증하지 않고 확장 작성자는 당분간 소유자 본인이며, 실제 스킬 없이 정한 manifest·권한·격리 계약은 첫 스킬에서 재작성될 가능성이 크다(PRD R-54). 확장의 실행 형태(절차형 스킬 / 외부 프로세스 도구 / 프로세스 내 코드)도 미결이다.

## 2. 선택지

| 안 | 내용 | 트레이드오프 |
|---|---|---|
| A | FR-13을 후속으로 내리고 첫 실제 스킬(일람표)로 계약을 검증 | MVP가 작아지고 계약이 실소비자로 검증됨. '플랫폼' 정체성은 코드 구조 제약으로만 유지 |
| B | 실제 스킬 1개를 MVP 확장으로 지정 | 계약과 §2 가설 2행을 함께 검증. MVP가 커짐 |
| C | 현행 유지(검증용 소확장) | 계약이 단일 사례 추상화로 굳음 |

## 3. 결정

**A.** FR-13과 §14.3 완료 조건을 후속 확장으로 내린다. "어댑터/스킬 경계를 코드 구조로 유지한다"는 PLAN의 아키텍처 제약(별도 ADR)으로 옮긴다.

- **첫 스킬은 일람표 작성**(§4.2)이다. 기준 과업 ①(ADR-006)의 면적·일람표 갱신이 그 최소형이므로, MVP 안에서는 공통 기능으로 만들고 MVP 뒤 첫 확장으로 분리하면서 FR-13 계약을 실제 소비자로 정의한다.
- OQ-07(초기 확장의 신뢰·배포 범위·결과 종류)에 '실행 형태' 항목을 추가하고 결정 시점을 첫 스킬 분리 시점으로 미룬다.

## 4. 결과 — 적용 시 바꿀 문장

- PRD FR-13 범위 값 'MVP 최소 계약' → '후속 확장', §14.3 삭제 또는 후속 절로 이동, AC-26 해당 없음 표기, OQ-07 항목·시점(이 ADR 링크), §4.2 일람표 행에 "첫 스킬" 표기.
- Design §09 확장 화면은 후속으로.
