08 / 권장안과 결정이 필요한 질문

2026-10-01 사용자가 아래 질문을 결정했다. 결정과 반영 위치는 ADR-026이며, 이 절은 결정 전의 권장안 기록으로 둔다.

8.1 권장안 (결정 아님)

  1. 목표 구조: 안 1(대화 열 + 무대 하나)을 뼈대로 하고, 안 2의 상시 연결 점·접히는 왼쪽 슬롯·[원래대로]·ui_go, 안 3의 턴 블록 문법·'대기' 묶음·프로젝트 보드를 접붙인다(§6.1).
  2. jig = skill: VIDE 내부 계약으로 정의하고, 기존 skill.md·jig.json v3에 필드를 얹는다. 러너는 거의 그대로 쓴다(§6.3).
  3. 시각: 참고 앱 A식 무채 웜 그레이 틀 + 고정 코랄 포인트를 허용 목록 6곳에만 쓴다. 토큰층과 별칭부터 시작한다(§3).
  4. 순서: 단계 0(멈춤 해소)과 단계 1(토큰 별칭)을 지금 레이아웃에서 먼저 한다. 목업으로 구조를 확인한 뒤 셸을 교체한다(§7.2).

8.2 결정이 필요한 질문

# 질문 선택지 권장
Q1 채팅이 jig로 판정되면 어떻게 할까 (a) 지금처럼 제안 카드 유지 (b) 카드는 두되 [열기]가 작업본·탭·대화·autorun까지 실제로 연다 (c) 자동으로 열고 계산까지(자동 모드), 사후 [일반 대화로]로 교정 (c). 계획 모드는 열기까지만 한다. SPEC-02.17·02.19, RESEARCH-10 B7을 뒤집으므로 ADR-026이 필요하다
Q2 시각 언어를 어디까지 바꿀까 바탕: 웜 그레이(참고 앱 A) / 세이지 유지. 포인트: A 고정 코랄 / B 프로젝트별 / A + 프로젝트 점. 본문: 12 / 13 / 14px. dark: Rhino 패널 전용 유지 / 앱 전체 테마 선택 웜 그레이 + A + 프로젝트 점, 13px, dark는 패널 전용 유지. Design §02 :49 동결 해제가 필요하다
Q3 화면 구조를 어디까지 바꿀까 (a) 지금 배치에서 정리만(안 2에 가까움) (b) 대화 열 + 무대로 전환(권장안) (c) 런 피드(안 3) (b). 다만 목업 확인 뒤에 한다. 2026-09-29 Blender식 탭 결정을 되돌리는 것이다. 대화 열 위치는 지금처럼 오른쪽이 이행 비용이 작고, 왼쪽이 '대화가 이끈다'는 인상이 강하다
Q4 어떤 jig를 AI·Jev가 자동으로 부를 수 있게 할까 (a) 공식 jig만 (b) 공식 + 검증(L3) 이상 설치 jig (c) (b) + 프로젝트 jig(s06-frame 같은) (d) 전부. 초안은 늘 user-only (c). "구조 분석"이 S-06에서 s06-frame으로 가려면 필요하다. ADR-020 B11 재검토 대상이다
Q5 작업본이 없을 때와 계획 모드에서의 열기 레이어: (a) 한 번 묻기 (b) VIDE/{jig}/{n} 기본값 자동 (c) 레이어 없이 계산하고 만들기 때 묻기. 계획 모드의 새 작업본 생성: 허용 / 기존 재사용만 레이어는 (b) 또는 (c). 계획 모드는 기존 재사용만 허용하고, 없으면 체크리스트에 '작업본 만들기'를 포함한다
Q6 "구조 분석"의 1순위 레거시 구조 분석(J-09) / 프로젝트에 s06-frame이 있으면 그것 / 레거시 퇴역 프로젝트 jig 우선(RESEARCH-10 §8.8). 레거시는 '열기만 자동' 어댑터로 둔다
