# 도면 생성기와 모델 → CAD 역반영

2026-10-07 사용자 결정("JIG 기능을 상세히 계획")의 도면 생성기·역반영 부분이다. 동작은 [SPEC-14](../specs/SPEC-14-drawing-generator.md), 실험 근거는 [SPIKE-2026-10-07-drawing-export](../tdd/SPIKE-2026-10-07-drawing-export.md), 선행 구현은 [PLAN-43](PLAN-43-section-finish-xref-submit.md) T-199(실험)·T-200(xref 그래프·표시)·H-ZWCAD-13(숨은 ZWCAD 충돌 안내 응답)이다.

## 착수 조건과 범위

- **제품 결정:** 2026-10-07 사용자가 C-08을 채택했고 PRD §4.4·§14.2에 반영했다. 제품 티켓은 PRD 채택을 더 기다리지 않는다. 사용자가 계획을 먼저 검토하기로 했으므로(PLAN-44) T-225·T-226부터 검토 뒤 시작하고, 아래 「결정이 필요한 질문」은 그 검토에서 바꾸지 않으면 기본값으로 진행한다.
- **범위:** Rhino 8 → DWG 2018 출력, ZWCAD 2023 숨은 실행의 정리·병합·역반영, mm 도면. AutoCAD·Revit, Make2D 투영 생성(T-231 결과 전), 3D 투영 갱신은 제외(SPEC-14.13).
- **원칙(AI.md §8):** 숨은 호스트는 VIDE가 띄우고 사본만 연다. 시험은 `.vide/` 아래의 합성 3DM·DWG만 쓴다. 사용자 원본과 사용자 호스트 창은 쓰지 않는다. 실호스트 시험은 호스트가 없으면 건너뜀으로 표시한다.
- **기술 계약:** 숨은 Rhino 내보내기 명령, ZWCAD worker 명령, 출처 표시(xdata)·반영 기준 저장 형식은 [ARCH-01](../architecture/ARCH-01-system.md)에 「도면 생성기(PLAN-47)」 절로 추가한다(T-226에서 시작, 티켓마다 보완).

## T-225 SPIKE: ZWCAD 정리 연산·xref 재부착·출처 표시 보존

- **기준:** SPEC-14.5·14.8, SPIKE-2026-10-07-drawing-export의 「한계」, H-ZWCAD-12·13.
- **위치:** 코드 `tools/spikes/YYYY-MM-DD-dwg-cleanup/`(실행하는 날), 기록 `docs/tdd/SPIKE-YYYY-MM-DD-dwg-cleanup.md`(실행하는 날 만든다).
- **질문:**
  1. 사이드 DB(`ReadDwgFile` 쓰기 모드 → `SaveAs` 2018)에서 치수 문자 `<>` 복원, 반지름·지름 DIMASZ 개체 재정의 제거, 정렬 치수로 교체, 문자 스타일 글꼴 이름 교정, 빈 레이아웃 삭제, 뷰포트 `On=true`가 되는가. ZWCAD 화면에서 연 결과(글꼴 대체·뷰포트 표시·치수 배치)가 맞는가(사본을 에이전트가 띄운 ZWCAD로 연 뒤 종료).
  2. 사이드 DB에서 `AttachXref` + 블록 삽입 교체가 되는가, 상대 경로로 저장되는가, 다시 열 때 해석되는가.
  3. Rhino 객체의 이름·사용자 문자열이 DWG 2018 Natural 출력에 xdata 등으로 남는가. 남지 않으면 내보내기 목록(객체 ID → 유형·레이어·기하 지문)과 출력 개체의 정확 일치로 짝을 찾을 수 있는가(좌표 오차·순서).
  4. ZWCAD 2023의 `Dimension.TextStyleId` 접근 위반처럼 Rhino 출력에서 죽는 속성 목록을 넓혀 확인한다(치수·MText·해치·뷰포트 속성 일괄 읽기).
  5. 블록 정의 교체(모델 기하 블록 재정의)와 xref 도면 교체 중 역반영 대응이 유지되는 쪽.
- **방법:** SPIKE-2026-10-07의 `build-model.py`·`run.mjs`를 재사용해 합성 출력 DWG를 만들고, probe를 쓰기 모드로 확장한다. 매 실행 뒤 띄운 호스트 종료와 충돌 덤프 0건을 확인한다.
- **완료:** 질문별 가능/불가/우회와 ZWCAD 결함 목록을 기록하고, T-229·T-230·T-232의 방식(정리 규칙별 구현 가능 여부, 출처 표시 방식)을 확정한다.
- **실패 처리:** 1의 일부가 불가하면 SPEC-14.5의 해당 규칙을 '보고만'으로 바꾸는 SPEC 수정안을 낸다.

## T-226 선행: 숨은 호스트 견고성과 출력 경로 정책

- **기준:** SPEC-14.13 실패 1·2, SPEC-14.14의 1, PRD §11.2, H-RHINO-08, H-ZWCAD-09·13.
- **변경:**
  - 숨은 실행 공통: 생성기 작업마다 숨은 Rhino·ZWCAD를 `launchHiddenZwcad`(기존)와 같은 방식으로 띄우고, 시간 상한·중단·종료 확인·충돌 덤프 처리를 한 곳에서 한다. 비정상 종료 코드와 마지막 단계를 진단 로그에 남긴다.
  - ZWCAD worker에 T-225 4의 위험 속성 회피 목록을 넣는다(읽지 않거나 안전한 대체 API).
  - **출력 경로 정책:** 엔진이 발급한 출력 토큰(작업 폴더 또는 사용자가 확인한 출력 경로 + 파일 이름 집합)을 가진 worker 명령만 `SaveAs`·내보내기·`AttachXref`를 할 수 있게 한다. 경로는 토큰 밖이면 거절, 이미 있는 파일이면 거절(덮어쓰기 금지).
  - AI 코드 정책은 바꾸지 않는다: `SdkCompiler`의 `Save`·`SaveAs`·`AttachXref` 등 금지, Rhino `CodePolicy`의 저장·내보내기 금지를 그대로 두고 시험으로 고정한다.
  - ARCH-01에 「도면 생성기(PLAN-47)」 절을 만들고 출력 토큰·worker 명령 목록을 적는다.
- **선행:** 없음(T-225와 병렬).
- **검증:**
  - 정상: 토큰 경로에 쓰기 성공, 다시 읽기.
  - 실패: 토큰 밖 경로·기존 파일·AI 코드의 `SaveAs`/`AttachXref`/`Export`가 모두 거절(`tests/core/` 정책 시험, 실호스트 시험은 없으면 건너뜀). 숨은 호스트 강제 종료 시 작업이 실패로 끝나고 원천·템플릿 파일 해시가 그대로.
- **완료:** 시험 통과, 호스트 지원표에 생성기용 행(H-RHINO·H-ZWCAD 새 번호) 추가.

## T-228 Rhino → DWG 내보내기 경로

- **기준:** SPEC-14.4, SPIKE 권고(2018 Natural, `_-SaveAs`만 레이아웃 보존).
- **변경:**
  - Rhino 연결 플러그인: 원천 문서의 스냅숏을 엔진 작업 폴더에 3DM 사본으로 쓴다(`Write3dmFile` 계열, 문서 경로·수정 상태 불변). 닫힌 문서는 파일 사본.
  - 숨은 Rhino worker 명령: 사본을 열고 전용 스킴의 2018 Natural로 `_-SaveAs`(출력 토큰 경로), 내보내기 목록(객체 ID → 유형·레이어·레이아웃·기하 지문, 디테일 축척)을 함께 쓴다. 사용자 스킴은 바꾸지 않는다.
  - 지원 밖 객체(3D 등)는 내보내기 전에 세어 보존 보고에 넘긴다.
- **선행:** T-226.
- **검증:** 합성 3DM(SPIKE의 `build-model.py` 기반)으로 레이아웃·축척·레이어·개체 수가 SPIKE 표와 같음. 실패: Rhino 없음(건너뜀 표시), 스냅숏 쓰기 실패, 시간 초과 → 실패 보고·호스트 종료. 사용자 Rhino 창 문서의 경로·수정 상태 불변.
- **완료:** 엔진에서 출력 DWG와 목록이 만들어지고 시험 통과.

## T-229 ZWCAD 정리 패스

- **기준:** SPEC-14.5·14.6, T-225 결과.
- **변경:** ZWCAD worker 명령 `VIDEDRAWINGCLEANUP`(출력 사본만): 치수 `<>` 복원(값이 측정값과 같을 때), 반지름·지름 DIMASZ 재정의 제거, 정렬 치수 교체(가능한 경우), 글꼴 이름 교정(내보내기 목록의 원천 스타일 기준), 추가 빈 레이아웃 삭제, 대응 뷰포트 켜기, 링크 블록 → xref 재부착(대상 DWG가 있을 때). 각 규칙의 적용·미적용 수를 돌려준다. 엔진은 출력을 다시 읽어 보존 보고를 만든다.
- **선행:** T-225, T-228.
- **검증:** 합성 출력에서 규칙별 전·후 값(치수 문자, DIMASZ, 글꼴, 레이아웃 수, 뷰포트 On, xref 여부). 실패: 대상 xref 없음 → 일반 블록 유지·보고, 사용자 문자 `ROOM <>` 같은 접두 유지, 정리 중 호스트 종료 → '정리 안 됨'·저장 불가.
- **완료:** SPIKE 표의 '변형·소실' 항목마다 고침 또는 보고가 시험으로 확인된다.

## T-230 템플릿 병합

- **기준:** SPEC-14.4의 2(방식 C)·14.3의 3·14.2(모델 기하·출처 표시).
- **변경:** ZWCAD worker 명령 `VIDEDRAWINGMERGE`: 템플릿 사본에 정리된 출력의 모델 기하를 넣는다(결정 질문 6: 기본 xref 도면, 대안 블록). 레이어 대응 적용, 대응 시트 레이아웃의 뷰포트 중심·축척 설정, 도곽 속성(도면명·축척) 채우기, 개체마다 출처 표시(T-225 3의 방식), 도면 출처 표시(원천 연결 ID·템플릿·생성 시각·판).

## T-232 역반영 차이 계산

- **기준:** SPEC-14.8~14.10·14.12.
- **변경:** 핵심 모듈 `src/core/drawing-backflow.ts`(가칭): 대응(출처 표시 / Sync jig 일치 행), 반영 기준(대응마다 원천 지문·도면 개체 지문·Handle) 저장, 행 분류(추가·수정·삭제·충돌·끊김·지원 안 함), 좌표 환산(생성 변환 / Sync jig 관계), xref 소유 파일 해석과 삽입 변환 사슬 역적용(T-200 `xref-graph.ts`), 레이어 결정. 프로젝트 DB 표에 반영 기준. 도면 읽기는 기존 Sync·`queryEntities`(열림)나 숨은 ZWCAD 사본 읽기(닫힘).

## T-233 역반영 적용 경로

- **기준:** SPEC-14.11, ADR-022·027, H-ZWCAD-04·06·09·10.
- **변경:**
  - ZWCAD 쓰기 능력 확장(`hosts/zwcad/worker/DwgEditor.cs`, 연결 플러그인의 바로 실행 경로): 지금의 mm 직선 폴리선·LINE에 더해 호 포함 폴리선(bulge), ARC, CIRCLE, 블록 삽입의 위치·회전, 출처 표시가 있는 치수의 정의점. 개체 속성(레이어·색·선종류·Handle) 보존. 이것은 엔진의 반영 연산이며 AI 코드 정책은 바꾸지 않는다.
  - 열린 연결 도면: 행 목록을 파일별 바로 실행 하나(되돌리기 기록 하나)로 적용, 여러 파일은 ADR-027 규칙(하나라도 실패하면 이미 적용한 파일 되돌림), 적용 뒤 다시 읽기.
  - 닫힌 도면: 숨은 ZWCAD가 사본에 적용해 출력 토큰 경로에 새 파일로 쓴다(T-226).

  - 반영 기준 갱신은 적용 확인된 행만, 되돌리기 시 이전 기준 복원.
- **선행:** T-226, T-232.
- **검증:** 실호스트(없으면 건너뜀) 합성 도면에서 유형별 수정의 Handle·레이어 유지, 되돌리기 한 번에 원상, 두 파일(루트+xref) 중 하나 실패 시 둘 다 원상, 결과 불명확 시 재적용 없음. 닫힌 도면은 원본 해시 불변·새 파일 생성.
- **완료:** H-ZWCAD 지원표에 역반영 행 추가, 시험 통과.

## 검수 계획 (T-234에서 실행)

`docs/tdd/VERIFY-YYYY-MM-DD-drawing-generator.md`. 관련: SPEC-14, AC-24·30·33·38, 새 H-RHINO·H-ZWCAD 행.

1. 합성 3DM(레이아웃 2개, 치수 6종, 한글 문자, 링크 블록) + 합성 템플릿 → 미리보기 → 저장. 출력 DWG를 사본으로 ZWCAD에서 열어 화면 확인(뷰포트·글꼴·치수 연동·xref 해석), 보존 보고와 대조.
2. 원천에서 선 이동·호 반지름 변경·객체 추가·삭제 → 열린 생성 도면에 반영 → Handle·레이어 유지, 되돌리기, 저장은 사용자 몫.
3. 도면에서 손 수정한 개체 → 충돌 표시, 지운 개체 → 끊김.
4. 루트 + xref 2개 합성 도면 → xref 소유 개체가 자식 파일에만 쓰임, 닫힌 자식은 새 사본.
5. 실패 주입: 숨은 ZWCAD 종료, 템플릿 단위 불일치, 출력 경로 기존 파일.
6. 시간: 시트 10장 생성·반영 100행의 소요를 기록(상한은 관찰 뒤 정한다).
