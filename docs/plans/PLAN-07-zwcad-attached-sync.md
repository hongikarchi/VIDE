# 현재 ZWCAD 연결

사용자의 2026-09-28 지시에 따라 현재 열린 `260923 기본도면.dwg`의 읽기 연결을 우선 완성한다. Rhino·공통 UI 작업과 별도 작업 트리를 쓰고 ZWCAD 어댑터 중심으로 구현한다. 제품 목표는 PRD FR-02·03·16, 동작은 ZWCAD 호스트 계약 §1.1, 기존 연결 구조는 ARCH-01을 따른다.

## 구현 순서

1. 설치된 ZWCAD 2023 .NET SDK로 현재 문서 연결 명령과 PaletteSet 패널을 만든다. 연결/해제·Sync·선택형 Live Sync·VIDE 열기를 제공한다.
2. 문서별 인증된 로컬 연결을 기존 프레임 TCP로 전달한다. 프로세스 시작 시각·연결 UUID·문서 식별자로 다른 창/도면과 구분한다. 주 스레드에서 읽고 원본 수정·저장·종료를 하지 않는다.
3. 기존 ZwcadEditors에 연결 발견·메타데이터 조회·직접 표시 취득을 추가한다. 현재 작업 도면의 선·곡선·블록을 표시하고 미표현 유형 수를 반환한다. 편집용 DwgReader의 제한을 읽기 표시의 선행 조건으로 쓰지 않는다.
4. 문서 목록의 기존 공통 경로에 CAD를 포함한다. 공통 UI의 수정은 연결 호스트 명칭 같은 필요한 부분으로 제한하며 다른 세션 변경을 덮어쓰지 않는다.

## 검증과 완료 기준

별도 소유 합성 CAD에서 연결·해제·다중 도면 구분·틀린 토큰 거절·알 수 없는 실행 메서드 거절·직접 표시·선택·변경 뒤 세대 증가를 검증한다. 사용자 작업 도면은 연결/조회/표시만 수행하고 DBMOD·파일 이름·단위를 보존한다. 실제 제품 브라우저에서 도면 표시까지 확인하며 미지원 표시를 알린다. 원본 AI 편집 지원은 이번 읽기 연결 성공과 구분한다.

ZWCAD 애드인 재로드가 불가능하면 검증 빌드를 먼저 완성하고 사용자 문서 종료 없이 최초 로드를 시도한다. 이미 로드된 이전 애드인의 교체가 필요한 경우에만 저장·재시작을 요청한다. Rhino 창·기존 서버를 임의 재시작하지 않고 별도 포트·데이터로 시험한다.

## 진행

별도 .NET 연결 플러그인·패널·문서 발견·읽기 Sync를 구현했다. 합성 CAD의 브라우저 표시·재열기·Live Sync·다중 도면·오류 경계는 통과했고 실제 사용자 창의 패널/연결도 확인했다. [검수](../tdd/VERIFY-2026-09-28-zwcad-attached-sync.md). 실제 기본도면은 이전 DLL에서 SDK 읽기 실패·수백 MB 외부참조 응답·시간 초과가 발생했다. 네이티브에서 실패 객체와 표시 데이터 폭증을 분리한 수정본은 큰 합성 블록 뒤의 정상 객체 표시까지 통과했다.

최신 Rhino/UI/스케치 변경과 병합하고 관련 브라우저 회귀를 통과했다. 사용자 재시작 후 수정 DLL을 배치해 현재 기본도면의 실제 제품 Sync와 새로고침 후 표시 복원을 확인했다. 3,841개 중 3,369개를 표시했고 472개는 숨김·미지원 등으로 제외했다(대형 블록 14개 포함). 기존 서버와 분리한 로컬 시험 포트 63703에서 검수했다. 다음은 대형 외부참조의 공유 기하/인스턴싱과 문자·해치 표시 보완이다. 현재 사용자 CAD의 AI 편집은 별도 남은 작업이며 읽기 연결 성공만으로 완료 처리하지 않는다.
