구조 분석 jig(J-09) 1단계 — 계획 단계 중력 검토

00 / 목적과 기준

CAD·Rhino로 받은 강구조를 해석 모델로 구성·확정하고, 선형 정적 해석과 KDS 14 31 10 부재 검정 결과를 근거와 함께 보이는 흐름을 실제 입력에서 끝까지 연결한다. 동작은 SPEC-06, 계약은 ARCH-02, 결정은 ADR-019, 자산과 검증 근거는 RESEARCH-08·RESEARCH-09를 따른다.

제외(이 계획 1단계 기준. 현행 범위 밖 목록은 SPEC-06 §14, 이어지는 작업은 아래 절): 배치 → 구조 자동 생성, 가새·지붕 수평가새 배치 규칙, 최종 점검 모드(풍·지진·전체 조합·P-Δ·모드 해석), 편집 재검토·영향 전파, 강재량 대안 비교·최적화, 계산서·일람표 문서, 프로젝트별 교환 형식(MGT 등), EJ·기초.

선행 조건: Rust stable(1.98.1, rustup, 2026-09-29 설치)과 VS Build Tools 2026의 MSVC·Windows SDK. Node 24.15.0. 데스크톱 패키지는 Python을 포함하지 않는다.

01 / 티켓

  • 방법: src/native/structure/에 최소 crate를 만들고 faer 희소 분해로 합성 3D 골조(약 12,000 자유도, 조합 23개 우변)를 푼다. 애드온 로드와 exe 호출을 각각 재고, 데스크톱 빌드가 산출물을 포함할 수 있는지 확인한다.
  • 기록: docs/tdd/SPIKE-2026-09-29-structure-core-binding.md.
  • 종료 조건: 애드온이 빌드·로드되고 풀이가 대칭 모델에서 평형을 만족하면 애드온으로 확정하고 ARCH-02 §1을 갱신한다. 막히면 exe로 전환한다.

03 / 이어지는 작업(2026-09-29)

FR-23 확장(결정 A1)과 RESEARCH-10 §10의 결함 조사에 따라 구조 해석의 다음 작업은 새 계획의 티켓으로 옮긴다. 이 계획은 T-033~039만 추적한다.

  • PLAN-23:
    • J-09의 라이브러리화와 결함 수정은 T-052다. 설계 부재 기준 Lb·K와 참고 처짐(결정 A8), 수평 구속 절점 지정, 곡선만 분할, 요약·미확정 미리보기(결정 A6), 작업 스레드 실행, 강재 자중, structure-draft-review 인용 검사가 들어간다.
    • 단면 선정·단면 성질·부호·일람표·CSV는 T-054다.
    • Rust 코어 확장(설계 부재 판정, 여러 조합의 한 번 분해 등)은 2차 T-067이다.
    • 위 제외 목록 가운데 배치 자동 생성·단면 선정·일람표·기초 간섭·E.J. 분절은 FR-23 확장 범위로 S-06 골조 jig(T-044·051·053·056)와 T-054가 맡는다.
  • PLAN-22: 작업본·화면 부품·겹침 층·Rhino에 만들기 같은 jig 공통 기능을 맡는다.

04 / 순서와 의존

T-033 → T-034 → T-035 → T-036 순서로 코어를 먼저 완성한다. T-037의 입력 구성과 T-038 화면은 T-034 계약이 정해지면 코어와 병행할 수 있다. T-039는 앞의 티켓이 끝난 뒤 한다.

05 / 검증 원칙

  • 수치는 fixture로만 통과를 판정한다. 기대값은 교과서·공개 벤치마크 값을 스스로 다시 유도해 넣고 출처를 적는다(저작권 문서 복사 금지).
  • PyNite 교차 검증은 개발 전용이다. 생성한 기대값 파일에 PyNite 버전과 생성일을 적는다.
  • 사용자 원본 문서를 호스트로 열지 않는다(AI.md §8).
