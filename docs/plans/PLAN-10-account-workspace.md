# 계정 웹사이트 — 로그인·프로젝트 목록·작업 PC 열기

2026-09-28 사용자 지시: Figma처럼 웹사이트에 로그인하면 계정의 프로젝트 목록이 보이고, 프로젝트를 누르면 전에 하던 작업이 그대로 열린다. 가입·로그인은 아이디와 비밀번호로 하고, PC 등록 코드는 없앤다. 같은 날 사용자가 고른 결정은 다음과 같다.

- 데이터 위치: 목록(이름·최근 작업 시각·작업 PC·미리보기)은 계정 사이트(Cloudflare D1)에 두고, 대화·모델·AI 실행은 작업 PC에 둔다. PC가 꺼져 있으면 목록만 보이고 열리지 않는다.
- 이 PC에서도 웹사이트 주소로 연다. 같은 PC의 브라우저는 로컬 주소로 바로 열고, 다른 기기는 PC의 원격 접속(임시 터널)으로 연다.
- 가입은 가입 코드를 아는 사람만 한다. 코드는 사용자가 정했으며 저장소에는 두지 않는다(Worker 비밀값 `SIGNUP_CODE`).

원격 실행 흐름은 PRD 공유 절(FR-18·19)을 넘어선다. PRD 반영은 [PLAN-09](PLAN-09-remote-host.md)와 함께 후속 제안으로 남긴다.

## 변경

1. 계정 사이트: 아이디 가입(가입 코드)·로그인, 프로젝트 목록(최근 작업 순, 미리보기 이미지, 이름 바꾸기, 목록에서 삭제, 공유 검토로 이동), 작업 PC 표시(켜짐·원격 가능·이 PC). 프로젝트를 누르면 그 PC가 서명한 1분 토큰으로 이동한다. 물리 계약은 [ARCH-01 계정 웹사이트와 작업 PC](../architecture/ARCH-01-system.md)가 소유한다.
2. 작업 PC: 설정 → VIDE 계정에서 같은 아이디로 로그인하면 PC 키만 저장하고 기존 로컬 프로젝트를 계정 목록에 올린다. 원격 접속은 로그인과 함께 켜지고 설정에서 끌 수 있다. 사이트에서 만든·바꾼 프로젝트는 같은 id로 PC에 생긴다. 모델을 표시하면 목록용 미리보기를 보낸다.
3. 작업 화면 정리: 오른쪽 위 `···` 메뉴를 없앴다. 작업 상한·AI 연결은 왼쪽 아래 설정 하나로 모았고, 앱 종료 버튼은 제거했다. 초안은 이미 프로젝트별로 자동 저장되므로 수동 저장·불러오기를 없앴다. 새 프로젝트와 이름 바꾸기는 브라우저 `prompt()` 대신 제목 줄의 입력칸으로 한다(내장 브라우저에서 `prompt()`가 막혀 새 프로젝트·이름이 저장되지 않던 원인).
4. 재시작 내성: 기본 포트 47821과 저장된 로컬 세션으로, 서버를 다시 켜도 열린 화면과 사이트의 로컬 주소가 유지된다.

## 검증

- `tests/sharing/hosts.mjs`(로컬 workerd): 가입 코드 필수·중복 아이디 409·직접 이메일 가입 403, 아이디 로그인, PC 로그인(확인 세션 미잔존)·로컬 프로젝트 등록, 사이트에서 만든·바꾼 프로젝트의 PC 수신, 로컬·원격 링크 발급과 PC의 1회 검증, 주소 제한, 미리보기, 원격 끄기, 종료 시 꺼짐, 목록 삭제, 로그아웃.
- `tests/server/remote-http.test.mjs`: 연결된 PC의 heartbeat(로컬 주소), 사이트 Origin에만 답하는 hello, 사이트 토큰의 로컬 세션 1회, 원격 세션 차단 경로.
- `tests/integration/browser-workspace-controls.mjs`: `···` 메뉴·앱 종료 없음, 초안 자동 복원, 입력칸으로 새 프로젝트·이름 바꾸기와 새로고침 뒤 유지. `browser-pin-tokens.mjs`: 문장 속 고정 토큰(표시·삽입·통째 삭제·라벨 전송).
- `tests/integration/remote-loop.mjs`(실제 staging·터널, `VIDE_SHARING_TEST_ORIGIN`·`VIDE_SIGNUP_CODE`): PC 로그인 → 에뮬레이션 iPad 로그인 → 프로젝트 카드 → 원격 열기·모델·스케치 요청 → 같은 PC 브라우저의 로컬 열기 → 원격 끄기. 결과는 [원격 루프 검수](../tdd/VERIFY-2026-09-28-remote-loop.md).
