# S-06 골조 배치

연결한 모델의 슬래브·기존 기초와 지금 그려진 기둥·거더를 읽어 거더를 기둥에 맞추고, 작은보·해석 미리보기·예비 단면·일람표·기둥 높이와 Rhino에 만들 상단선·부재까지 이어 보는 탐색용 도구.

이 명세에서 'jig'는 VIDE 안에서 한 가지 검토를 처음부터 끝까지 해 주는 작업 도구 하나를 말한다. 이 도구는 여러 프로젝트에서 쓰는 일반판이고, 한 프로젝트에 둔 이 도구('이 프로젝트의 jig')에는 그 프로젝트의 실제 값을 따로 둔다.

## ① 목적

유수지 상판 위 철골 골조를 초기 검토할 때, 연결한 Rhino·CAD 파일에서 슬래브 경계·보이드·기존 기초·유수지 보·기존 그리드·E.J.와 지금 그려진 기둥·거더·신설 기초를 역할별로 읽는다. 기본(그려진 배치)에서는 거더 끝을 가까운 기둥 위로 붙이고, 거더망이 만드는 칸마다 작은보를 두고, 구역별 하중으로 골조 해석 미리보기를 돌려 KS H형강 예비 단면·부호·부재 일람표·강재 물량·기둥 길이와 받침 높이를 보인 뒤, 상단선과 H 부재를 Rhino에 만든다. 배치 기준을 '새 배치 제안'으로 바꾸면 경간 상한 안에서 새 축선·기둥·파일캡 후보를 만들고 기존 기초·오픈컷·유수지 보와의 간섭을 판정한다. 모든 수치는 탐색용 예비값이며 구조 검토를 대신하지 않는다. 실제 프로젝트 값은 그 프로젝트에 둔 이 도구에만 둔다.

## ② 언제 쓰나 / 언제 아니다

그려 둔 기둥·거더가 기둥에 제대로 붙었는지, 작은보를 어떻게 두고 검정비가 대략 어떤지 빨리 보고 싶을 때, 그리고 초기 배치 검토에서 새 기둥을 어디에 둘지 볼 때 쓴다.

## ③ 입력

입력은 연결한 파일의 레이어를 슬래브 경계·기존 기초 같은 역할에 하나씩 짝지어 모으는 '입력 조립' 하나와, 사람이 그리는 구역 넷이다. 연결한 파일은 VIDE 플러그인으로 VIDE와 이어 둔, 지금 Rhino나 CAD에 열린 파일이다. 레이어 이름 규칙이 첫 후보를 내고, 남은 역할은 AI가 "어느 파일의 어느 레이어인가"를 이유 한 줄과 함께 제안한다. AI는 레이어만 고르고, 형상의 좌표는 늘 VIDE의 계산이 파일에서 직접 읽는다. 사람이 역할을 말하거나 화면 왼쪽의 역할 카드에서 고르면 그 역할이 확인된 것으로 기록된다. 사람이 [입력 확인]을 누르기 전에는 결과에 '입력 미확인'이 붙는다.

### 입력 조립(연결 파일의 레이어)

| 역할 | 형태 | 필수 | 출처(첫 후보가 되는 레이어 이름) |
|---|---|---|---|
| 슬래브 경계 | 닫힌 다각형, 여럿 | 필수 | 이름에 '슬래브'·'slab'·'데크'·'deck'이 든 레이어 |
| 보이드·설치 불가 영역 | 닫힌 다각형, 여럿 | 선택 | '보이드'·'void'·'설치불가'·'설치 불가' |
| 기존 기초 | 평면 발자국(외곽), 여럿 | 필수 | '기존…기초'·'existing…footing'·'EX…FOOT'·'유수지…기둥' |
| 유수지 보 | 띠(평면 폭이 있는 보), 여럿 | 선택 | '유수지…보'·'basin…beam'·'basin…girder' |
| 기존 그리드 | 선, 여럿 | 선택 | '그리드'·'grid'·'축선' |
| 신설 E.J.(신축 이음) | 선, 여럿 | 선택 | '신설…E.J'·'신설…EJ'·'new…ej' |
| 기존 E.J. | 선, 여럿 | 선택 | '기존…E.J'·'기존…EJ'·'Exp.J'·'existing…ej' |
| 현재 배치 · 신설 기둥 | 선(기둥 중심선), 여럿 | 선택 | '기둥'·'column' |
| 현재 배치 · 거더 | 폴리선, 여럿 | 선택 | '거더'·'girder' |
| 현재 배치 · 신설 기초 | 평면 발자국(외곽), 여럿 | 선택 | '신설…기초'·'파일캡'·'pile…cap'·'new…footing' |

그려진 배치로 해석까지 가려면 현재 배치의 기둥과 거더가 있어야 한다. 표에서 '선택'은 입력 조립이 비어 있어도 계산을 시작할 수 있다는 뜻이다.

## ④ 설정값

단위 열은 저장하는 단위다. 화면에서 mm·%로 보이는 값은 범위 열 끝에 적었다. EL(m)은 기준면에서 잰 높이(레벨)다. 근거 열의 '가정'은 일반값이라는 뜻이고 프로젝트 값은 그 프로젝트에 둔 이 도구에서 정한다. 근거 기록이 없는 설정값도 아직 확정된 값이 아니므로 '가정(근거 기록 없음)'으로 적었다. '가정: 프로젝트 결정'은 이 도구를 처음 쓴 프로젝트에서 사람이 정한 방향을 일반값으로 옮긴 것이다. 괄호 안 영문은 VIDE 안에서 쓰는 이름이라 사람이 따로 칠 일은 없다.

## ⑤ 단계

계산 단계는 설정값을 바꾸고 손을 떼면(슬라이더를 놓으면) 바뀐 단계부터 다시 계산한다. [다시 계산] 버튼을 누르면 해석 미리보기 단계까지 다시 계산한다. 이 도구를 열면 처음 막히는 점검까지 자동으로 계산한다. 배치 기준이 '그려진 배치'이면 2~6번(새 배치 제안 단계)은 '배치 전'이라는 빈 결과만 내고, '새 배치 제안'이면 그 후보를 만든다.

1. **입력 조립**(계산) — 역할별로 읽은 것(개수·크기·회전·면적)과 축 방향을 정하고, 기존 그리드 교점의 탐색 거리 안에 기존 기초가 없으면 모델에서 기초가 빠졌을 수 있는 자리('모델 누락 가능')로 표시한다.
2. **입력 확인** 【사람】 — 화면 왼쪽 역할 카드에서 각 역할의 레이어가 맞는지 보고 [입력 확인]을 누른다. 누르기 전 결과에는 '입력 미확인'이 붙는다.
3. **진단 · 지금 그려진 배치**(계산) — 그려진 기둥·거더·신설 기초를 읽기만 해서 파일캡↔기존 기초(불가), 오픈컷↔기존 기초(협의 또는 불가), 기둥↔유수지 보(경고)와 기둥 위에서 끊은 경간을 표로 보인다.
4. **축선·배치**(계산, 새 배치 제안) — 직교 격자와 엇갈림 격자를 만들어 경간 > 파일캡 > 유수지 보 > 오픈컷 > 기둥 수 순서로 비교해 하나를 고르고, 대안을 함께 보인다. 경간 상한은 대각 거더를 포함해 끝까지 지키고, 지키지 못한 것은 목록으로 보인다.
5. **기둥**(계산, 새 배치 제안) — 슬래브 안, 소방 동선 밖에 기둥을 두고, 신설 E.J.마다 쌍기둥을 둔다. 하단은 기존 기초 상단(또는 설정값 레벨), 길이는 맞춤 단위로 내린다.
6. **기초 발자국**(계산, 새 배치 제안) — 기둥마다 파일캡과 오픈컷 외곽을 만든다. E.J. 쌍기둥은 공통 파일캡이다.
7. **기초 간섭**(계산, 새 배치 제안) — 3번과 같은 판정을 새 배치에 적용한다. 불가 기둥의 비켜 두기 후보는 제안만 하고 자동으로 적용하지 않는다. 기존 E.J. 양쪽에 걸친 구간은 경고로 보인다.
8. **거더 보정 · 그려진 배치**(계산) — 거더 끝을 붙임 거리 안의 기둥 상단으로 옮기고, 기둥 위에서 끊고, 겹친 곡선을 합치고, 휜 곡선은 한 원의 일부(원호)로 맞춘다. 기둥 없는 끝, 슬래브 경계·보이드를 넘는 곳, 경간 초과를 목록으로 보인다.
9. **칸**(계산) — 보정한 거더망의 닫힌 칸을 찾는다.
10. **작은보**(계산) — 칸마다 정한 방향으로 설정 간격 이하로 작은보를 두고, 슬래브 끝이 한도보다 멀면 내민 보를 둔다. 개구 둘레 보 두기를 켜면 보이드에서 잘린 작은보를 보이드 둘레 보에 건다.
11. **해석 모델**(계산) — 거더·작은보·기둥을 상단선으로 잇고(편심 무시), 구속 레벨, 자중, 구역 하중(데크·건조·식재), 하중 조합 1.2D+1.6L · 1.2D+1.6L+NX · 1.2D+1.6L+NY · 1.0D+1.0L을 넣는다(D는 고정하중, L은 활하중, NX·NY는 X·Y 방향의 가상 수평력).
12. **해석 미리보기**(계산) — 부재 검정비·지배 조항·참고 처짐을 '미확정 미리보기'로 보인다.
13. **해석 확정** 【사람】 — 미리보기를 보고 [해석 확정]을 누른다. 확정해야 부재 만들기가 열린다.
14. **확정 해석**(계산, 버튼) — 확정한 모델로 해석을 다시 돌려 확정 결과로 남긴다.
15. **단면 선정**(계산) — 역할 × 경간 띠(곡선 부재는 따로)로 묶어, 보 춤 상한 이하에서 목표 검정비 안의 가장 가벼운 KS H형강을 고른다. 선정 중 해석은 미확정 미리보기이며 결과는 '예비'다. 후보가 없으면 지금 단면을 두고 '후보 없음'으로 보인다.
16. **부호·일람표**(계산) — 역할·단면·곡률로 부호를 붙이고, 다시 계산해도 같은 부재는 같은 부호를 유지한다. 부호별 개수·총길이·단위중량·중량·최대 검정비와 강재 합계를 보인다.
17. **기둥 높이**(계산) — 기둥 위 가장 깊은 거더 하단 아래로 기둥 길이를 맞춤 단위로 내리고, 차이를 받침 높이 표로 보인다. 보 춤 + 마감(0.15 m 가정)이 1.2 m를 넘으면 표시한다.
18. **Rhino에 만들기 계획**(계산) — 기둥선·거더 상단선(원호 유지)·작은보 상단선과 H 부재 목록을 만든다.
19. **부재 만들기 계획 · 확정 해석**(계산, 버튼) — 확정한 해석과 같은 단면일 때만 H 부재 목록을 확정한다.
20. **선정 단면 적용** 【사람】 — 단면 표를 보고 선정 단면을 모델에 적용할지 확인한다.
21. **선정 단면을 모델에 적용**(계산, 버튼) — '선정'된 묶음의 부재 가운데 지금 단면과 다른 것만 사람의 수정 사항(결과를 고쳐 남긴 기록)으로 바꾼다. '후보 없음'·'미검토' 묶음은 그대로 둔다. 적용하면 해석 확정이 풀리므로 13번을 다시 눌러야 부재를 만들 수 있다.

Rhino에 만들기 【사람】 — [선만 먼저 만들기]와 [부재 만들기]는 사람이 누른다(⑥).

## ⑧ 한계·가정

- 모든 수치는 탐색용 예비값이다. 구조 검토·구조계산서·기초 설계·접합 상세를 대신하지 않는다.
- 해석은 사람이 [해석 확정]을 누르기 전까지 미확정 미리보기다. 단면 선정도 미확정 미리보기 해석으로 반복한 예비값이다.
- 해석 모델은 부재를 상단선으로 잇고 편심을 무시한다(가정 목록에 적음).
- 강종은 SM355, 탄성계수 210,000 MPa로 가정한다. 기준 원문 확인 전이다.
- 하중 조합은 1.2D+1.6L, 1.2D+1.6L+NX, 1.2D+1.6L+NY, 1.0D+1.0L 넷(D 고정하중, L 활하중, NX·NY는 X·Y 방향 가상 수평력)이고 가상 수평력 비는 0.002 가정이다.
- 수평 구속의 강성은 정해지지 않았다(물어볼 것). 켜면 구속 레벨에서 기둥이 가로·세로로 밀리지 않게 붙잡는 것으로 본다.
- 부호 접두(SC·SG·SB·SEG·SCB·STB, 앞에 'S06-'를 붙여 S06-SG1 꼴)는 가정이다.
- 유수지 보 띠는 오목한 데를 메운 바깥 둘레(볼록 껍질)로 본다.
- 새 배치 제안의 후보는 직교 격자와 엇갈림 격자 둘뿐이다. 비켜 두기 후보는 제안만 하고 자동으로 적용하지 않는다.
- 기둥 높이의 마감 두께 0.15 m와 보 춤 + 마감 한도 1.2 m는 설정값이 아닌 고정 가정이다.
- 도면(CAD)과 모델의 위치 맞춤은 그 프로젝트에 둔 이 도구에서 확인한다.
- 선정 단면을 적용하면 해석 확정이 풀리고 다시 확정해야 부재를 만들 수 있다. AI가 이 도구를 고를 때 읽는 도구 설명서의 한계 목록에는 아직 "적용 경로 없음"으로 적혀 있으나 현재 단계에는 적용이 있다.
- 단계 목록의 '입력 확인'과 '선정 단면 적용'은 화면의 같은 확인 카드(사람이 확인 버튼을 누르는 칸)를 쓴다. 화면에서 두 확인이 어떻게 나뉘어 보이는지는 확인하지 못했다(가정).
- 설정값 근거 가운데 '가정(근거 기록 없음)'은 도구 설명에 근거가 적혀 있지 않은 값이다.
- 설정값 표의 단위 표기(도, EL(m), kN/㎡, 비)는 읽기 쉽게 풀어 쓴 것이다. 명세와 도구 선언을 맞대어 보는 대조가 단위를 어떤 표기로 비교할지는 아직 정해지지 않았다(가정).
- 검토하지 않는 항목: 접합부, 기초·말뚝, E.J. 상세, 기존 기초 구속 강성, 수평 하중 조합, 진동.
- 실제 프로젝트 값과 비공개 원본은 이 일반판에 넣지 않는다. 도구를 만들 때 쓰는 자체 시험은 일부러 만든 합성 배치만 쓴다.
