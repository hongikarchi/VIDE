# 프로젝트 자료

회사 서버의 프로젝트 폴더(메일·회의록·문서·도면)를 정리한 자료에서 지금 정해진 것·막힌 것·최근 바뀐 것을 현황 보고서로 읽습니다.

이 명세에서 'jig'는 VIDE 안에서 한 가지 검토를 처음부터 끝까지 해 주는 작업 도구 하나를 말한다. 이 jig는 화면 코드로 된 내장 jig라 사본을 만들 수 없다.

## ① 목적

프로젝트 폴더의 메일·회의록·문서·도면을 정리한 프로젝트 자료(프로젝트마다 하나)를 읽기만 해서, 지금 정해진 것·막힌 것·최근 바뀐 것을 현황 보고서로 보인다. 보고서 항목에서 분야별 이슈 노트로, 다시 진술마다 원문 근거와 원본 파일로 들어간다. 원본은 회사 서버에 그대로 두고 경로만 기록한다. 진술의 상태는 사람이 확인해 바꾼다.

## ② 언제 쓰나 / 언제 아니다

### 언제 쓰나

- 프로젝트 현황 알려 줘
- 현황 보고 보여 줘
- 지금 막힌 게 뭐야

### 판정 낱말

대화에서 이 낱말이 나오면 VIDE가 이 도구를 쓸 요청으로 알아본다.

- 프로젝트 현황
- 현황 보고

### 언제 아니다

- 원본 파일 고치기
- 회사 서버 폴더 정리
- 자료에 없는 내용의 판단

## ③ 입력

| 역할 | 형태 | 출처 | 없을 때 |
|---|---|---|---|
| 프로젝트 지식 DB | 프로젝트 하나의 정리된 자료(진술·근거·원본 경로) | 이 프로젝트의 자료 파일 | 보고서를 만들지 않고 자료가 아직 없다는 이유를 보임 |

## ④ 설정값

설명서(`jig.json`)가 없는 화면 코드 jig라 설정값 표가 없다. 분야(구조 / 토목·유수지 / 조경 / 파사드·외장 / 조명·전기·설비 / 소방·피난·안전 / 인허가·심의·법규 / 건축 계획·디자인 / 공사비·계약·업무 범위 / 일정·진행 / 기타)와 검색어는 화면에서 고른다.

## ⑤ 단계

【사람】은 사람이 확인하거나 골라야 다음으로 넘어가는 곳이다.

1. **자료 읽기** — 이 프로젝트의 자료를 읽기 전용으로 연다.
2. **현황 보고** — 정해진 것·막힌 것·최근 바뀐 것을 모아 보고서로 보인다.
3. **이슈 노트·근거** — 항목에서 분야별 이슈 노트와 진술의 원문 근거, 원본 파일 경로로 들어간다.
4. 【사람】 진술의 상태를 확인하거나 바꾼다.

## ⑥ 결과

- **화면:** 현황 보고서, 분야별 이슈 노트, 진술 검색과 원문 근거.
- **Rhino에 만들기:** 없음.
- **파일:** 없음. 원본 파일은 회사 서버에서 연다.

## ⑦ 통과 조건

설명서의 점검 목록이 없는 화면 코드 jig다. 보고서의 진술은 자료에 있는 원문 근거가 있을 때만 보인다.

## ⑧ 한계·가정

- 시험판이다. 자료는 앱 밖에서 만든다.
- 원본은 회사 서버에 두고 경로만 기록하므로, 서버에 접근할 수 없으면 원본을 열 수 없다.
- 내장 jig라 사본을 만들거나 관리자에게 제출할 수 없다.
