# 동기화 · 도면↔모델

같은 프로젝트의 Rhino 모델과 CAD 도면이 서로 어떻게 놓여 있는지(이동·회전·오차) 계산하고, 서로 맞지 않는 객체를 표로 보입니다.

이 명세에서 'jig'는 VIDE 안에서 한 가지 검토를 처음부터 끝까지 해 주는 작업 도구 하나를 말한다. 이 jig는 화면 코드로 된 내장 jig라 사본을 만들 수 없다.

## ① 목적

같은 프로젝트에 연결한 Rhino 모델과 CAD 도면(ZWCAD)의 동기화 기록을 읽어, 두 문서의 위치 관계(평면 회전·이동과 높이 차, 맞춘 쌍의 오차)를 계산하고 서로 대응하지 않는 객체를 표로 보인다. 위치 맞추기와 객체 대응은 계산으로 하므로 다시 해도 같은 결과가 나오고, 차이가 무슨 뜻인지는 AI 검토가 이 표의 행과 숫자만 인용해 판정한다. 사람이 한쪽을 기준으로 정하면 다른 쪽을 그 기준에 맞춘다. 좌표는 모두 미터(m)로 다룬다.

## ② 언제 쓰나 / 언제 아니다

### 언제 쓰나

- 도면이랑 모델 어긋난 데 찾아 줘
- 모델과 도면 비교해 줘
- 정합 검토 해 줘

### 판정 낱말

대화에서 이 낱말이 나오면 VIDE가 이 도구를 쓸 요청으로 알아본다.

- 도면이랑 모델 어긋
- 도면과 모델 어긋
- 모델이랑 도면 어긋
- 모델과 도면 어긋
- 도면 모델 비교
- 정합 검토

### 언제 아니다

- 동기화가 됐는지 묻는 질문
- 도면이나 모델 한쪽의 객체 옮기기·색 바꾸기
- 화면 확대·이동

## ③ 입력

| 역할 | 형태 | 출처 | 없을 때 |
|---|---|---|---|
| Rhino 동기화 기록 | 연결한 Rhino 문서의 객체(곡선·솔리드). 솔리드는 기준 높이에서 자른 평면 단면의 직선 변 하나하나를 객체로 본다 | 이 프로젝트에 연결한 Rhino 문서의 마지막 동기화 | 계산하지 않고 Rhino 문서를 연결해 동기화하라는 이유를 보임 |
| ZWCAD 동기화 기록 | 연결한 CAD 도면의 선·폴리선 객체 | 이 프로젝트에 연결한 CAD 도면의 마지막 동기화 | 계산하지 않고 CAD 도면을 연결해 동기화하라는 이유를 보임 |

## ④ 설정값

설명서(`jig.json`)가 없는 화면 코드 jig라 설정값 표가 없다. 비교할 레이어와 단면 기준 높이는 화면에서 고른다.

## ⑤ 단계

【사람】은 사람이 확인하거나 골라야 다음으로 넘어가는 곳이다.

1. **동기화 기록 읽기** — 두 문서의 마지막 동기화 기록을 읽어 객체를 직선 조각으로 나눈다.
2. **위치 맞추기** — Rhino에서 CAD로 가는 평면 회전·이동과 높이 차를 계산하고, 맞춘 쌍의 수와 오차(최대·평균)를 보인다. 후보가 여럿이면 '모호함'으로 표시한다.
3. **객체 대응** — 맞춘 위치에서 두 문서의 객체를 짝짓고, 짝이 없거나 길이·위치가 다른 객체를 표로 모은다.
4. **AI 검토** — 표의 행과 숫자만 인용해 각 차이가 무슨 뜻인지 판정한다.
5. 【사람】 어느 쪽을 기준으로 맞출지 고르고 적용한다.

## ⑥ 결과

- **화면:** 두 문서의 위치 관계(회전·이동·높이 차·오차)와 맞지 않는 객체 표, AI 검토 판정.
- **Rhino에 만들기:** 사람이 모델 쪽을 맞추기로 고른 경우에만 연결한 Rhino 문서에 반영한다.
- **파일:** 없음.

## ⑦ 통과 조건

설명서의 점검 목록이 없는 화면 코드 jig다. 위치 맞추기에 쓸 쌍이 없거나 후보가 모호하면 그 사실을 화면에 보이고 객체 대응을 확정하지 않는다.

## ⑧ 한계·가정

- 두 문서가 같은 축척(미터)으로 그려졌다고 본다. CAD 도면은 보통 높이 0에 있다.
- 평면에서의 회전과 이동만 찾는다. 축척 차이나 기울어진 도면은 맞추지 않는다.
- 차이의 의미 판정은 AI 검토가 하며, 표에 없는 숫자를 근거로 쓰지 않는다.
- 내장 jig라 사본을 만들거나 관리자에게 제출할 수 없다.
