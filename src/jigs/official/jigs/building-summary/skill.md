# 건축개요

건축 가능 영역·매스 jig에서 사람이 확정한 고른 대안과, 있으면 사이트 모델링의 대지 요약을 받아
건축개요(대지 위치·지역·대지면적·규모·건축면적·연면적·건폐율·용적률·높이·조경·공개공지·주차·구조)와
층별 면적표를 만든다.

- 숫자는 앞 jig가 계산한 값과 사람이 넣은 값만 옮긴다. 이 jig는 면적·법정 값을 새로 계산하거나 정하지
  않는다. 비어 있는 칸은 '사람 입력 필요'로 둔다.
- 값마다 출처(계산 · 공부 · 사람 입력 · 법규 결과)와, 법정 값이면 확정 상태와 근거를 보인다.
- 개요의 숫자가 출처에 없거나 층별 합계가 연면적과 다르면 내보내지 않고 다른 칸을 보인다.
- 미확정 조건이 있으면 보고서 첫머리에 개수와 목록을 싣는다.
- 결과는 탐색용 규모검토이며 인허가 도서·면적 산정·법규 검토를 대체하지 않는다.
