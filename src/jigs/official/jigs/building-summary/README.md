# 건축개요

매스 검토에서 고른 대안과 대지 요약을 받아 건축개요와 층별 면적표를 만들고, 숫자가 맞을 때만 보고서와 표로 냅니다.

이 명세에서 'jig'는 VIDE 안에서 한 가지 검토를 처음부터 끝까지 해 주는 작업 도구 하나를 말한다. 건축 가능 영역·매스, 사이트 모델링도 같은 프로젝트에서 쓰는 다른 jig다.

## ① 목적

건축 가능 영역·매스 jig에서 사람이 확정한 고른 대안과, 있으면 사이트 모델링의 대지 요약을 받아 사무소 건축개요 표의 순서대로 건축개요(건물명·대지 위치·지역·지구·대지면적·공사종별·주용도·규모·도로 현황·건축면적·연면적·용적률 산정 연면적·건폐율·용적률·높이·대지 안의 조경·공개공지·주차·구조·비고)와 층별 면적표를 만든다. 숫자는 앞 jig가 계산한 값과 사람이 넣은 값을 옮기기만 하고 새로 계산하거나 법정 값을 정하지 않는다. 칸마다 출처를 붙인다. 출처는 계산(앞 jig가 계산한 값), 공부(토지대장 같은 공적 장부의 값), 사람 입력, 법규 결과(법규 검토 jig가 낸 값) 네 가지다. 법정 값에는 확정 상태(확정인지 아직 미정인지)와 근거도 붙인다. 개요의 숫자가 출처와 맞고 층별 합계가 연면적과 같을 때만 보고서와 표를 낸다. 결과는 탐색용 규모검토이며 인허가 도서·면적 산정·법규 검토를 대체하지 않는다.

## ② 언제 쓰나 / 언제 아니다

### 언제 쓰나

- 건축개요 만들어 줘
- 고른 대안으로 층별 면적표 뽑아 줘
- 규모검토 개요 표 내보내기

### 판정 낱말

대화에서 이 낱말이 나오면 VIDE가 이 도구를 쓸 요청으로 알아본다.

- 건축개요
- 층별 면적표
- 면적표
- 개요 표

### 언제 아니다

- 법규 판단
- 인허가 도서
- 면적 산정 제외 판단
- 대안 고르기

## ③ 입력

| 역할 | 형태 | 출처 | 없을 때 |
|---|---|---|---|
| 고른 대안(건축 가능 영역·매스) | 다른 jig의 결과: 대안 이름, 대안 면적 행(건축면적·연면적 지상·지하·합계·산정 제외 면적·용적률 산정 연면적·건폐율·용적률·층수·높이와 법정 대비 판정), 층별 바닥면적·용도·제외 면적·제외 근거, 대지 면적(계산), 주용도, 규제 조건 항목(값·적용 여부·확정 상태·근거), 조경·공개공지·주차 값, 미확정 조건 목록 | 건축 가능 영역·매스 jig에서 사람이 [고른 대안 확정] 버튼을 누른 결과. 이 프로젝트에서 그 jig를 마지막으로 계산한 결과를 읽음 | 개요를 만들지 않고 "그 jig에서 대안을 고르고 [고른 대안 확정]을 하세요"라는 이유를 보임 |
| 대지 요약(사이트 모델링) | 다른 jig의 결과: 필지 고유번호(PNU)·주소, 공부 면적, 계산 면적, 용도지역·지구, 도로 현황, 자료 조회 시각 | 사이트 모델링 jig의 대지 요약 | 없어도 됨. 대지 위치·공부 대지면적·도로 현황 칸은 '사람 입력 필요'가 됨. 지역·지구 칸은 고른 대안의 규제 조건에 용도지역 값이 있으면 그 값을 쓰고, 없을 때만 '사람 입력 필요'가 됨 |

받은 앞 결과는 어느 jig의 결과인지, jig 버전, 대안 또는 대지, 계산 시각, 상태와 함께 결과에 남는다.

## ④ 설정값

| 이름(코드값) | 단위 | 기본 | 범위 | 근거 |
|---|---|---|---|---|
| 공사종별 (`constructionType`) | 선택 | 사람 입력 필요 (`unset`) | 신축 · 증축 · 개축 · 재축 · 이전 · 대수선 · 용도변경 | 확정 — 사람이 적는 항목. 개요의 공사종별 칸에 그대로 옮김 |
| 구조 (`structure`) | 선택 | 사람 입력 필요 (`unset`) | 철근콘크리트조 · 철골조 · 철골철근콘크리트조 · 철골·철근콘크리트 혼합구조 · 목조 · 조적조 · 기타 | 확정 — 사람이 적는 항목. 개요의 구조 칸에 그대로 옮김 |
| 주차 방식 (`parkingMethod`) | 선택 | 사람 입력 필요 (`unset`) | 지상 자주식 · 지하 자주식 · 기계식 | 확정 — 사람이 적는 항목. 고른 대안에 같은 방식의 주차 대안 판정이 있으면 함께 적음 |

세 설정값 모두 기본이 '사람 입력 필요'이며, 고르지 않으면 해당 칸이 '사람 입력 필요'로 남는다. 괄호 안 영문은 VIDE 안에서 쓰는 이름이라 사람이 따로 칠 일은 없다.

## ⑤ 단계

【사람】은 사람이 확인하거나 골라야 다음으로 넘어가는 곳이다.

1. 【사람】 건축 가능 영역·매스 jig에서 대안을 고르고 [고른 대안 확정] 버튼을 누른다. 이 도구의 화면 밖, 매스 jig에서 하는 일이다.
2. **앞 결과 받기** — 고른 대안과 대지 요약을 받고, 어느 jig·대안·계산 시각에서 왔는지 표로 남긴다. 고른 대안이 없으면 이유를 보이고 멈춘다.
3. 【사람】 사람이 적는 항목(공사종별·구조·주차 방식)을 고른다. 건물명·비고는 설정값이 아니라 사람이 결과를 고쳐 남기는 기록(수정 사항)으로 받도록 되어 있지만, 지금 이 도구 화면에는 그 글을 적는 칸이 없다(⑧). AI가 제안한 글은 사람이 받기 전에는 들어가지 않는다.
4. **건축개요·층별 면적표** — 고른 대안·대지 요약·설정값을 사무소 표 순서의 개요 칸과 층별 면적표(지하 깊은 층부터, 이어 지상 1층부터, 끝에 지상 합계·지하 합계·합계)로 옮긴다. 칸마다 출처·확정 상태·근거·자료를 붙이고, 면적 칸 옆에 평(1평 = 400/121 ㎡ ≒ 3.3058 ㎡로 환산한 참고 값)을 적는다. 미확정 조건과 '사람 입력 필요' 칸을 모은다.
5. **일관성 점검** — 개요의 숫자가 모두 출처에 있는지, 글자와 평이 값에서 쓴 것인지, 층별 합계가 지상·지하·합계 줄과 개요의 연면적·용적률 산정 연면적과 같은지, 층 수가 규모와 같은지 대조한다. 층별 면적표의 각 층 값(바닥면적·산정 제외 면적·용적률 산정 포함 면적)과 그 평도 같은 방법으로 대조한다. 하나라도 다르면 내보낼 표를 비우고, 출처와 맞지 않는 칸('다른 칸')을 보인다.
6. 【사람】 다른 칸이 있으면 매스 jig의 대안을 고쳐 다시 확정하거나 값을 확인한 뒤 [다시 계산]을 누른다. 다른 칸이 없으면 보고서와 표를 확인하고 낸다.

열면 이 프로젝트에서 마지막으로 계산한 결과를 다시 쓰고, 처음으로 흐름을 막는 문제가 나올 때까지 저절로 계산한다.

## ⑥ 결과

- **화면:** 가운데에 건축개요 보고서와 요약 숫자 줄(연면적 m², 미확정 조건 개수, 사람 입력 필요 칸 수, 다른 칸 개수). 아래 결과 탭에 건축개요(항목, 세부, 값, 평, 출처, 확정 상태, 근거·비고, 자료 — 8열), 층별 면적표(층·용도·바닥면적·산정 제외 면적·용적률 산정 포함 면적·평·비고), 일관성 점검(칸·보인 값·맞아야 할 값·이유), 미확정 조건(조건·상태), 앞 결과(입력·출처 jig 결과·jig·대안·대지·계산 시각·상태). 왼쪽에 단계 목록, 두 입력의 출처, 설정값. 용적률 산정 연면적(개요)은 층별 면적표의 용적률 산정 포함 면적을 모두 더한 값이다.
- **보고서:** 파일 하나로 열리는 건축개요 보고서(HTML). 첫 문장은 상태에 따라 "맞지 않아 내보내지 않음" · "미확정 조건 n개" · "연면적 n m²의 건축개요" · "고른 대안을 아직 받지 못함" 가운데 하나. 요약 숫자는 다섯 개(연면적, 용적률(계획), 건폐율(계획), 미확정 조건 개수, 사람 입력 필요 칸 수)다. 절은 건축개요와 값의 출처, 층별 면적표, 일관성 점검, 받은 앞 결과이며 가정과 검토하지 않은 항목(미확정 조건, 사람 입력 필요 칸, 제외 면적의 적정성, 법정 값의 적용 여부와 해석)을 싣는다. 다른 칸이 없고 층별 면적표가 채워졌을 때만 저장·인쇄할 수 있다.
- **파일:** 엑셀로 열 수 있는 표 파일(CSV) — 건축개요, 층별 면적표, 일관성 점검, 미확정 조건, 앞 결과. 건축개요·층별 면적표 표는 일관성 점검을 통과했을 때만 내용이 들어간다.
- **Rhino에 만들기:** 없음. 이 jig는 Rhino에 아무것도 만들지 않는다.

## ⑦ 통과 조건

1. 앞 결과 받기 — 결과에 계산할 수 없는 숫자(0으로 나누기 같은 이유로 깨진 값)가 없다.
2. 건축개요·층별 면적표 — 결과에 계산할 수 없는 숫자가 없다.
3. 일관성 점검 — 결과에 계산할 수 없는 숫자가 없다.

세 점검 모두 막음 수준(통과하지 못하면 다음 단계로 가지 않음)이다. 개요 숫자와 출처의 대조, 층별 합계와 연면적의 대조는 점검이 아니라 일관성 점검 단계의 결과(다른 칸 개수)로 보이며, 다른 칸이 1개 이상이면 보고서와 표를 내보내지 않는다.

## ⑧ 한계·가정

- 탐색용 규모검토이며 인허가 도서·면적 산정·법규 검토를 대체하지 않는다. 법규 판단, 면적 산정 제외의 적정성 판단, 대안 고르기는 하지 않는다.
- 고른 대안은 건축 가능 영역·매스 jig에서 사람이 확정한다. 법정 값은 법규 결과나 사람이 넣은 값을 그대로 옮긴다.
- 층별 바닥면적은 고른 대안의 층 윤곽 면적이며 벽체 중심선 면적 산정이 아니다.
- 산정 제외 면적은 매스 jig에서 사람이 넣은 값을 그대로 쓴다.
- 평은 1평 = 400/121 ㎡로 환산한 참고 값이다.
- 대지면적은 공부 면적과 계산 면적을 나란히 보이고 하나로 합치지 않는다. 건폐율·용적률(계획)의 분모는 계산 면적이다.
- 주차 계획 대수가 없으면 법정 대수로 본다.
- 숫자 대조는 아주 작은 반올림 차이(값의 백만분의 일 이하)만 같은 값으로 본다. 실무에서 보이는 자릿수의 차이는 모두 다른 칸이 된다.
- 내보내기는 보고서(HTML)와 표 파일(CSV)뿐이고, 엑셀·한글 파일(XLSX·HWPX)은 아직 낼 수 없다. 낼지 여부는 아직 정하지 않았다.
- 건물명·비고는 수정 사항(사람이 적는 글, 200자까지)으로 받도록 되어 있지만 지금 이 도구 화면에는 적는 칸이 없다. 적지 않으면 건물명은 '사람 입력 필요', 비고는 빈칸이다.
- AI가 적은 건물명·비고는 넣지 않는다. 그 거절 이유는 지금 화면·보고서에 보이지 않는다.
- 가정: 고른 대안을 받은 뒤 앞 jig가 다시 계산되면 '다시 계산 필요'를 보이는 일과, 앞 jig의 다른 결과를 고르는 일은 이 도구가 아니라 VIDE가 공통으로 맡는다고 보았다.
