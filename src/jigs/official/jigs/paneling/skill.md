# 패널링

사람이 연결 Rhino 문서에서 고른 기준 면을 세 단계로 다룬다. 단계는 순서대로 이어지고, 앞 단계 값이
바뀌면 뒤 단계 결과는 '다시 계산 필요'가 된다.

1. **미리보기:** 패턴·패널 크기(가로 × 세로, 줄눈 중심 간격)·크기를 재는 법·패턴 축과 시작 모서리·경계
   처리로 패널을 나눈다. AI 없이 바로 다시 계산된다.
2. **부재:** 두께·두께 방향·줄눈 폭·경계 줄눈·판재 한도로 패널마다 닫힌 부재와 줄눈 선을 만든다.
3. **최적화·타입화:** 평면도 허용 오차·평면화 방법·타입 허용 오차·최대 타입 수로 평면화, 패널 타입,
   결합부 타입, 일람표, 평면 패널의 재단 윤곽을 낸다.

## 되묻기

아래 값은 프로젝트·사람마다 달라서 작업본에 값이 없으면 묻는다. 대화로 열었으면 그 단계의 빠진 값만
질문 카드 하나로 묻고, 카드에는 추천값을 먼저 보인다.

| 단계 | 묻는 값 | 추천값 |
|---|---|---|
| 1 | 기준 면 | 없음 — 사람이 Rhino에서 고르고 [고른 면 쓰기] |
| 1 | 패턴 | 사각 격자 |
| 1 | 패널 크기 | 1,200 × 600 mm |
| 1 | 크기를 재는 법 | 면 위 길이 |
| 1 | 패턴 축·시작 모서리 | 면의 U 방향, 매개변수 최소 모서리 |
| 1 | 경계 처리 | 자르기 |
| 1 | 합치기 기준(합치기일 때) | 온 패널 면적의 30% |
| 1 | 투영 평면(투영 격자일 때) | 평면 XY |
| 2 | 두께, 두께 방향 | 50 mm, 바깥(면 법선 쪽) |
| 2 | 줄눈 폭, 경계 줄눈 | 10 mm, 경계에 맞춤 |
| 2 | 판재 한도 | 없음 |
| 3 | 평면도 허용 오차, 평면화 방법 | 3 mm, 패널별 최적 평면 |
| 3 | 타입 허용 오차, 최대 타입 수 | 2 mm, 제한 없음 |
| 3 | 평면으로 볼 곡률 반지름, 결합부 각 간격 | 100 m, 1° |

- 질문을 건너뛰거나 닫아도 작업은 멈추지 않는다. 그 값은 추천값으로 '가정'이 되고, 1단계 미리보기는
  가정 값으로 바로 계산한다.
- 부재·타입을 Rhino에 만들려면 그 단계와 앞 단계의 값이 모두 사람이 넣거나 받은 값이어야 한다.
  '가정' 표지를 눌러 [이 값으로 확인]하면 값은 그대로 두고 확인한 것이 된다.
- AI는 값을 제안할 수 있으나 사람이 받기 전에는 계산에 넣지 않는다.

## 지키는 것

- 모양 계산은 코드가 한다. 실패한 패널(트림 밖·넓이 0·투영이 접힘·두께 불가 등)은 빼거나 메우지 않고
  수와 이유를 보인다. 경계 처리 '빼기'로 뺀 패널도 수와 위치를 보인다.
- Rhino 문서에는 사람이 [Rhino에 만들기]를 누를 때만 쓰고, 결과 카드의 [되돌리기] 한 번으로 그 만들기를
  모두 지운다. 사용자의 원본 파일을 열어 쓰지 않는다.
