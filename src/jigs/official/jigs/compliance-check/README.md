# 법규 체크

Rhino에서 모델링한 건물을 '건축 가능 영역·매스'의 규제 조건과 숫자·형상으로 비교해, 항목마다 적합·위반·판단 필요·사람 입력 필요·검사 불가와 근거를 보이는 탐색용 검사 도구.

이 명세에서 'jig'는 VIDE 안에서 한 가지 검토를 처음부터 끝까지 해 주는 작업 도구 하나를 말한다. '건축 가능 영역·매스'와 '사이트 모델링'도 같은 프로젝트에서 쓰는 다른 jig다. '연결 문서'는 VIDE 플러그인으로 VIDE와 이어 둔, 지금 Rhino에 열린 파일을 말한다.

## ① 목적

설계자가 지금 Rhino에 열린 연결 문서의 건물(사람이 모델링한 매스·층 윤곽·주차 구획·조경·공개공지)이 이 프로젝트에서 정한 규제 조건을 넘는 곳이 있는지 항목별로 보게 한다. 숫자와 형상은 계산으로 구하고, 한계 값은 '건축 가능 영역·매스'의 규제 조건(사람이 넣은 값 또는 법규 Q&A 결과)에서만 가져온다. 정할 수 없는 비교는 조용히 적합·위반으로 정하지 않는다. 다섯 상태의 뜻은 다음과 같다.

- 적합 · 위반: 한계 값과 계획 값이 모두 있고 비교가 하나로 정해진다.
- 판단 필요: 값은 있지만 법 해석이나 사람이 정할 조건(예: 기준 지반을 최저로 볼지 최고로 볼지)에 따라 결과가 갈린다.
- 사람 입력 필요: 비교에 쓸 한계 값이나 계획 값을 아직 아무도 넣지 않았다.
- 검사 불가: 필요한 형상(층 윤곽, 외피 등)이나 문서 단위가 없어 계산 자체를 할 수 없다.

[법규 체크]를 누를 때만 읽고 계산하며, Rhino 문서는 바꾸지 않는다. 탐색용 법규 체크이며 인허가 검토·법규 검토를 대체하지 않는다.

## ② 언제 쓰나 / 언제 아니다

### 언제 쓰나

- 법규 위반 있는지 봐 줘
- 지금 설계 법규 체크해 줘
- 규정 위반 확인해 줘
- 일조 사선 넘는 데 있어?

### 판정 낱말

대화에서 이 낱말이 나오면 VIDE가 이 도구를 쓸 요청으로 알아본다.

- 법규 체크
- 법규 위반
- 규정 위반 확인
- 법규 검토 결과
- 위반 사항

### 언제 아니다

- 법규 질문 답하기
- 규제 조건 정하기
- 매스 대안 만들기
- 인허가 도서

## ③ 입력

| 역할 | 형태 | 출처 | 꼭 있어야 하나 |
|---|---|---|---|
| 설계 모델(연결 Rhino 문서) | 지금 Rhino에 열려 있는 연결 문서 하나. 객체마다 검사 역할(건물 매스·층 윤곽·건축면적 윤곽·옥탑 등·주차 구획·조경(지상)·조경(옥상 등)·공개공지·검사에서 뺌)을 정해 읽는다 | 연결된 Rhino 문서. [법규 체크]를 누를 때 다시 읽는다 | 예 |
| 규제 조건·외피(건축 가능 영역·매스) | 규제 조건 항목 전부(값·단위·적용 여부·확정 상태·근거 조항), 대지 경계와 대지면적·정북, 규칙별 금지 띠(건축선·이격 같은 규칙 하나가 막는 대지 가장자리 띠), 일조 금지 부피(정북 일조 사선 밖의 덩어리)·최대 외피(모든 제한을 지킨 최대 덩어리), 주용도·층고 | 이 프로젝트의 '건축 가능 영역·매스'가 넘겨준 결과 | 아니오(없으면 규제 조건을 쓰는 행이 '사람 입력 필요', 형상 제한 행이 '검사 불가') |
| 대지 요약(사이트 모델링) | 대지 경계 위 지형 높이(최저·최고·평균) — 기준 지반 후보로만 쓴다 | 이 프로젝트의 '사이트 모델링'이 넘겨준 대지 요약 | 아니오 |

객체의 검사 역할은 다음 순서로 정한다. 객체 속성에 적힌 역할 → 사람이 이전에 확인해 프로젝트에 남긴 분류 → '건축 가능 영역·매스'가 만든 층 매스 가운데 고른 대안의 것은 층 윤곽으로 읽고, 다른 jig가 만든 객체(주차 추정 매스, 외피, 제한선 등)는 검사에서 뺌 → 레이어 이름(예: 건물·매스, 층윤곽·층, 주차, 조경, 공개공지, 검사제외). 어느 것으로도 정하지 못한 객체는 '역할 없음'이며, 사람이 [역할 제안 받기]로 AI 제안을 받아 받기·역할 바꾸기·버리기를 하거나 직접 역할을 정한다.

층마다 넣는 산정 제외 면적(값·근거)과 층 용도는 계산이 사람의 수정 사항(사람이 결과를 고쳐 남기는 기록)으로 받도록 되어 있지만, 지금 이 도구 화면에는 넣는 칸이 없다(⑧). AI가 넣은 값은 받지 않는다.

## ⑤ 단계

【사람】은 사람이 하는 일, 【AI】는 AI가 제안만 하는 일이다.

1. 【사람】 법규 체크를 연다(JIG 목록에서 열거나 대화에서 "법규 위반 있는지 봐 줘"). 열 때 연결 Rhino 문서를 한 번 읽어 객체마다 검사 역할을 정해 보인다. 열린 연결이 없으면 읽지 않고 "Rhino에서 문서를 열고 연결한 뒤 다시 누르세요" 안내만 보인다. 이전에 고른 문서가 없고 열린 연결이 여럿이면 열 때 읽지 않고, 화면 맨 위의 '읽을 Rhino 문서'에서 고른 뒤에 읽는다.
2. 역할을 확인한다. 역할 없는 객체는 【사람】 [역할 제안 받기] → 보낼 레이어 목록 확인 → [보내고 제안 받기]를 누르면 【AI】가 역할을 제안하고, 【사람】이 묶음마다 받기·역할 바꾸기·버리기를 한다. 레이어나 객체에 역할을 직접 정할 수도 있다. 확인한 분류는 프로젝트에 남는다.
3. 【사람】 설정값(기준 지반·산정 제외 입력 끝남·없음 확정·숨긴 객체 포함)을 정한다.
4. 【사람】 [법규 체크]를 누른다. 사람만 누르며, 대화의 AI도 누르지 않는다.
5. 계산(VIDE가 자동으로, 사람 개입 없음): 문서를 다시 읽고 규모(건폐율·용적률·높이·층수), 형상 제한(건축선 후퇴·가각·건축한계선·대지 안의 공지·민법상 이격·기타 이격·정북 일조·최대 외피·대지 밖), 주차·조경·공개공지를 계산해 항목마다 상태·이유·근거·숫자 출처를 낸다. 기준 지반을 최저로 볼지 최고로 볼지, 옥탑을 높이에 넣을지처럼 정해지지 않은 조건이 있으면 경우마다 따로 계산해 '경우별 결과'로 함께 보이고, 경우마다 결과가 다르면 그 항목은 '판단 필요'가 된다. 2분 안에 끝나야 한다.
6. 【사람】 결과 행을 눌러 걸린 객체와 외피 밖 부분을 화면에서 확인하고, 필요하면 보고서·표를 낸다. 모델·분류·설정·규제 조건이 바뀌면 '다시 체크 필요'가 보이고 4로 돌아간다.

## ⑥ 결과

- **화면:** 머리에 상태별 수(적합·위반·판단 필요·사람 입력 필요·검사 불가)와 미확정 수(판단 필요로 남은 조건의 수), 마지막 체크 시각과 읽은 문서. 아래 결과 서랍에 네 탭이 있다. 결과 탭은 행마다 상태·계획 값·한계 값·여유·근거 조항·숫자 출처·경우별 결과를 보인다. 미적용 탭은 적용 여부가 '미적용'으로 확정된 항목, 분류 탭은 역할별 객체 수와 쓰지 못한 객체, 입력 탭은 읽은 문서·받은 앞 결과와 계산 시각을 보인다. 늘 "탐색용 법규 체크 — 인허가 검토·법규 검토를 대체하지 않음"과 "검사 목록 밖의 법규는 보지 않음"을 보인다.
- **3D 보기:** 외피 밖으로 나간 초과 부분은 결과를 보는 동안 늘 VIDE의 3D 화면에 번호가 붙은 반투명 덩어리로 겹쳐 보인다. 결과 행을 누르면 그 행의 걸린 객체를 고르고 첫 초과 부분으로 화면을 맞춘다. 3D의 덩어리를 누르면 표의 그 행이 열린다. 최대 외피 윤곽을 옅은 선으로 함께 켤 수 있다. Rhino에는 아무것도 쓰지 않는다.
- **Rhino에 만들기:** 없음.
- **파일:** 웹 문서로 열리는 보고서(HTML)와 엑셀로 여는 결과 표(CSV). 보고서는 검토용(전부)과 보고용(결과 표·초과 부분·고지·첫 쪽 요약만) 두 등급 가운데 고른다. 체크가 최신일 때만 낸다(아직 체크하지 않았거나 '다시 체크 필요'이면 꺼짐).

## ⑦ 통과 조건

이 도구에는 계산 결과를 믿을 만한지 따로 보는 점검이 없다(선언한 점검 0개). 결과 표의 적합·위반은 설계를 판정한 것이지 이 도구의 점검이 아니며, 위반이 있어도 흐름을 막지 않는다.

도구를 만들 때는 결과에 검사 목록의 모든 항목이 결과 행이나 미적용 항목으로 꼭 한 번 나오는지, 상태별 수와 미확정 수가 행과 맞는지를 확인한다. 또 일부러 만든 합성 자료 세 벌(규제 조건이 갖춰진 경우, 규제 조건이 없는 경우, 미확정 조건이 걸린 경우)로 기대 결과와 같은지 자체 시험한다. 이는 쓰는 사람이 할 일이 아니다.

## ⑧ 한계·가정

- 한계 값은 규제 조건 항목에서만 온다. 계산에 법정 값이 들어 있지 않으며, 값이 비면 '사람 입력 필요', 법규 판단이 걸린 비교는 '판단 필요'다.
- AI는 객체 역할을 제안만 하고 판정하지 않는다. 제안은 사람이 받기 전에는 계산에 들어가지 않는다.
- 검사 목록 밖의 법규(피난·장애인 편의·방화·승강기·채광, 허용 용도 판정, 주차 구획 치수·차로, 조경 식재, 공개공지 위치 요건, 지하층 이격, 일조 시간 분석 등)는 보지 않는다.
- 지표면 산정 방법은 법규 판단이므로 하나로 정하지 않는다. 사람이 높이를 넣지 않으면 사이트 모델링의 최저·최고 두 경우로 계산한다(평균은 보이기만 함).
- 층 윤곽이 없으면 연면적·용적률·층수는 '검사 불가'다(매스를 층고로 나누어 만들지 않음). 건축면적 윤곽이 없으면 매스를 위에서 내려다본 바닥 그림자(수평투영)를 건축면적으로 쓰며, 산정에서 빼는 처마·차양 등을 빼지 않으므로 건축면적·건폐율이 실제보다 크게 나올 수 있다.
- 맨 위층 윤곽으로 세운 형상은 '건축 가능 영역·매스'의 기준층 층고를 가정으로 써서 높이를 정한다.
- 문서 단위를 알 수 없으면 길이·면적·부피를 쓰는 행은 '검사 불가'다.
- 기준 지반 근거는 고르는 목록(측량·현황 자료, 설계 기준 레벨, 인허가 협의 값)뿐이고 자유 문장으로 쓰지 않는다.
- 층별 산정 제외 면적과 층 용도는 계산이 받도록 되어 있지만 지금 이 도구 화면에는 넣는 칸이 없다. 그래서 용적률은 제외 면적 없이 계산되며, '산정 제외 면적 입력 끝남'을 켜지 않으면 용적률이 넘는 결과는 '판단 필요'로 남는다.
