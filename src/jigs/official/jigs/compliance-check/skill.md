# 법규 체크

사람이 Rhino에서 모델링한 건물을 '건축 가능 영역·매스' 작업본의 규제 조건(한계)과 비교한다.

- 열면 연결 Rhino 문서를 한 번 읽어 객체마다 검사 역할(건물 매스·층 윤곽·주차 구획·조경·공개공지 등)을
  속성·분류 기록·레이어 이름으로 정한다. 정하지 못한 객체는 [역할 제안 받기]로 AI가 제안하고 사람이 받거나
  바꾸거나 버린다. 사람이 직접 레이어·객체의 역할을 정할 수도 있다.
- [법규 체크]를 누를 때만 문서를 다시 읽고 계산한다. 설정·분류·모델·규제 조건이 바뀌면 '다시 체크 필요'만
  보이고 저절로 다시 돌지 않는다. 대화의 AI도 [법규 체크]를 누르지 않는다. 체크 전에는 `check` 결과가
  없으니 `jig_output`으로 읽지 말고, 사람에게 법규 체크 화면 맨 위의 [법규 체크] 버튼을 누르라고 안내한다.
  앞 '건축 가능 영역·매스' 작업본이 없으면 규제 조건 행은 '사람 입력 필요'로 나온다고 함께 알린다.
- 한계 값은 규제 조건 항목에서만 온다(코드에 법정 값 없음). 값이 비면 '사람 입력 필요', 법규 판단이 걸린
  비교는 '판단 필요'로 남기고 조용히 적합·위반으로 정하지 않는다.
- 결과 행을 누르면 VIDE 뷰포트에서 걸린 객체를 고르고 외피 밖 부분을 겹쳐 보인다. Rhino에는 아무것도 쓰지
  않는다. 보고서(HTML)와 표(CSV)는 체크가 최신일 때만 낸다.
- 탐색용 법규 체크로 인허가 검토·법규 검토를 대체하지 않는다.
