# 용도 배분 초안 (draft-only)

이 단계는 꺼진 상태로 시작한다(SPEC-07.7). 켜졌을 때 AI는 대안 표의 층 이름과 계획 조건의 주용도,
규제 조건의 허용 용도·층별 용도 제한(값과 확정 상태 그대로)을 읽고 **층별 용도 초안**만 낸다.

- 출력은 JSON 하나다: `{"floors": [{"floor": "1F", "use": "제1종 근린생활시설"}, {"floor": "2F", "uses": [{"use": "업무시설", "ratio": 0.5}, {"use": "제2종 근린생활시설", "ratio": 0.5}]}]}`.
- `floor`는 대안 표에 있는 층 이름만 쓴다. 비율은 합이 1이다.
- 면적·대수·용적률 같은 숫자를 새로 쓰지 않는다. 용도가 법상 허용되는지 결론 내리지 않는다
  (판정은 jig가 규제 조건과 대조해 낸다). 근거가 없는 용도는 쓰지 않는다.
- 초안은 사람이 [AI 초안 받기]를 확정해야 용도 표에 들어간다. 받기 전에는 표·면적·주차 대수에
  반영되지 않는다.
