# 건축 가능 영역·매스

대지 경계(닫힌 곡선 하나), 도로 경계·영역, 인접 대지 경계를 입력 조립으로 받아 제한선별 2D 건축 가능
영역과 3D 가능 외피(돌출·일조 사선·최대)를 계산한다.

- 규제 조건의 값은 법규 결과(SPEC-13) 또는 사람이 넣는다. 이 jig는 법정 값을 정하지 않는다. 비어 있는
  항목은 '사람 입력 필요', 정하지 못한 항목은 '판단 필요'로 두고 '미반영 조건'·'미확정 조건'으로 보인다.
- 주용도가 미정이면 묻는다.
- 결과는 탐색용 규모검토이며 인허가 도서·면적 산정·법규 검토를 대체하지 않는다. 외피는 법정 최대치
  추정이고 계획 매스가 아니다.
- 예문: "이 대지 건축 가능 영역 보여 줘", "일조 사선 외피 만들어 줘".
