대화 열

작성기와 상태줄은 지금 VIDE 그대로입니다(첨부, 요청 목록, 모드, 모델, 추론 강도, Ctrl+Enter로 보내기). 말, 경로 줄, 진행 체크, 질문 카드, 결과 카드가 한 줄기로 쌓입니다. 끝난 요청은 한 줄로 접히고, 사람을 기다리는 일만 위에 고정됩니다.

무대

한 번에 하나: 프로젝트 보드, 모델, jig 작업본, 참고 자료, 보고서. 왼쪽 레일은 무대를 고르는 입구이고, 말로 요청해도 같은 무대로 옮겨 갑니다. 요청이 무대를 바꿀 때 테두리가 한 번 코랄로 빛납니다. 왼쪽 슬롯은 모델이면 레이어, jig면 단계와 설정값입니다.

포인트 컬러

코랄은 AI 실행 점, 현재 단계 점, 작성기 대상 칩, 방금 바뀐 부재, 포커스에만 씁니다. 버튼은 검정, 선택 행은 옅은 바탕입니다.

이 목업의 범위

영역 배치와 각 영역에 보일 내용만 검토합니다. 버튼·입력·간격 같은 세부 모양은 지금 VIDE 것을 그대로 쓰며, 여기 그린 모양은 자리 표시입니다.

레일

홈은 지금처럼 모든 프로젝트로 갑니다. 그 아래 대시보드는 새 항목이며 넣을 내용은 검토 중입니다. 프로젝트 자료는 지금 만든 프로젝트 DB(정해진 것·막힌 것·바뀐 것, 분야, 상태, 근거 원문)입니다.

jig마다 다른 화면

모든 jig가 같은 틀을 씁니다: 왼쪽(단계·설정값·입력 역할), 위(KPI 띠), 가운데(보기 여러 개: 3D·평면·표·보고서), 아래(서랍: 목록·근거), 행동 버튼. 무엇을 끼울지는 jig의 panel.json이 정합니다. 무대 머리의 jig 이름(▾)으로 구조 골조와 법규 검토를 바꿔 보세요.
